The typed execution library that compiler-generated TypeScript imports, also usable from handwritten TypeScript: [`Module`](./runtime.md#module), [`Context`](./runtime.md#context), captured [`Value`](./runtime.md#value) constructors, collections and the Arrow schema constructors.

Most hosts run programs through [`Node`](./tea.md#node) from `tea` instead. A host that
already owns synchronized rows starts from a generated [`Module`](./runtime.md#module) (the
default export of a `tea build` file, or the result of [`loadModule`](./compiler.md#loadmodule)):
bind it with [`Module.bind`](./runtime.md#module-module-bind), create a [`Context`](./runtime.md#context), and call
[`Context.step`](./runtime.md#context-context-step) once per row.

### color function

Construct a captured Tea color from a [`Color`](./runtime.md#color-class), a `#RRGGBB` or `#RRGGBBAA` hex string, or `null` for the missing color.

```ts
function color(value: string | Color | null): Value<Color | null, "color">;
```

A string goes through [`Color.parse`](./runtime.md#color-class-color-class-parse), so malformed hex throws a
`TypeError`.

```ts

color(new Color(0, 0, 255)).value?.toString(); // '#0000FF'
color(null).value; // null
```

### contextValue

Read a bind-visible builtin inside a module's generated binding calculation; hosts supply these values through [`Module.bind`](./runtime.md#module-module-bind) rather than calling this.

```ts
function contextValue(
  values: ReadonlyMap<number, Scalar> | undefined,
  id: number,
  name: string,
): Scalar;
```

Throws when `values` has no entry for `id`. `Module.bind` treats that error
as context not supplied yet: the configuration stays incomplete instead of
failing or keeping stale results. Execution-only builtins, which change per
row, never have a value here.

### Color class

### Context

The execution owner for one bound module. Generated programs specialize its four property types; storage mechanics and transactions stay in this library.

```ts
class Context<
  P extends object = object,
  I extends object = object,
  S extends object = object,
  O extends object = object,
> {
  readonly params: P;
  readonly inputs: I;
  readonly outputs: O;
  constructor(module: Module<Context<P, I, S, O>>);
  get state(): S;
  get storage(): Step;
  capture<T, K extends string = string>(
    value: Stored,
    empty: Value<T, K>,
  ): Value<T, K>;
  step(input: StepInput): StepResult;
  readResult(slot: number, empty: Value<unknown>): Stored;
  dispose(): void;
}
```

**Example:** `new Context(module).step(\{series: [10], builtins: [], requests: [],
provisional: false\})` evaluates one synchronized row. Separate Contexts own
separate histories and Heaps, even when their executable code is shared.

#### Context Context params

Captured parameter values by name, fixed for this Context's lifetime.

```ts
readonly params: P;
```

#### Context Context inputs

Named history readers for series inputs, builtins and request children.

```ts
readonly inputs: I;
```

#### Context Context outputs

Named output destinations: `.set(value)` for set fields and `.append(value)` for append fields. Each call captures a detached copy of the value at that moment.

```ts
readonly outputs: O;
```

#### Context Context state

Root state is accessible only while main is executing.

```ts
get state(): S;
```

#### Context Context step

Accept one attempt atomically. Main may return normally at any point; an exception aborts its writes and output. Final attempts advance history; successful provisional attempts retain the existing varip/Heap behavior.

```ts
step(input: StepInput): StepResult;
```

```ts
Call with provisional true, then false for the same logical row.
```

#### Context Context dispose

Release this execution's storage; repeated disposal is harmless.

```ts
dispose(): void;
```

### Module

A compiled program's configuration and ordinary TypeScript entry function. Binding returns an independent configuration; execution state belongs to Context.

```ts
class Module<C extends Context = Context> {
  readonly abi: typeof RUNTIME_ABI_VERSION;
  readonly inputs: {
    readonly schema: Schema;
    readonly series: readonly {
      readonly name?: string;
      readonly id: string | null;
      readonly depth: Depth;
    }[];
    readonly builtins: readonly Builtin[];
  };
  readonly parameters: readonly Parameter[];
  readonly state: {
    readonly frames: readonly Frame[];
  };
  readonly outputs: {
    readonly schema: Schema;
  };
  readonly requests: readonly Request[];
  constructor(
    data: Pick<
      Module,
      "abi" | "inputs" | "parameters" | "state" | "outputs" | "requests"
    >,
    execute: (context: C) => void,
    calculate?: (
      data: ReturnType<typeof copyData>,
      constants: ReadonlyMap<number, Scalar>,
    ) => void,
  );
  bind(
    values?: Readonly<Record<string, unknown>>,
    context?: ReadonlyMap<number, Scalar>,
    path?: readonly string[],
  ): Module<C>;
  ready(): boolean;
  remaining(): readonly string[];
  main(context: C): void;
  clone(): Module<C>;
}
```

### str

