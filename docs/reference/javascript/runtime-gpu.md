Runs an artifact compiled by `tea/codegen/wgsl` on a caller-supplied `GPUDevice`, over concrete input arrays the host has already materialized.

Start with [`createGpuExecution`](./runtime-gpu.md#creategpuexecution): it validates and packs each
[`GpuBinding`](./runtime-gpu.md#gpubinding), sizes buffers from the device's hard limits, and returns
a resumable [`GpuExecution`](./runtime-gpu.md#gpuexecution) that publishes [`Datum`](./tea.md#datum) rows shaped by
the artifact's output schema.

## Functions

### createGpuExecution

Own device buffers for caller-ordered bindings and publish schema-named rows. Each declaration callback receives an independent Arrow schema. Readback is validated for the entire chunk before any row is delivered; disposal releases only buffers created by this session.

```ts
function createGpuExecution(
  device: GPUDevice,
  artifact: CompiledWgslProgram,
  bindings: readonly GpuBinding[],
): Promise<GpuExecution>;
```

```ts
const execution = await createGpuExecution(device, artifact, [
  {
    params: {},
    indices: 2,
    series: { close: [10, 12] },
    declare: (d) => console.log(d.schema),
    next: (row) => console.log(row.output0),
  },
]);
try {
  await execution.runAll();
} finally {
  execution.dispose();
}
// For an artifact compiled from `emit "output0" close`, this logs 10, then 12.
```

## Classes

### GpuBindingError

The artifact or a binding was rejected by [`createGpuExecution`](./runtime-gpu.md#creategpuexecution) before any GPU resource was created or any callback ran.

```ts
class GpuBindingError extends OperationalError {
  constructor(message: string);
}
```

Causes include a stale or malformed artifact, parameters the embedded
module's `bind()` rejects or that exceed the i32 or f32 range, a missing or
wrong-length series, an infinite or out-of-f32-range series value, a
wrong-length `time` array, and sizes beyond the u32 execution ABI. The
message names the binding index where one applies.

### GpuExecutionError

GPU work could not be set up, failed, or was requested from a session that can no longer run.

```ts
class GpuExecutionError extends OperationalError {
  constructor(message: string);
}
```

[`createGpuExecution`](./runtime-gpu.md#creategpuexecution) throws it for WGSL compilation errors and for
buffers, workgroups or workgroup storage beyond the device's limits;
[`GpuExecution`](./runtime-gpu.md#gpuexecution) methods throw it for a chunk that fails validation
(for example an effect overflow, or a `time` entry that is not a safe
integer) and for a disposed, failed or busy session.

### GpuExecution

A resumable GPU run over fixed bindings, created by [`createGpuExecution`](./runtime-gpu.md#creategpuexecution).

```ts
interface GpuExecution {
  readonly done: boolean;
  runChunk(): Promise<GpuChunkResult>;
  runAll(): Promise<GpuRunSummary>;
  dispose(): void;
}
```

Execution state stays on the device between chunks, so absolute row numbers
and history do not depend on chunk boundaries. The session owns only the
buffers it created; the caller keeps the `GPUDevice`.

**`GpuExecution.done`**

```ts
readonly done: boolean;
```

True once every binding has delivered all its rows.

**`GpuExecution.runChunk`**

```ts
runChunk(): Promise<GpuChunkResult>;
```

Run the next chunk for every unfinished binding. After readback the whole
chunk is validated before any row is delivered; then each binding's
`next()` receives its rows synchronously, binding by binding in caller
order. Any failure, including an exception thrown by `next()`, makes the
session terminal. Rejects with [`GpuExecutionError`](./runtime-gpu.md#gpuexecutionerror) after disposal,
after a failure, or while another chunk is running. Resolves
`{bindings: [], done: true}` once done.

**`GpuExecution.runAll`**

```ts
runAll(): Promise<GpuRunSummary>;
```

Run chunks until every binding is done; fails like `runChunk()`.

**`GpuExecution.dispose`**

```ts
dispose(): void;
```

Destroy the buffers this session created. Repeated calls are harmless;
later runs reject with [`GpuExecutionError`](./runtime-gpu.md#gpuexecutionerror).

## Types

### GpuBinding

One concrete execution of an artifact: parameter values, materialized input arrays, and the callbacks that receive its rows.

```ts
type GpuBinding = Readonly<{
  params: Readonly<Record<string, unknown>>;
  indices: number;
  series: Readonly<Record<string, readonly number[]>>;
  time?: readonly (number | null)[];
  declare?(outputs: Module["outputs"]): void;
  next(datum: Datum): void;
}>;
```

Each binding runs with private state, and its position in the array passed
to [`createGpuExecution`](./runtime-gpu.md#creategpuexecution) is its identity (`bindingIndex`).

- `params`: parameter values by name, validated by the embedded module's
  `bind()`; omitted parameters keep their defaults.
- `indices`: the number of rows to run, at most 2147483647.
- `series`: an array of exactly `indices` numbers for each id in the
  artifact's `requiredSeries`; other keys are ignored. Values are rounded
  to f32: `NaN` is na, and infinities or values beyond the f32 range are
  rejected.
- `time`: optional epoch milliseconds per row, `indices` entries long, each
  a safe integer or `null`; it becomes each row's `time`.
- `declare`: optional; called once during `createGpuExecution`, before any
  row, with this binding's module `outputs` and a private schema copy.
- `next`: receives each row as a detached [`Datum`](./tea.md#datum).

```ts
const binding: GpuBinding = {
  params: { length: 20 },
  indices: close.length,
  series: { close },
  next: (row) => rows.push(row),
};
```
