Compiles a checked Tea Program into one bind-independent WebGPU artifact and defines the physical layout that artifact shares with `tea/runtime/gpu`.

Start with [`compileProgramToWgsl`](./codegen-wgsl.md#compileprogramtowgsl): it returns a complete
[`CompiledWgslProgram`](./codegen-wgsl.md#compiledwgslprogram) for [`createGpuExecution`](./runtime-gpu.md#creategpuexecution), or an eligibility
report naming the construct the GPU backend does not support, never a
partial shader. The `GPU_*` constants and `Wgsl*` types document the buffer
bindings, offsets and strides inside the artifact.

## Functions

### analyzeWgslEligibility

Report whether a checked Program can run on the GPU, without keeping an artifact.

```ts
function analyzeWgslEligibility(program: Program): WgslEligibilityReport;
```

| Parameter | Description                                                                             |
| --------- | --------------------------------------------------------------------------------------- |
| `program` | A checked Program, as returned by [`compileToProgram`](./compiler.md#compiletoprogram). |

**Returns:** An eligible report with no issues, or an ineligible report naming
the construct that stopped compilation.

Compilation is the single capability walk: this runs the full
[`compileProgramToWgsl`](./codegen-wgsl.md#compileprogramtowgsl) and returns only its eligibility, so reporting
never maintains a parallel support table that can drift from the emitter.

```ts
const report = analyzeWgslEligibility(program);
if (!report.eligible) console.log(report.issues[0]?.code);
// For plot("price", close): 'struct-reference-lowering-unimplemented'
```

### compileProgramToWgsl

Lower a checked Program into a portable GPU artifact without binding data or allocating a device. Logical fields use the embedded TypeScript module's ordinary Arrow schemas; physical layouts retain WGSL offsets and scalar encodings. Unsupported Tea operations return diagnostics rather than a partial shader.

```ts
function compileProgramToWgsl(program: Program): WgslCompilationResult;
```

```ts
const errors = new Errors();
const program = compileToProgram(
  [{ filename: "demo.tea", source: 'emit "output0" close' }],
  errors,
);
if (program) {
  const result = compileProgramToWgsl(program);
  if (result.status === "compiled") {
    loadModule(result.artifact.bindingModule.source).outputs.schema.fields[4]
      .name;
    // "output0"
  }
}
```

    readonly initializedWordOffset: 0;

It holds no device, data or parameter values, so one artifact serves any
number of [`GpuBinding`](./runtime-gpu.md#gpubinding)s, and it survives a JSON round trip for
storage. Arrow output structure lives only in the embedded module;
`resultChannels` and `events` only say where each output's bytes are.
Produce it with [`compileProgramToWgsl`](./codegen-wgsl.md#compileprogramtowgsl); run it with
[`createGpuExecution`](./runtime-gpu.md#creategpuexecution).

### WgslCacheContract

How an execution may stage its fixed state in workgroup memory.

```ts
interface WgslCacheContract {
  readonly storageEntryPoint: string;
  readonly cachedEntryPoint: string;
  readonly overrides: {
    readonly workgroupSize: WgslOverride;
    readonly cacheWordsPerExecution: WgslOverride;
    readonly cacheAllocationWords: WgslOverride;
  };
  readonly segments: readonly WgslCacheSegment[];
}
```

The runtime picks the longest prefix of ranked `segments` whose words, for
every execution in a workgroup, fit the device's
`maxComputeWorkgroupStorageSize`. It then runs `cachedEntryPoint` with
`cacheWordsPerExecution` set to that prefix's length, or `storageEntryPoint`
when no segment fits.

**`WgslCacheContract.storageEntryPoint`**

```ts
readonly storageEntryPoint: string;
```

Entry point that keeps state in storage; equals `module.entryPoint`.

**`WgslCacheContract.cachedEntryPoint`**

```ts
readonly cachedEntryPoint: string;
```

Entry point that copies the staged segments in, runs, and copies them back.

**`WgslCacheContract.overrides`**

```ts
readonly overrides: {
    readonly workgroupSize: WgslOverride;
    readonly cacheWordsPerExecution: WgslOverride;
    readonly cacheAllocationWords: WgslOverride;
};
```

Pipeline constants: the workgroup size, the staged words per execution,
and the workgroup array length (staged words times workgroup size, or 1).

**`WgslCacheContract.segments`**

```ts
readonly segments: readonly WgslCacheSegment[];
```

Fixed-state segments in rank order.

### WgslStateFrameLayout

Static layout of one frame template: the program root (`id` 0, owner `<program>`) or a function.

```ts

```

start of the frame.

**`WgslStateFrameLayout.id`**

```ts
readonly id: number;
```

Index in `CompiledWgslProgram.state.frames`, matching the embedded

**`WgslStateFrameLayout.owner`**

readonly owner: string;

Function name, or `<program>` for the root.

**`WgslStateFrameLayout.committedActivationWordOffset`**

readonly committedActivationWordOffset: number;

Activation words, each holding the absolute activation row plus one, or
zero while inactive. The tentative word is reset from the committed word
when a row starts and becomes durable when the row commits.

**`WgslStateFrameLayout.wordCount`**

```ts
readonly wordCount: number;
```

Total words of the frame, including the frames of its call sites.

**`WgslStateFrameLayout.children`**

```ts
readonly children: readonly {
    readonly slot: number;
    readonly templateId: number;
    readonly wordOffset: number;
}[];
```

One entry per written call site: its call `slot`, the callee's frame
`templateId`, and the `wordOffset` of the embedded child frame.

### WgslStateLocalLayout

Placement of one retained local inside its frame.

```ts
interface WgslStateLocalLayout {
  readonly name: string;
  readonly slot: number;
  readonly storage: "perBar" | "var";
  readonly scratchWordOffset: number;
  readonly valueWordCount: number;
  readonly committedInitWordOffset: number | null;
  readonly tentativeInitWordOffset: number | null;
  readonly historyDescriptorWordOffset: number | null;
}
```

Word offsets count u32 words from the start of the frame.

**`WgslStateLocalLayout.slot`**

```ts
readonly slot: number;
```

Slot in the generated JS frame table. WGSL may elide history-free
formals, so this is not necessarily the local's index below.

**`WgslStateLocalLayout.storage`**

```ts
readonly storage: 'perBar' | 'var';
```

`perBar` values start fresh each row; `var` values persist across rows.

**`WgslStateLocalLayout.scratchWordOffset`**

```ts
readonly scratchWordOffset: number;
```

First word of the local's current value.

**`WgslStateLocalLayout.valueWordCount`**

```ts
readonly valueWordCount: number;
```

Words in one value of this local.

**`WgslStateLocalLayout.committedInitWordOffset`**

```ts
readonly committedInitWordOffset: number | null;
```

Committed initialization flag of a `var` local; null for `perBar`.

**`WgslStateLocalLayout.tentativeInitWordOffset`**

```ts
readonly tentativeInitWordOffset: number | null;
```

Initialization flag for the row in progress; null for `perBar`.

**`WgslStateLocalLayout.historyDescriptorWordOffset`**

```ts
readonly historyDescriptorWordOffset: number | null;
```

Two fixed words containing the binding-specific history payload offset
(relative to the execution state) and capacity. Null means no retained
history exists for this local.

## Types

### WgslCodec

Physical scalar decoding instructions. Logical types and enum identities live only in the Arrow schema; this codec says where WGSL wrote the value and its validity flag. Reference structs remain unsupported by this backend.

```ts
type WgslCodec =
  | {
      readonly kind: "bool";
      readonly physicalLayout: number;
      readonly valueByteOffset: number;
    }
  | {
      readonly kind: "int" | "float" | "string" | "color";
      readonly physicalLayout: number;
      readonly validByteOffset: number;
      readonly valueByteOffset: number;
    }
  | {
      readonly kind: "enum";
      readonly physicalLayout: number;
      readonly validByteOffset: number;
      readonly ordinalByteOffset: number;
    };
```

```ts
A float codec reads validity at byte 0 and f32 payload bits at byte 4;
the corresponding Arrow field is Float64 because Tea publishes JS numbers.
```

### WgslCompilationResult

Outcome of [`compileProgramToWgsl`](./codegen-wgsl.md#compileprogramtowgsl): `'compiled'` with a complete [`CompiledWgslProgram`](./codegen-wgsl.md#compiledwgslprogram), or `'staged-unsupported'` with `artifact: null` and an ineligible report.

```ts
type WgslCompilationResult =
  | {
      readonly status: "staged-unsupported";
      readonly eligibility: WgslEligibilityReport;
      readonly artifact: null;
    }
  | {
      readonly status: "compiled";
      readonly eligibility: WgslEligibilityReport & {
        readonly eligible: true;
      };
      readonly artifact: CompiledWgslProgram;
    };
```

There is never a partial artifact.

## Constants

### GPU_EXTERNAL_BUFFER_BINDINGS

Binding numbers, within [`GPU_BUFFER_GROUP`](./codegen-wgsl.md#constants), of the seven storage buffers: job descriptors, series values, execution state, result cells, effect status, effect records and parameters.

```ts
const GPU_EXTERNAL_BUFFER_BINDINGS: Readonly<{
  jobs: 0;
  series: 1;
  executionStates: 2;
  results: 3;
  effectStatus: 4;
  effectRecords: 5;
  params: 6;
}>;
```

### GPU_JOB_DESCRIPTOR_OFFSETS

Byte offset of each u32 field within a job descriptor.

```ts
const GPU_JOB_DESCRIPTOR_OFFSETS: Readonly<{
  seriesOffset: 0;
  rowCount: 4;
  resultOffset: 8;
  resultCount: 12;
  effectOffset: 16;
  effectCapacity: 20;
  chunkRows: 24;
  paramsOffset: 28;
  stateOffset: 32;
  stateWords: 36;
}>;
```

The descriptor locates one binding's slice of the shared buffers:
`seriesOffset`, `resultOffset`, `effectOffset`, `paramsOffset` and
`stateOffset` are element indices (series values, result cells, effect
records, parameter slots and state words), not bytes. `rowCount` is the
binding's extent, `chunkRows` the rows one dispatch runs, and `resultCount`,
`effectCapacity` and `stateWords` the lengths of its result, effect and
state slices.
