The `tea` command compiles, runs and inspects Tea scripts, serves this documentation offline, and runs the language server. Every command accepts `--help`; `tea --version` prints the version. Set the `TEA_LOG` environment variable to `debug`, `info`, `warn` or `error` to change how much the command logs.

| Name                      | Description                                               |
| ------------------------- | --------------------------------------------------------- |
| [`tea docs`](#tea-docs)   | Serve the documentation website locally.                  |
| [`tea lsp`](#tea-lsp)     | Serve the Language Server Protocol over stdin and stdout. |
| [`tea run`](#tea-run)     | Compile and execute a Tea script over a CSV dataset.      |
| [`tea build`](#tea-build) | Compile a Tea script and emit TypeScript.                 |
| [`tea parse`](#tea-parse) | Run the frontend and dump intermediate artifacts.         |

## Commands

### tea docs

Serve the documentation website locally.

```bash
tea docs [options]
```

| Option            | Description                                 |
| ----------------- | ------------------------------------------- |
| `--port <number>` | Port to bind. Default: any available port.  |
| `--no-open`       | Do not open the documentation in a browser. |

### tea lsp

Serve the Language Server Protocol over stdin and stdout.

```bash
tea lsp [options]
```

| Option    | Description                                        |
| --------- | -------------------------------------------------- |
| `--stdio` | Accepted and ignored: stdio is the only transport. |

### tea run

Compile and execute a Tea script over a CSV dataset.

```bash
tea run <file> --input <file> [--trace] [--<input name> <value>...]
```

| Argument | Description      |
| -------- | ---------------- |
| `file`   | Tea source file. |

| Option               | Description                                                            |
| -------------------- | ---------------------------------------------------------------------- |
| `-i, --input <file>` | CSV dataset to bind as input series. Required.                         |
| `--trace`            | Print the machine trace format (golden-compatible) instead of a table. |

Compile and execute a Tea script over a CSV dataset. Override an input default with a flag named after the variable that declares it, such as --length 20 for length = input.int(14).

### tea build

Compile a Tea script and emit TypeScript.

```bash
tea build [options] <file>
```

| Argument | Description      |
| -------- | ---------------- |
| `file`   | Tea source file. |

| Option             | Description                                      |
| ------------------ | ------------------------------------------------ |
| `-o, --out <file>` | Write emitted TypeScript here instead of stdout. |

### tea parse

Run the frontend and dump intermediate artifacts.

```bash
tea parse [options] <file>
```

| Argument | Description      |
| -------- | ---------------- |
| `file`   | Tea source file. |

| Option     | Description                     |
| ---------- | ------------------------------- |
| `--tokens` | Dump the token stream.          |
| `--ast`    | Dump the syntax tree (default). |
| `--ir`     | Dump the lowered IR.            |
