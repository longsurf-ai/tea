Hull moving average of `source`.

```tea
ta.hma(source, int length)
```

| Parameter | Type  | Description                                                         |
| --------- | ----- | ------------------------------------------------------------------- |
| `source`  |       | Series to average, usually [`close`](../price-and-volume.md#close). |
| `length`  | `int` | Number of bars, an `int` of at least `2`.                           |

**Returns:** The average; `na` for the first `length + math.floor(math.sqrt(length)) - 2` bars.

It is the [`ta.wma`](./wma.md) over `math.floor(math.sqrt(length))` bars of
`2 * ta.wma(source, length / 2) - ta.wma(source, length)`, with `length / 2`
rounded down. Like [`ta.wma`](./wma.md), it leaves out `na` values.
