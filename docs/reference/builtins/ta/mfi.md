Money Flow Index (MFI) of `series`, from `0` to `100`.

```tea
ta.mfi(float series, int length)
```

| Parameter | Type    | Description                                                  |
| --------- | ------- | ------------------------------------------------------------ |
| `series`  | `float` | Price series, usually [`hlc3`](../price-and-volume.md#hlc3). |
| `length`  | `int`   | Number of bars in the window, at least 1.                    |

**Returns:** `float`: the index.

Each bar's money flow is `series` times [`volume`](../price-and-volume.md#volume). Over the last
`length` bars, the flows of bars where `series` rose and of bars where it
fell are summed separately, and the index compares the two. A bar whose
change or flow involves an `na` value is left out, and a bar where `series`
did not change counts toward neither sum.

**Formula**

$$
\begin{aligned}
\Delta_t &= \mathit{series}_t - \mathit{series}_{t-1}, \qquad
F_t = \mathit{series}_t \cdot \mathit{volume}_t \\
K_t &= \{\, i : 0 \le i < \mathit{length},\
\Delta_{t-i} \ne \text{na},\ F_{t-i} \ne \text{na} \,\} \\
P_t &= \sum_{i \in K_t,\ \Delta_{t-i} > 0} F_{t-i}, \qquad
N_t = \sum_{i \in K_t,\ \Delta_{t-i} < 0} F_{t-i} \\
\mathrm{mfi}_t &= 100 - \frac{100}{1 + P_t / N_t}
\end{aligned}
$$

**Warm-up and na:** `na` on the first `length` bars, and when the bars in the window
that fell have a total flow of `0`, as when none fell or their volume is
`0`. It is `0` when the bars that rose have a total flow of `0` but those
that fell do not.

**Example:** At index 4 the 3-bar window has one rising bar with a flow of `12 * 100` and
one falling bar with `11 * 200`, so the index is
`100 - 100 / (1 + 1200 / 2200)`. No bar fell in the window at index 6, so
it is `na` there.

```tea
emit "close" close
emit "volume" volume
emit "mfi" ta.mfi(close, 3)
```
