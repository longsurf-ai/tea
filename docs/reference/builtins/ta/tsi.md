True Strength Index (TSI) of `source`, from `-1` to `1`.

```tea
ta.tsi(
    float source,
    simple int short_length,
    simple int long_length
)
```

| Parameter      | Type         | Description                                                                                                                          |
| -------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| `source`       | `float`      | Series to measure, usually [`close`](../price-and-volume.md#close).                                                                  |
| `short_length` | `simple int` | Length of the second smoothing in bars, at least 1. It must be a value known when the script starts, such as a constant or an input. |
| `long_length`  | `simple int` | Length of the first smoothing in bars, at least 1. It must be a value known when the script starts, such as a constant or an input.  |

**Returns:** `float`: the index.

The bar-to-bar change of `source` is smoothed twice with [`ta.ema`](./ema.md),
first over `long_length` bars and then over `short_length` bars, and divided
by the absolute change smoothed the same way. Both smoothings skip a bar
whose change is `na`.

**Formula**

$$
\begin{aligned}
\Delta_t &= \mathit{source}_t - \mathit{source}_{t-1} \\
(a_t, b_t) &= \begin{cases}
\bigl(\mathrm{ema}(\Delta, \mathit{long\_length})_t,\
\mathrm{ema}(|\Delta|, \mathit{long\_length})_t\bigr)
& \Delta_t \ne \text{na} \\
(\text{na}, \text{na}) & \text{otherwise}
\end{cases} \\
\mathrm{tsi}_t &= \frac{\mathrm{ema}(a, \mathit{short\_length})_t}
{\mathrm{ema}(b, \mathit{short\_length})_t}
\end{aligned}
$$

**Warm-up and na:** `na` until a bar-to-bar change of `source` is known and not `0`;
that change gives exactly `1` or `-1`. With both lengths `1`, it is also
`na` on each bar where `source` did not change. An `na` value leaves out
the changes into and out of it, so the index keeps its value on that bar
and the next.

**Example:** The first change gives 1 at index 1, and at index 2 the smoothed change, 1,
over the smoothed absolute change, `5 / 3`, gives 0.6. The close is missing
at index 5, so the index keeps its value there and at index 6.

```tea
emit "close" close
emit "tsi" ta.tsi(close, 2, 3)
```

```csv
time,close
0,10
1,12
2,11
3,14
4,13
5,
6,16
7,15
```

**Output:**

