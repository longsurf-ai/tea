Relative Strength Index (RSI) of `source`, from `0` to `100`.

```tea
ta.rsi(float source, simple int length)
```

| Parameter | Type         | Description                                                                                                            |
| --------- | ------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `source`  | `float`      | Series to measure, usually [`close`](../price-and-volume.md#close).                                                    |
| `length`  | `simple int` | Smoothing length in bars, at least 1. It must be a value known when the script starts, such as a constant or an input. |

**Returns:** `float`: the index.

The gains and the losses from bar to bar are each smoothed with
[`ta.rma`](./rma.md) over `length` bars, and the index compares the two. It is
`100` when the smoothed loss is `0`, including on a flat series, and `0`
when only the smoothed gain is `0`.

**Formula**

$$
\begin{aligned}
\Delta_t &= \mathit{source}_t - \mathit{source}_{t-1} \\
U_t &= \mathrm{rma}(\max(\Delta, 0), \mathit{length})_t \\
D_t &= \mathrm{rma}(\max(-\Delta, 0), \mathit{length})_t \\
\mathrm{rsi}_t &= \begin{cases}
100 & D_t = 0 \\
0 & U_t = 0,\ D_t > 0 \\
100 - \dfrac{100}{1 + U_t / D_t} & \text{otherwise}
\end{cases}
\end{aligned}
$$

**Warm-up and na:** `na` until `length` changes of `source` are known: the first
`length` bars when no value is `na`. An `na` value leaves out the changes
into and out of it, so once started the index keeps its value on that bar
and the next.

**Example:** A 3-bar RSI starts at index 3, where the average gain is `(2 + 0 + 2) / 3`
and the average loss `1 / 3`, giving 80. The close is missing at index 6,
so the index keeps its value there and at index 7.

```tea
emit "close" close
emit "rsi" ta.rsi(close, 3)
```

```csv
time,close
0,10
1,12
2,11
3,13
4,13
5,12
6,
7,14
8,16
```
