Correlation coefficient of the last `length` values of `source1` and `source2`, from `-1` to `1`.

```tea
ta.correlation(float source1, float source2, int length)
```

| Parameter | Type    | Description                                                    |
| --------- | ------- | -------------------------------------------------------------- |
| `source1` | `float` | First series, such as [`close`](../price-and-volume.md#close). |
| `source2` | `float` | Second series, paired with `source1` bar by bar.               |
| `length`  | `int`   | Number of bars in the window, at least 2.                      |

**Returns:** `float`: Pearson's correlation coefficient, from `-1` to `1`.

It is Pearson's correlation of the values paired bar by bar. Pairs on a
rising straight line give `1` and pairs on a falling one give `-1`, up to
rounding; `0` means no straight-line relation. A bar where either value is
`na` is left out of both series.

**Formula**

$$
\begin{aligned}
\mathrm{correlation}_t &= \max\left(-1,\ \min\left(1,
\ \frac{\sum_{i \in K_t} u_i v_i}
{\sqrt{\sum_{i \in K_t} u_i^2 \cdot \sum_{i \in K_t} v_i^2}}\right)\right) \\
u_i &= \mathit{source1}_{t-i}
- \frac{1}{|K_t|} \sum_{j \in K_t} \mathit{source1}_{t-j} \\
v_i &= \mathit{source2}_{t-i}
- \frac{1}{|K_t|} \sum_{j \in K_t} \mathit{source2}_{t-j} \\
K_t &= \{\, i : 0 \le i < \mathit{length},
\ \mathit{source1}_{t-i} \ne \text{na},
\ \mathit{source2}_{t-i} \ne \text{na} \,\}
\end{aligned}
$$

**Warm-up and na:** `na` on the first `length - 1` bars, when fewer than two bars in the
window have both values, and when either series is constant over those bars.

**Example:** At index 2 the close and the volume both rise by equal steps, so the
correlation is 1; at index 4 the close falls by equal steps while the volume
rises, so it is -1. The volume is missing at index 7, so that window pairs
only its other two bars.

```tea
emit "close" close
emit "volume" volume
emit "correlation" ta.correlation(close, volume, 3)
```
