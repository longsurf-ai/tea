Weighted moving average: the mean of the last `length` values of `source`, with weights falling linearly from the newest value to the oldest.

```tea
ta.wma(float source, int length)
```

| Parameter | Type    | Description                                                         |
| --------- | ------- | ------------------------------------------------------------------- |
| `source`  | `float` | Series to average, usually [`close`](../price-and-volume.md#close). |
| `length`  | `int`   | Number of bars in the window, at least 1.                           |

**Returns:** `float`: the weighted mean of the window.

The newest value has weight `length`, the one before it `length - 1`, and so
on down to 1 for the oldest, and the weighted sum is divided by the sum of
the weights. Values that are `na` are left out together with their weights.

**Formula**

$$
\begin{aligned}
\mathrm{wma}_t &= \frac
{\sum_{i \in K_t} (\mathit{length} - i) \cdot \mathit{source}_{t-i}}
{\sum_{i \in K_t} (\mathit{length} - i)} \\
\text{where}\quad K_t &= \{\, i : 0 \le i < \mathit{length},
\ \mathit{source}_{t-i} \ne \text{na} \,\}
\end{aligned}
$$

**Warm-up and na:** `na` on the first `length - 1` bars, and when every value in the
window is `na`.

**Example:** A 3-bar average weights the closes 3, 2 and 1 from newest to oldest, so at
index 2 it is `(3 * 16 + 2 * 13 + 10) / 6 = 14`. The close at index 4 is
missing, so at index 5 only the weights 3 and 1 remain:
`(3 * 25 + 19) / 4 = 23.5`.

```tea
emit "close" close
emit "wma" ta.wma(close, 3)
```
