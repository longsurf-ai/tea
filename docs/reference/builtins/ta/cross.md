True on the bar where `source1` crosses `source2` in either direction.

```tea
ta.cross(source1, source2)
```

| Parameter | Description                    |
| --------- | ------------------------------ |
| `source1` | Series that crosses.           |
| `source2` | Series or level being crossed. |

**Returns:** `true` when [`ta.crossover`](./crossover.md) or [`ta.crossunder`](./crossunder.md) is `true`, otherwise `false`.
