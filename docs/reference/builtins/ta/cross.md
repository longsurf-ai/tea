Cross: `true` on the bar where `source1` crosses `source2` in either direction.

```tea
ta.cross(float source1, float source2)
```

| Parameter | Type    | Description                                         |
| --------- | ------- | --------------------------------------------------- |
| `source1` | `float` | Series that crosses, such as a fast moving average. |
| `source2` | `float` | Series or fixed level that `source1` crosses.       |

**Returns:** `bool`: `true` on the bar of the cross, otherwise `false`.

It is `true` when [`ta.crossover`](./crossover.md) or [`ta.crossunder`](./crossunder.md) is.
Equality on the previous bar counts as either side, so `source1` touching
`source2` and moving back to the side it came from is also a cross.

**Formula**

$$
\begin{aligned}
\mathrm{cross}_t ={}
& (\mathit{source1}_t > \mathit{source2}_t
\land \mathit{source1}_{t-1} \le \mathit{source2}_{t-1}) \\
\lor{}
& (\mathit{source1}_t < \mathit{source2}_t
\land \mathit{source1}_{t-1} \ge \mathit{source2}_{t-1})
\end{aligned}
$$

**Warm-up and na:** `false` on the first bar. A comparison with `na` is `false`, so the
result is also `false` on a bar where `source1` or `source2` is `na` and on
the bar after it: a cross that spans an `na` bar is not reported.

**Example:** `true` at indices 1, 2 and 7, where the close moves across 50, and at index
4, where it moves back below after touching 50 at index 3. The missing close
at index 5 hides the rise from 49 to 52.

```tea
emit "close" close
emit "cross" ta.cross(close, 50)
```

```csv
time,close
0,49
1,51
2,49
3,50
4,49
5,
6,52
7,48
```

**Output:**

```text
index  close  cross
0      49     false
1      51     true
2      49     true
3      50     false
4      49     true
5      na     false
6      52     false
7      48     true
```

**See also:** [`ta.crossover`](./crossover.md), [`ta.crossunder`](./crossunder.md)
