Symmetrically weighted moving average of the last four values of `source`.

```tea
ta.swma(source)
```

| Parameter | Description                                                         |
| --------- | ------------------------------------------------------------------- |
| `source`  | Series to average, usually [`close`](../price-and-volume.md#close). |

**Returns:** The weighted mean; `na` for the first three bars and while any of the four values is `na`.

The weights are `1/6`, `2/6`, `2/6` and `1/6`, from the oldest value to the
newest.
