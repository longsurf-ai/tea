Symmetrically weighted moving average: the mean of the last four values of `source`, with weights 1, 2, 2 and 1.

```tea
ta.swma(float source)
```

| Parameter | Type    | Description                                                         |
| --------- | ------- | ------------------------------------------------------------------- |
| `source`  | `float` | Series to average, usually [`close`](../price-and-volume.md#close). |

**Returns:** `float`: the weighted mean of the four values.

The weights are 1/6, 2/6, 2/6 and 1/6 from the oldest value to the newest.
The window is always four bars; there is no `length` parameter. An `na`
value in the window makes the result `na`.

**Formula**

$$
\mathrm{swma}_t = \frac
{\mathit{source}_{t-3} + 2 \cdot \mathit{source}_{t-2}
+ 2 \cdot \mathit{source}_{t-1} + \mathit{source}_t}
{6}
$$

**Warm-up and na:** `na` on the first 3 bars, and while any of the four values is
`na`.

**Example:** The first value is at index 3: `(12 + 2 * 12 + 2 * 18 + 18) / 6 = 15`. The
close at index 7 is missing, so the four windows that hold it, at indexes 7
to 10, are `na`.

```tea
emit "close" close
emit "swma" ta.swma(close)
```

```csv
time,close
0,12
1,12
2,18
3,18
4,24
5,18
6,12
7,
8,18
9,24
10,24
11,18
```
