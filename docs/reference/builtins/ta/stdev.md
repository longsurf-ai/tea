Standard deviation: how widely the last `length` values of `source` spread around their mean.

```tea
ta.stdev(float source, int length, bool biased = true)
```

| Parameter | Type    | Default | Description                                                                                                                                                  |
| --------- | ------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `source`  | `float` |         | Series to measure, such as [`close`](../price-and-volume.md#close).                                                                                          |
| `length`  | `int`   |         | Number of bars in the window, at least 1.                                                                                                                    |
| `biased`  | `bool`  | `true`  | `true` (the default) uses the population variance, which divides by the number of known values; `false` uses the sample variance, which divides by one less. |

**Returns:** `float`: the standard deviation, in the units of `source`.

It is the square root of [`ta.variance`](./variance.md) with the same arguments, so it
is in the units of `source`. Values that are `na` are left out, and known
values that are all equal give exactly `0`, even when they are decimals.

**Formula**

$$
\mathrm{stdev}_t =
\sqrt{\mathrm{variance}(\mathit{source}, \mathit{length}, \mathit{biased})_t}
$$

**Warm-up and na:** `na` on the first `length - 1` bars, and when every value in the
window is `na`. With `biased` set to `false`, also `na` when only one value
in the window is known.

**Example:** At indexes 3 to 5 each 4-bar window holds two 10s and two 12s, each 1 from
their mean of 11, so the standard deviation is 1. The windows that hold the
18 at index 6 give 3.

```tea
emit "close" close
emit "stdev" ta.stdev(close, 4)
```

```csv
time,close
0,10
1,12
2,10
3,12
4,10
5,12
6,18
7,12
```

**Output:**

```text
index  close  stdev
0      10     na
1      12     na
2      10     na
3      12     1
4      10     1
5      12     1
6      18     3
7      12     3
```
