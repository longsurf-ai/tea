Offset to the highest value: `0` when the maximum of the last `length` values of `source` is on the current bar, `-1` when it is on the previous bar, and so on.

```tea
ta.highestbars(float source, int length)
```

| Parameter | Type    | Description                                                      |
| --------- | ------- | ---------------------------------------------------------------- |
| `source`  | `float` | Series to search, usually [`high`](../price-and-volume.md#high). |
| `length`  | `int`   | Number of bars in the window, at least 1.                        |

**Returns:** `int`: the offset, from `1 - length` to `0`.

`bar_index + ta.highestbars(source, length)` is the bar index of the
highest value. Ties go to the most recent bar. Values that are `na` are left
out.

**Formula**

$$
\begin{aligned}
\mathrm{highestbars}_t &= -\min \Big\{\, i \in K_t :
\mathit{source}_{t-i} = \max_{j \in K_t} \mathit{source}_{t-j} \,\Big\} \\
\text{where}\quad K_t &= \{\, i : 0 \le i < \mathit{length},
\ \mathit{source}_{t-i} \ne \text{na} \,\}
\end{aligned}
$$

**Warm-up and na:** `na` on the first `length - 1` bars, and when every value in the
window is `na`.

**Example:** At index 3 the close of 12 ties with the one two bars back, and the most
recent wins. At index 5 the highest close is two bars back; the missing
close at index 4 is left out.

```tea
emit "close" close
emit "highestbars" ta.highestbars(close, 3)
```

```csv
time,close
0,10
1,12
2,11
3,12
4,
5,9
6,13
7,13
```

**Output:**

```text
index  close  highestbars
0      10     na
1      12     na
2      11     -1
3      12     0
4      na     -1
5      9      -2
6      13     0
7      13     0
```

**Pine Script:** Pine also has a one-argument form, `ta.highestbars(length)`, that
searches `high`. Tea always takes `source`.
