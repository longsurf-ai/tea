Highest value: the maximum of the last `length` values of `source`.

```tea
ta.highest(float source, int length)
```

| Parameter | Type    | Description                                                      |
| --------- | ------- | ---------------------------------------------------------------- |
| `source`  | `float` | Series to search, usually [`high`](../price-and-volume.md#high). |
| `length`  | `int`   | Number of bars in the window, at least 1.                        |

**Returns:** `float`: the highest value in the window.

The window includes the current bar. Values that are `na` are left out. To
compare with earlier bars only, read the result's history:

```tea
upper = ta.highest(high, 20)
emit "breakout" close > upper[1]
```

**Formula**

$$
\mathrm{highest}_t = \max_{i \in K_t} \mathit{source}_{t-i}
\quad\text{where}\quad
K_t = \{\, i : 0 \le i < \mathit{length},
\ \mathit{source}_{t-i} \ne \text{na} \,\}
$$

**Warm-up and na:** `na` on the first `length - 1` bars, and when every value in the
window is `na`.

**Example:** The highest close of the last 3 bars. The first two bars are `na`, and the
missing close at index 4 is left out of the windows that hold it.

```tea
emit "close" close
emit "highest" ta.highest(close, 3)
```

```csv
time,close
0,10
1,12
2,11
3,9
4,
5,8
6,13
7,10
```

**Output:**

```text
index  close  highest
0      10     na
1      12     na
2      11     12
3      9      12
4      na     11
5      8      9
6      13     13
7      10     13
```

**Pine Script:** Pine also has a one-argument form, `ta.highest(length)`, that
searches `high`. Tea always takes `source`.
