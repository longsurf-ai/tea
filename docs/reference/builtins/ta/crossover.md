Crossover: `true` on the bar where `source1` moves from at or below `source2` to above it.

```tea
ta.crossover(float source1, float source2)
```

| Parameter | Type    | Description                                         |
| --------- | ------- | --------------------------------------------------- |
| `source1` | `float` | Series that crosses, such as a fast moving average. |
| `source2` | `float` | Series or fixed level that `source1` crosses.       |

**Returns:** `bool`: `true` on the bar of the cross, otherwise `false`.

Equality counts as below on the previous bar but not as above on the
current one, so `source1` touching `source2` and moving back above it is a
cross.

**Formula**

$$
\mathrm{crossover}_t =
(\mathit{source1}_t > \mathit{source2}_t)
\land
(\mathit{source1}_{t-1} \le \mathit{source2}_{t-1})
$$

**Warm-up and na:** `false` on the first bar. A comparison with `na` is `false`, so the
result is also `false` on a bar where `source1` or `source2` is `na` and on
the bar after it: a cross that spans an `na` bar is not reported.

**Example:** The close crosses above 50 at indices 2 and 5; at index 5 it moves back
above after touching 50 at index 4. The rise from 48 to 53 is not reported,
because the close between them, at index 7, is missing.

```tea
emit "close" close
emit "crossover" ta.crossover(close, 50)
```

```csv
time,close
0,49
1,50
2,51
3,52
4,50
5,51
6,48
7,
8,53
9,54
```

**Output:**

```text
index  close  crossover
0      49     false
1      50     false
2      51     true
3      52     false
4      50     false
5      51     true
6      48     false
7      na     false
8      53     false
9      54     false
```
