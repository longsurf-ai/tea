True on the bar where `source1` moves above `source2`.

```tea
ta.crossover(source1, source2)
```

| Parameter | Description                    |
| --------- | ------------------------------ |
| `source1` | Series that crosses.           |
| `source2` | Series or level being crossed. |

**Returns:** `true` on the crossing bar, otherwise `false`.

It is `source1 > source2` on this bar and `source1 <= source2` on the
previous bar. Equality on the current bar is not a cross, and a comparison
with `na` is `false`, so the result is `false` on the first bar.

```tea
fast = ta.ema(close, 9)
slow = ta.ema(close, 21)
emit "crossedUp" ta.crossover(fast, slow)
emit "crossedLevel" ta.crossover(close, 100.0)
```
