Number of bars since `condition` was last `true`.

```tea
ta.barssince(condition)
```

| Parameter   | Description         |
| ----------- | ------------------- |
| `condition` | Condition to track. |

**Returns:** `0` on a bar where `condition` is `true`, then `1`, `2` and so on; `na` until `condition` is first `true`.
