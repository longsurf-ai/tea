Bars since a condition: the number of bars since `condition` was last `true`.

```tea
ta.barssince(bool condition)
```

| Parameter   | Type   | Description                                          |
| ----------- | ------ | ---------------------------------------------------- |
| `condition` | `bool` | Condition to track, a `bool` such as `close > open`. |

**Returns:** `int`: `0` on a bar where `condition` is `true`, otherwise one more than on the previous bar.

**Formula**

$$
\mathrm{barssince}_t =
\begin{cases}
0 & \text{if } \mathit{condition}_t \\
\mathrm{barssince}_{t-1} + 1 & \text{otherwise}
\end{cases}
$$

**Warm-up and na:** `na` until the first bar where `condition` is `true`, and never `na`
after it.

**Example:** It is `na` until the close first rises above 50 at index 2. The missing
close at index 5 is not above 50, so the count goes on.

```tea
emit "close" close
emit "barssince" ta.barssince(close > 50)
```

```csv
time,close
0,48
1,49
2,52
3,51
4,47
5,
6,46
7,53
8,49
```

**Output:**

```text
index  close  barssince
0      48     na
1      49     na
2      52     0
3      51     0
4      47     1
5      na     2
6      46     3
7      53     0
8      49     1
```
