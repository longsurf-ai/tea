Volume traded at each price over a range of bars, as returned by [`ta.volumeProfile`](./volumeProfile.md).

```tea
type VolumeByPrice
```

| Field               | Description                                                                   |
| ------------------- | ----------------------------------------------------------------------------- |
| `float low`         | Bottom of the first row: the lowest low counted.                              |
| `float step`        | Height of every row.                                                          |
| `array<float> up`   | Volume of rising bars, those closing at or above their open, in each row.     |
| `array<float> down` | Volume of falling bars in each row.                                           |
| `int poc`           | Row with the most volume, the point of control; the lowest such row on a tie. |
| `int valueLow`      | Lowest row of the value area.                                                 |
| `int valueHigh`     | Highest row of the value area.                                                |

Row `i` covers the prices from `low + i * step` to `low + (i + 1) * step`.
The arrays hold one value per row, the bottom row first. An empty profile,
before any bar with a price range has been added, has no rows and is `na`
everywhere else.
