Intraday intensity index of the current bar: where [`close`](../price-and-volume.md#close) sits between [`low`](../price-and-volume.md#low) and [`high`](../price-and-volume.md#high), times [`volume`](../price-and-volume.md#volume).

```tea
series float ta.iii
```

It is `(2 * close - high - low) / (high - low) * volume`; `na` when `high`
equals `low`.
