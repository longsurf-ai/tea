Offset to the lowest value: `0` when the minimum of the last `length` values of `source` is on the current bar, `-1` when it is on the previous bar, and so on.

```tea
ta.lowestbars(float source, int length)
```

| Parameter | Type    | Description                                                    |
| --------- | ------- | -------------------------------------------------------------- |
| `source`  | `float` | Series to search, usually [`low`](../price-and-volume.md#low). |
| `length`  | `int`   | Number of bars in the window, at least 1.                      |

**Returns:** `int`: the offset, from `1 - length` to `0`.

`bar_index + ta.lowestbars(source, length)` is the bar index of the lowest
value. Ties go to the most recent bar. Values that are `na` are left out.

**Formula**

$$
\begin{aligned}
\mathrm{lowestbars}_t &= -\min \Big\{\, i \in K_t :
\mathit{source}_{t-i} = \min_{j \in K_t} \mathit{source}_{t-j} \,\Big\} \\
\text{where}\quad K_t &= \{\, i : 0 \le i < \mathit{length},
\ \mathit{source}_{t-i} \ne \text{na} \,\}
\end{aligned}
$$

**Warm-up and na:** `na` on the first `length - 1` bars, and when every value in the
window is `na`.

**Example:** At index 3 the close of 8 ties with the one two bars back, and the most
recent wins. At index 5 the lowest close is two bars back; the missing close
at index 4 is left out.

```tea
emit "close" close
emit "lowestbars" ta.lowestbars(close, 3)
```

```csv
time,close
0,10
1,8
2,9
3,8
4,
5,11
6,7
7,7
```

**Output:**

```text
index  close  lowestbars
0      10     na
1      8      na
2      9      -1
3      8      0
4      na     -1
5      11     -2
6      7      0
7      7      0
```

**Pine Script:** Pine also has a one-argument form, `ta.lowestbars(length)`, that
searches `low`. Tea always takes `source`.
