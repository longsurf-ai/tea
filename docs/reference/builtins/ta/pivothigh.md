Value of a pivot high, reported `rightbars` bars after it, otherwise `na`.

```tea
ta.pivothigh(source, int leftbars, int rightbars)
```

| Parameter   | Type  | Description                                                                                   |
| ----------- | ----- | --------------------------------------------------------------------------------------------- |
| `source`    |       | Series to search, usually [`high`](../price-and-volume.md#high).                              |
| `leftbars`  | `int` | Number of bars before the pivot that must be lower.                                           |
| `rightbars` | `int` | Number of bars after the pivot that must be lower; the pivot is reported this many bars late. |

**Returns:** `source[rightbars]` on a bar that confirms a pivot high, otherwise `na`.

The value `rightbars` bars ago is a pivot high when it is strictly higher
than each of the `leftbars` values before it and the `rightbars` values after
it. Values that are `na`, including bars before the first, do not prevent a
pivot, so one can be reported with fewer than `leftbars` bars on its left.

```tea
pivot = ta.pivothigh(high, 5, 5)
emit "pivotHigh" pivot
emit "pivotBar" na(pivot) ? na : bar_index - 5 // bar index of the pivot itself
```
