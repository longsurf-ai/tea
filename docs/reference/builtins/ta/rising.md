Rising: `true` when `source` is greater than each of its previous `length` values.

```tea
ta.rising(float source, int length)
```

| Parameter | Type    | Description                                                      |
| --------- | ------- | ---------------------------------------------------------------- |
| `source`  | `float` | Series to test, such as [`close`](../price-and-volume.md#close). |
| `length`  | `int`   | Number of previous bars to compare with, at least 1.             |

**Returns:** `bool`: `true` when `source` is greater than every known previous value in the window, otherwise `false`.

Each previous value is compared with the current one, so the values in
between need not rise bar by bar. Previous values that are `na` are left
out.

**Formula**

$$
\begin{aligned}
\mathrm{rising}_t &= (\mathit{source}_t \ne \text{na})
\land (K_t \ne \varnothing) \\
&\quad \land \Big(\mathit{source}_t > \max_{i \in K_t} \mathit{source}_{t-i}\Big) \\
\text{where}\quad K_t &= \{\, i : 1 \le i \le \mathit{length},
\ \mathit{source}_{t-i} \ne \text{na} \,\}
\end{aligned}
$$

**Warm-up and na:** `false` on the first `length` bars. After that, `false` when
`source` is `na` or every previous value in the window is `na`.

**Example:** Index 3 is `true` although the close fell at index 2, while index 4 is
`false` because 13 is not greater than 13. At index 6 the missing close is
left out, so 14 is compared with 13 only.

```tea
emit "close" close
emit "rising" ta.rising(close, 2)
```

```csv
time,close
0,10
1,12
2,11
3,13
4,13
5,
6,14
7,15
```

**Output:**

```text
index  close  rising
0      10     false
1      12     false
2      11     false
3      13     true
4      13     false
5      na     false
6      14     true
7      15     true
```
