Keltner Channel width: the distance between the upper and lower [`ta.kc`](./kc.md) bands as a fraction of the middle line.

```tea
ta.kcw(
    float series,
    simple int length,
    simple float mult,
    simple bool useTrueRange = true
)
```

| Parameter      | Type           | Default | Description                                                                                                                                                             |
| -------------- | -------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `series`       | `float`        |         | Series to average, usually [`close`](../price-and-volume.md#close).                                                                                                     |
| `length`       | `simple int`   |         | Smoothing length in bars for both averages, at least 1. It must be known when the script starts, such as a constant or an input.                                        |
| `mult`         | `simple float` |         | Band distance in average ranges, such as `2`. It must be known when the script starts, such as a constant or an input.                                                  |
| `useTrueRange` | `simple bool`  | `true`  | `true`, the default, measures each bar's range with `ta.tr(false)`; `false` uses `high - low`. It must be known when the script starts, such as a constant or an input. |

**Returns:** `float`: the width as a fraction of the middle line.

Unlike [`ta.bbw`](./bbw.md), it is not multiplied by `100`.

**Formula**

$$
\begin{aligned}
\mathrm{kcw}_t &= \frac{\mathit{upper}_t - \mathit{lower}_t}{\mathit{middle}_t} \\
\text{where}\quad [\mathit{middle}, \mathit{upper}, \mathit{lower}]
&= \mathrm{kc}(\mathit{series}, \mathit{length}, \mathit{mult},
\mathit{useTrueRange})
\end{aligned}
$$

**Warm-up and na:** `na` where [`ta.kc`](./kc.md) gives `na` bands, as on the first bar when
`useTrueRange` is `true`, and where the middle line is `0`.

**Example:** At index 1 the bands are 17 and 5 around a middle line of 11, so the width
is `12 / 11`. With `useTrueRange` `false` the first bar has a width, and the
widths are smaller because `high - low` leaves out the gaps from the
previous close.

```tea
emit "high" high
emit "low" low
emit "close" close
emit "kcw" ta.kcw(close, 3, 2)
emit "kcwHighLow" ta.kcw(close, 3, 2, false)
```

```csv
0,11,9,10
1,13,11,12
2,12,10,11

4,14,12,13
5,16,14,15
```
