Keltner Channel width as a fraction of the middle line.

```tea
ta.kcw(source, int length, mult, useTrueRange = true)
```

| Parameter      | Type  | Default | Description                                                                          |
| -------------- | ----- | ------- | ------------------------------------------------------------------------------------ |
| `source`       |       |         | Series to average, usually [`close`](../price-and-volume.md#close).                  |
| `length`       | `int` |         | Smoothing length in bars.                                                            |
| `mult`         |       |         | Band distance in average ranges.                                                     |
| `useTrueRange` |       | `true`  | `true` measures each bar's range with [`ta.tr`](./tr.md); `false` uses `high - low`. |

**Returns:** The width as a ratio; `na` when the middle line is `0`.

It is `(upper - lower) / middle` for the channels [`ta.kc`](./kc.md) returns with
the same arguments. Unlike [`ta.bbw`](./bbw.md), it is not multiplied by `100`.
