Wilder's moving average of `source`, the smoothing behind [`ta.rsi`](./rsi.md), [`ta.atr`](./atr.md) and [`ta.dmi`](./dmi.md).

```tea
ta.rma(source, int length)
```

| Parameter | Type  | Description                                 |
| --------- | ----- | ------------------------------------------- |
| `source`  |       | Series to average.                          |
| `length`  | `int` | Smoothing length in bars, a positive `int`. |

**Returns:** The average; `na` until `length` values that are not `na` have arrived.

It starts as the simple average of the first `length` values that are not
`na`, then moves toward each new value by `1 / length` of the difference. An
`na` value is skipped: it does not count toward the first `length` values,
and later the previous result is kept.
