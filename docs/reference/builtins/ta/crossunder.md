Crossunder: `true` on the bar where `source1` moves from at or above `source2` to below it.

```tea
ta.crossunder(float source1, float source2)
```

| Parameter | Type    | Description                                         |
| --------- | ------- | --------------------------------------------------- |
| `source1` | `float` | Series that crosses, such as a fast moving average. |
| `source2` | `float` | Series or fixed level that `source1` crosses.       |

**Returns:** `bool`: `true` on the bar of the cross, otherwise `false`.

Equality counts as above on the previous bar but not as below on the
current one, so `source1` touching `source2` and moving back below it is a
cross.

**Formula**

$$
\mathrm{crossunder}_t =
(\mathit{source1}_t < \mathit{source2}_t)
\land
(\mathit{source1}_{t-1} \ge \mathit{source2}_{t-1})
$$

**Warm-up and na:** `false` on the first bar. A comparison with `na` is `false`, so the
result is also `false` on a bar where `source1` or `source2` is `na` and on
the bar after it: a cross that spans an `na` bar is not reported.

**Example:** The close crosses below 50 at indices 2 and 5; at index 5 it moves back
below after touching 50 at index 4. The fall from 52 to 47 is not reported,
because the close between them, at index 7, is missing.

```tea
emit "close" close
emit "crossunder" ta.crossunder(close, 50)
```

```csv
time,close
0,51
1,50
2,49
3,48
4,50
5,49
6,52
7,
8,47
9,46
```

**Output:**

```text
index  close  crossunder
0      51     false
1      50     false
2      49     true
3      48     false
4      50     false
5      49     true
6      52     false
7      na     false
8      47     false
9      46     false
```
