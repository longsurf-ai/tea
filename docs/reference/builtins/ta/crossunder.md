True on the bar where `source1` moves below `source2`.

```tea
ta.crossunder(source1, source2)
```

| Parameter | Description                    |
| --------- | ------------------------------ |
| `source1` | Series that crosses.           |
| `source2` | Series or level being crossed. |

**Returns:** `true` on the crossing bar, otherwise `false`.

It is `source1 < source2` on this bar and `source1 >= source2` on the
previous bar. Equality on the current bar is not a cross, and the result is
`false` on the first bar.
