Momentum: `source` minus its value `length` bars ago.

```tea
ta.mom(float source, int length)
```

| Parameter | Type    | Description                                                         |
| --------- | ------- | ------------------------------------------------------------------- |
| `source`  | `float` | Series to compare, usually [`close`](../price-and-volume.md#close). |
| `length`  | `int`   | Number of bars back, at least 1.                                    |

**Returns:** `float`: the difference.

It is the same as [`ta.change`](./change.md) with `length` required, except that an
`int` source gives a `float` result.

**Formula**

$$
\mathrm{mom}_t = \mathit{source}_t - \mathit{source}_{t-\mathit{length}}
$$

**Warm-up and na:** `na` on the first `length` bars, and when either value is `na`.

**Example:** Momentum over 3 bars. The first value, at index 3, is `14 - 10`.

```tea
emit "close" close
emit "mom" ta.mom(close, 3)
```

```csv
time,close
0,10
1,12
2,15
3,14
4,18
5,20
6,19
```

**Output:**

```text
index  close  mom
0      10     na
1      12     na
2      15     na
3      14     4
4      18     6
5      20     5
6      19     5
```
