True range of the current bar.

```tea
ta.tr(handle_na = true)
```

| Parameter   | Default | Description                                                                                                                                           |
| ----------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `handle_na` | `true`  | What to return when the previous [`close`](../price-and-volume.md#close) is `na`, as on the first bar: `true` gives `high - low`, `false` gives `na`. |

**Returns:** The true range, or the `handle_na` result when the previous close is `na`.

It is the largest of `high - low`, `math.abs(high - close[1])` and
`math.abs(low - close[1])`, using [`high`](../price-and-volume.md#high), [`low`](../price-and-volume.md#low) and
[`close`](../price-and-volume.md#close).
