Lowest value: the minimum of the last `length` values of `source`.

```tea
ta.lowest(float source, int length)
```

| Parameter | Type    | Description                                                    |
| --------- | ------- | -------------------------------------------------------------- |
| `source`  | `float` | Series to search, usually [`low`](../price-and-volume.md#low). |
| `length`  | `int`   | Number of bars in the window, at least 1.                      |

**Returns:** `float`: the lowest value in the window.

The window includes the current bar. Values that are `na` are left out.

**Formula**

$$
\mathrm{lowest}_t = \min_{i \in K_t} \mathit{source}_{t-i}
\quad\text{where}\quad
K_t = \{\, i : 0 \le i < \mathit{length},
\ \mathit{source}_{t-i} \ne \text{na} \,\}
$$

**Warm-up and na:** `na` on the first `length - 1` bars, and when every value in the
window is `na`.

**Example:** The lowest close of the last 3 bars. The first two bars are `na`, and the
missing close at index 4 is left out of the windows that hold it.

```tea
emit "close" close
emit "lowest" ta.lowest(close, 3)
```

```csv
time,close
0,10
1,8
2,9
3,11
4,
5,12
6,7
7,10
```

**Output:**

```text
index  close  lowest
0      10     na
1      8      na
2      9      8
3      11     8
4      na     9
5      12     11
6      7      7
7      10     7
```

**Pine Script:** Pine also has a one-argument form, `ta.lowest(length)`, that searches
`low`. Tea always takes `source`.

**See also:** [`ta.highest`](./highest.md), [`ta.lowestbars`](./lowestbars.md)
