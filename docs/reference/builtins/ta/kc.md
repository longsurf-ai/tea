Keltner Channels: an exponential average of `source` with bands `mult` average ranges above and below it.

```tea
ta.kc(source, int length, mult, useTrueRange = true)
```

| Parameter      | Type  | Default | Description                                                                                                             |
| -------------- | ----- | ------- | ----------------------------------------------------------------------------------------------------------------------- |
| `source`       |       |         | Series to average, usually [`close`](../price-and-volume.md#close).                                                     |
| `length`       | `int` |         | Smoothing length in bars.                                                                                               |
| `mult`         |       |         | Band distance in average ranges.                                                                                        |
| `useTrueRange` |       | `true`  | `true` measures each bar's range with `ta.tr(false)`, so the range is `na` on the first bar; `false` uses `high - low`. |

**Returns:** A tuple `[middle, upper, lower]`.

The middle line is `ta.ema(source, length)`. The distance is `mult` times the
[`ta.ema`](./ema.md), over `length` bars, of each bar's [`ta.tr`](./tr.md), or of
`high - low` when `useTrueRange` is `false`. The averages start on the first
bar, so there is no warm-up `na`.

```tea
[middle, upper, lower] = ta.kc(close, 20, 1.5)
emit "middle" middle
emit "upper" upper
emit "lower" lower
```
