Linear regression curve: the value of the least-squares line through the last `length` values of `source`, read `offset` bars back.

```tea
ta.linreg(float source, int length, simple int offset)
```

| Parameter | Type         | Description                                                                                                                                                       |
| --------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `source`  | `float`      | Series to fit, usually [`close`](../price-and-volume.md#close).                                                                                                   |
| `length`  | `int`        | Number of bars in the window, at least 2.                                                                                                                         |
| `offset`  | `simple int` | Bars back from the current bar at which to read the line; 0 reads it on the current bar. It must be known when the script starts, such as a constant or an input. |

**Returns:** `float`: the value of the fitted line.

The line is fitted with the oldest value at position 0 and the current
value at position `length - 1`, then read at position
`length - 1 - offset`. An `offset` of 0 gives the line's value on the
current bar, also known as the least-squares moving average, and a negative
`offset` extends the line past it. An `na` value in the window makes the
result `na`.

**Formula**

$$
\begin{aligned}
\mathrm{linreg}_t &= a + b \cdot (n - 1 - \mathit{offset}) \\
b &= \frac
{n \sum_j j \cdot y_j - \left(\sum_j j\right) \left(\sum_j y_j\right)}
{n \sum_j j^2 - \left(\sum_j j\right)^2},
\qquad a = \frac{\sum_j y_j - b \sum_j j}{n} \\
\text{where}\quad n &= \mathit{length},
\quad y_j = \mathit{source}_{t-n+1+j},
\quad j = 0, \dots, n - 1
\end{aligned}
$$

**Warm-up and na:** `na` on the first `length - 1` bars, and while any value in the
window is `na`.

**Example:** At index 2 the closes 10, 14 and 12, at positions 0 to 2, fit the line
`11 + position`. It reads 13 on the current bar (`offset` 0) and 14 one bar
ahead (`offset` -1). The close at index 6 is missing, so indexes 6 to 8 are
`na`.

```tea
emit "close" close
emit "fit" ta.linreg(close, 3, 0)
emit "ahead" ta.linreg(close, 3, -1)
```
