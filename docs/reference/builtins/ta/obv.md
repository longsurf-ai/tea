On-balance volume: the running total of [`volume`](../price-and-volume.md#volume), added on bars where [`close`](../price-and-volume.md#close) rose and subtracted on bars where it fell.

```tea
series float ta.obv
```

It is `ta.cum(math.sign(ta.change(close)) * volume)`, computed once per bar
for the whole script.
