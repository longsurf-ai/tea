Spreads the volume of every bar since the last reset across price rows.

```tea
ta.volumeProfile(
    array<float> highs,
    array<float> lows,
    array<float> volumes,
    array<bool> rising,
    bool reset,
    int rows = 24,
    float valueArea = 70.0,
    bool compute = true
)
```

| Parameter   | Type           | Default | Description                                                                                     |
| ----------- | -------------- | ------- | ----------------------------------------------------------------------------------------------- |
| `highs`     | `array<float>` |         | High of each bar added on this call.                                                            |
| `lows`      | `array<float>` |         | Low of each bar added on this call.                                                             |
| `volumes`   | `array<float>` |         | Volume of each bar added on this call.                                                          |
| `rising`    | `array<bool>`  |         | Whether each bar added on this call closed at or above its open.                                |
| `reset`     | `bool`         |         | Whether to finish the current profile, returning it, and start a new one with this call's bars. |
| `rows`      | `int`          | `24`    | Number of price rows, a positive `int`.                                                         |
| `valueArea` | `float`        | `70.0`  | Share of the volume, in percent, that the value area holds.                                     |
| `compute`   | `bool`         | `true`  | Whether to build the profile this call returns; `false` returns an empty profile.               |

**Returns:** The finished profile on a reset, else the profile so far.

Each call adds a group of bars, such as the lower-timeframe bars inside the
current chart bar from [`request.security_lower_tf`](../request.md#security_lower_tf). The range from the
lowest low to the highest high is cut into `rows` equal rows. Each bar's
volume is spread over the rows its low-to-high range covers, in proportion to
the overlap; a bar whose high equals its low puts all its volume in one row.
The value area grows from the point of control one row at a time, taking the
neighbor with more volume (the upper one on a tie), until it holds
`valueArea` percent of the volume.

Volume is kept in four fine cells per row, so a call costs only the cells
its bars touch. Rows are built from the cells, which splits a cell lying
across a row boundary in proportion: a row can differ from an exact split
by part of one cell's volume, and the total never changes. Building the rows
is the costly part, so pass `compute = false` on bars that do not need the
profile; their bars still count.

With `reset`, the call returns the profile that just finished, of every bar
before this call, and this call's bars start the next one. A period's profile
is therefore ready on the first bar of the next period. The four arrays
describe the same bars in the same order; bars with an `na` high or low are
skipped and an `na` volume counts as `0`. To profile every bar of the chart,
pass one-element arrays and never reset:

```tea
profile = ta.volumeProfile(array.from(high), array.from(low), array.from(volume), array.from(close >= open), false)
emit "poc" profile.low + (profile.poc + 0.5) * profile.step
```
