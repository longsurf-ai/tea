Spreads the volume of every bar added since the last reset across price rows.

```tea
ta.volumeProfile(
    array<float> highs,
    array<float> lows,
    array<float> volumes,
    array<bool> rising,
    bool reset,
    int rows = 24,
    float valueArea = 70.0
)
```

| Parameter   | Type           | Default | Description                                                              |
| ----------- | -------------- | ------- | ------------------------------------------------------------------------ |
| `highs`     | `array<float>` |         | High of each bar added on this call.                                     |
| `lows`      | `array<float>` |         | Low of each bar added on this call.                                      |
| `volumes`   | `array<float>` |         | Volume of each bar added on this call.                                   |
| `rising`    | `array<bool>`  |         | Whether each bar added on this call closed at or above its open.         |
| `reset`     | `bool`         |         | Whether to drop the bars added before this call and start a new profile. |
| `rows`      | `int`          | `24`    | Number of price rows, a positive `int`.                                  |
| `valueArea` | `float`        | `70.0`  | Share of the volume, in percent, that the value area holds.              |

**Returns:** The profile of the bars added since the last reset.

Each call adds a group of bars, such as the lower-timeframe bars inside the
current chart bar from [`request.security_lower_tf`](../request.md#security_lower_tf), and returns the
profile of every bar added since the last `reset`. The range from the lowest
low to the highest high is cut into `rows` equal rows. Each bar's volume is
spread over the rows its low-to-high range covers, in proportion to the
overlap; a bar whose high equals its low puts all its volume in one row.
The value area grows from the point of control one row at a time, taking the
neighbor with more volume (the upper one on a tie), until it holds
`valueArea` percent of the volume.

The four arrays describe the same bars in the same order; bars with an `na`
high or low are skipped and an `na` volume counts as `0`. To profile the
chart's own bars, pass one-element arrays:

```tea
profile = ta.volumeProfile(array.from(high), array.from(low), array.from(volume), array.from(close >= open), barstate.isfirst)
emit "poc" profile.low + (profile.poc + 0.5) * profile.step
```
