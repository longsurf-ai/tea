Simple moving average: the mean of the last `length` values of `source`.

```tea
ta.sma(float source, int length)
```

| Parameter | Type    | Description                                                         |
| --------- | ------- | ------------------------------------------------------------------- |
| `source`  | `float` | Series to average, usually [`close`](../price-and-volume.md#close). |
| `length`  | `int`   | Number of bars in the window, at least 1.                           |

**Returns:** `float`: the mean of the window.

Every value in the window has the same weight. Values that are `na` are
left out, so the mean is over the window's other values.

**Formula**

$$
\mathrm{sma}_t = \frac{1}{|K_t|} \sum_{i \in K_t} \mathit{source}_{t-i}
\quad\text{where}\quad
K_t = \{\, i : 0 \le i < \mathit{length},
\ \mathit{source}_{t-i} \ne \text{na} \,\}
$$

**Warm-up and na:** `na` on the first `length - 1` bars, and when every value in the
window is `na`.

**Example:** A 3-bar average. The first two bars are `na`. The close is missing at
index 4, so the windows that hold it average their two known values.

```tea
emit "close" close
emit "sma" ta.sma(close, 3)
```

```csv
time,close
0,10
1,11
2,12
3,13
4,
5,15
6,16
7,17
```

**Output:**

```text
index  close  sma
0      10     na
1      11     na
2      12     11
3      13     12
4      na     12.5
5      15     14
6      16     15.5
7      17     16
```
