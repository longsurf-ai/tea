Average true range (ATR): the smoothed average of recent true ranges, a measure of volatility in price units.

```tea
ta.atr(simple int length)
```

| Parameter | Type         | Description                                                                                                    |
| --------- | ------------ | -------------------------------------------------------------------------------------------------------------- |
| `length`  | `simple int` | Smoothing length in bars, at least 1. It must be known when the script starts, such as a constant or an input. |

**Returns:** `float`: the average true range.

It is [`ta.rma`](./rma.md), Wilder's moving average, of `ta.tr(true)` over
`length` bars: the simple average of the first `length` true ranges, after
which each bar moves the average `1 / length` of the way toward the new true
range ([`ta.tr`](./tr.md)). The first bar's true range is `high - low`.

**Formula**

$$
\mathrm{atr}_t = \mathrm{rma}(\mathrm{tr}(\text{true}), \mathit{length})_t
$$

**Warm-up and na:** `na` until `length` true ranges that are not `na` have arrived: the
first `length - 1` bars when no high or low is missing. After that, a bar
whose true range is `na`, because its high or low is `na`, keeps the
previous value.

**Example:** Index 3 averages the first four true ranges, `(2 + 3 + 4 + 3) / 4 = 3`. The
gap at index 4 gives a true range of 7, and the ATR moves a quarter of the
way to it, `3 + (7 - 3) / 4 = 4`; the missing high at index 5 leaves it at 4.

```tea
emit "high" high
emit "low" low
emit "close" close
emit "tr" ta.tr(true)
emit "atr" ta.atr(4)
```
