Directional movement index: the +DI and -DI lines and the ADX trend strength, each from `0` to `100`.

```tea
ta.dmi(int diLength, int adxSmoothing)
```

| Parameter      | Type  | Description                                         |
| -------------- | ----- | --------------------------------------------------- |
| `diLength`     | `int` | Smoothing length for +DI and -DI, a positive `int`. |
| `adxSmoothing` | `int` | Smoothing length for ADX, a positive `int`.         |

**Returns:** A tuple `[plusDI, minusDI, adx]`. +DI and -DI are `na` for the first `diLength - 1` bars, and ADX for the first `diLength + adxSmoothing - 2` bars.

On each bar, the upward move of [`high`](../price-and-volume.md#high) counts toward +DI and the
downward move of [`low`](../price-and-volume.md#low) toward -DI, whichever is larger and positive.
Each is smoothed with [`ta.rma`](./rma.md) over `diLength` bars and divided by the
true range ([`ta.tr`](./tr.md)) smoothed the same way. ADX is `100` times the
[`ta.rma`](./rma.md), over `adxSmoothing` bars, of the absolute difference between
+DI and -DI divided by their sum.

```tea
[plusDI, minusDI, adx] = ta.dmi(14, 14)
emit "+DI" plusDI
emit "-DI" minusDI
emit "ADX" adx
```
