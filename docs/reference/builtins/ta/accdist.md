Accumulation/distribution: the running total of each bar's volume, weighted by where [`close`](../price-and-volume.md#close) sits between [`low`](../price-and-volume.md#low) and [`high`](../price-and-volume.md#high).

```tea
series float ta.accdist
```

Each bar adds `(2 * close - low - high) / (high - low) * volume`, or `0` when
`high` equals `low`.
