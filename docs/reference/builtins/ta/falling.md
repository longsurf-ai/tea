Falling: `true` when `source` is less than each of its previous `length` values.

```tea
ta.falling(float source, int length)
```

| Parameter | Type    | Description                                                      |
| --------- | ------- | ---------------------------------------------------------------- |
| `source`  | `float` | Series to test, such as [`close`](../price-and-volume.md#close). |
| `length`  | `int`   | Number of previous bars to compare with, at least 1.             |

**Returns:** `bool`: `true` when `source` is less than every known previous value in the window, otherwise `false`.

Each previous value is compared with the current one, so the values in
between need not fall bar by bar. Previous values that are `na` are left
out.

**Formula**

$$
\begin{aligned}
\mathrm{falling}_t &= (\mathit{source}_t \ne \text{na})
\land (K_t \ne \varnothing) \\
&\quad \land \Big(\mathit{source}_t < \min_{i \in K_t} \mathit{source}_{t-i}\Big) \\
\text{where}\quad K_t &= \{\, i : 1 \le i \le \mathit{length},
\ \mathit{source}_{t-i} \ne \text{na} \,\}
\end{aligned}
$$

**Warm-up and na:** `false` on the first `length` bars. After that, `false` when
`source` is `na` or every previous value in the window is `na`.

**Example:** Index 3 is `true` although the close rose at index 2, while index 4 is
`false` because 7 is not less than 7. At index 6 the missing close is left
out, so 6 is compared with 7 only.

```tea
emit "close" close
emit "falling" ta.falling(close, 2)
```

```csv
time,close
0,10
1,8
2,9
3,7
4,7
5,
6,6
7,5
```

**Output:**

```text
index  close  falling
0      10     false
1      8      false
2      9      false
3      7      true
4      7      false
5      na     false
6      6      true
7      5      true
```
