Price-volume trend: the running total of each bar's [`volume`](../price-and-volume.md#volume), weighted by the relative change of [`close`](../price-and-volume.md#close).

```tea
series float ta.pvt
```

It is `ta.cum(ta.change(close) / close[1] * volume)`.
