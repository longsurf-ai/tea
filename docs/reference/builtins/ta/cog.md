Center of gravity (COG) of the last `length` values of `source`.

```tea
ta.cog(float source, int length)
```

| Parameter | Type    | Description                                                         |
| --------- | ------- | ------------------------------------------------------------------- |
| `source`  | `float` | Series to measure, usually [`close`](../price-and-volume.md#close). |
| `length`  | `int`   | Number of bars in the window, at least 1.                           |

**Returns:** `float`: the center of gravity.

It is minus the average bar position in the window, from `1` for the
current bar to `length` for the oldest, with each position weighted by its
value. Values that are `na` are left out, and the others keep their
positions. For positive values it lies between `-length` and `-1`:
`length` equal values give `-(length + 1) / 2`, and larger newer values
move it toward `-1`.

**Formula**

$$
\begin{aligned}
\mathrm{cog}_t &= -\frac{\sum_{i \in K_t} (i + 1) \cdot \mathit{source}_{t-i}}
{\sum_{i \in K_t} \mathit{source}_{t-i}} \\
\text{where}\quad K_t &= \{\, i : 0 \le i < \mathit{length},
\ \mathit{source}_{t-i} \ne \text{na} \,\}
\end{aligned}
$$

**Warm-up and na:** `na` on the first `length - 1` bars, when every value in the window
is `na`, and when the known values sum to `0`.

**Example:** Equal closes give -2 at index 2, and the 20 moves the value to -1.75 while
it is newest (index 3) and to -2.25 while it is oldest (index 5). At index 6
the missing close is left out: `-(2 * 10 + 3 * 10) / 20` is -2.5.

```tea
emit "close" close
emit "cog" ta.cog(close, 3)
```

```text

1      10     na

4      10     -2

7      10     -2
```
