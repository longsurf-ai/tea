Supertrend: a trailing line on one side of price, and the trend direction.

```tea
ta.supertrend(factor, int atrPeriod)
```

| Parameter   | Type  | Description                                           |
| ----------- | ----- | ----------------------------------------------------- |
| `factor`    |       | Band distance in average true ranges.                 |
| `atrPeriod` | `int` | Length of the [`ta.atr`](./atr.md), a positive `int`. |

**Returns:** A tuple `[line, direction]`. `direction` is `-1` in an uptrend, where `line` is the lower band below price, and `1` in a downtrend, where `line` is the upper band above price; it is `1` until the ATR has a previous value. `line` is `0` on the first bar and `na` until the ATR has a value.

Bands sit `factor` times `ta.atr(atrPeriod)` above and below [`hl2`](../price-and-volume.md#hl2).
The lower band never falls unless the previous [`close`](../price-and-volume.md#close) was below it,
and the upper band never rises unless the previous close was above it. The
trend turns up when `close` rises above the upper band and turns down when
`close` falls below the lower band.

```tea
[line, direction] = ta.supertrend(3.0, 10)
emit "supertrend" line
emit "uptrend" direction == -1
```
