Pivot low: the value `rightbars` bars back when it is lower than the `leftbars` values before it and the `rightbars` values after it, otherwise `na`.

```tea
ta.pivotlow(float source, int leftbars, int rightbars)
```

| Parameter   | Type    | Description                                                      |
| ----------- | ------- | ---------------------------------------------------------------- |
| `source`    | `float` | Series to search, usually [`low`](../price-and-volume.md#low).   |
| `leftbars`  | `int`   | Number of bars before the pivot that must be higher, at least 0. |
| `rightbars` | `int`   | Number of bars after the pivot that must be higher, at least 0.  |

**Returns:** `float`: the pivot's value on the bar that reports it, otherwise `na`.

The pivot must be strictly lower than each of these `leftbars + rightbars`
neighbors: a tie with any of them is not a pivot. Neighbors that are `na`
are left out, but at least one must be known, unless `leftbars` and
`rightbars` are both `0`. A pivot is reported `rightbars` bars after its own
bar, so `bar_index - rightbars` is the bar index of the pivot.

**Formula**

$$
\begin{aligned}
\mathrm{pivotlow}_t &=
\begin{cases}
p_t & \text{if } (J_t \ne \varnothing \lor n = 0)
\text{ and } \mathit{source}_{t-i} > p_t \text{ for every } i \in J_t \\
\text{na} & \text{otherwise}
\end{cases} \\
p_t &= \mathit{source}_{t-\mathit{rightbars}}, \qquad
n = \mathit{leftbars} + \mathit{rightbars} \\
J_t &= \{\, i : 0 \le i \le n,\ i \ne \mathit{rightbars},
\ \mathit{source}_{t-i} \ne \text{na} \,\}
\end{aligned}
$$

**Warm-up and na:** `na` on the first `leftbars + rightbars` bars, so a value with fewer
than `leftbars` bars before it is never a pivot. After that, `na` on a bar
where the value `rightbars` bars back is `na`, or where that value has
neighbors and all of them are `na`.

**Example:** Two bars on each side, so the first four bars are `na` and the 7 at index 0,
with no bars before it, is never a pivot. Index 5 reports the 8 at index 3,
leaving out the missing low at index 4, and index 11 reports the 5 at index
9; the equal lows at indices 6 and 7 are not pivots.

```tea
emit "low" low
emit "pivotlow" ta.pivotlow(low, 2, 2)
```


**Pine Script:** Pine also has a two-argument form without `source`,
`ta.pivotlow(leftbars, rightbars)`; Tea always takes `source`. `leftbars`
and `rightbars` must be `int`, where Pine also accepts a `float`.
