See [types](../language/types.md) for the `map<K, V>` type and [memory model](../../memory-model.md) for how map values are copied and shared. Unlike Pine Script, where collections are references, a Tea collection is a value: assigning it or passing it to a function copies it, so a function that pushes to its argument leaves the caller’s collection unchanged. Every function whose first parameter is `self` can also be called as a method on the collection: `values.push(x)` is the same call as `array.push(values, x)`.

## Creating and copying

### new

Creates an empty map.

```tea
const map<K, V> map.new<K: map-key, V: storable>()
```

**Returns:** A new map with no entries.

Write the key and value types in angle brackets, as in `map.new<string, float>()`. Keys can be `int`, `float`, `bool`, `string`, `color` or an enum. A map keeps its keys in the order they were added. A variable declared as `map<string, float> prices = na` holds no map, and calling a function on it stops the run with an error.

**Example:**

```tea
latest = map.new<string, float>()
latest.put("close", close)
emit "close" latest.get("close")
emit "open" latest.get("open") // na: no such key
```

```csv
time,open,close
0,9,9
1,10,11
2,10,10
3,10,12
4,12,9
5,10,14
6,14,10
7,11,15
```

**Output:**

```text
index  close  open
0      9      na
1      11     na
2      10     na
3      12     na
4      9      na
5      14     na
6      10     na
7      15     na
```

### copy

Returns a copy of a map.

```tea
map<K, V> map.copy<K: map-key, V: storable>(
    series map<K, V> self
)
```

| Parameter | Type               | Description |
| --------- | ------------------ | ----------- |
| `self`    | `series map<K, V>` | The map.    |

**Returns:** A new map with the same entries in the same order.

Maps are values, so plain assignment already copies them. The copy is shallow: struct values still refer to the same structs.

| Parameter | Type               | Description                         |
| --------- | ------------------ | ----------------------------------- |
| `self`    | `series map<K, V>` | The map.                            |

**Returns:** The value, or the value type’s empty value (`na`, or `false` for `bool`) when the key is absent. Use [`map.contains`](./map.md#contains) to tell an absent key from a stored `na`.

Keys match by value; colors match by their channels, so `#FF0000` and `#FF0000FF` are the same key.

## Changing

### put

Stores a value under a key, replacing any value already there.

```tea
void map.put<K: map-key, V: storable>(
    series map<K, V> self,
    series K key,
    series V value
)
```

| Parameter | Type               | Description                                                          |
| --------- | ------------------ | -------------------------------------------------------------------- |
| `self`    | `series map<K, V>` | The map to update. Must be a variable or field; the call updates it. |
| `key`     | `series K`         | The key to store under. Cannot be `na`.                              |
| `value`   | `series V`         | The value to store.                                                  |

Replacing a value keeps its key’s position; a new key goes last. A collection holds at most 100,000 elements; adding a key past that stops the run with an error.

### remove
