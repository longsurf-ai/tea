Price and volume of the current row, read from input columns the host supplies.

Each name reads the input column of the same name, as [`close`](./price-and-volume.md#close)
describes. The host must supply every column a script reads, or binding the
script fails. Library files can read these names too, and no file can
redeclare or assign them.

Available in every script without an import or namespace.

| Name                | Description                                                                                |
| ------------------- | ------------------------------------------------------------------------------------------ |
| [`open`](#open)     | Opening price of the current row.                                                          |
| [`high`](#high)     | Highest price of the current row.                                                          |
| [`low`](#low)       | Lowest price of the current row.                                                           |
| [`close`](#close)   | Closing price of the current row.                                                          |
| [`volume`](#volume) | Traded volume of the current row.                                                          |
| [`hl2`](#hl2)       | Midpoint of the current row's high and low, `(high + low) / 2`.                            |
| [`hlc3`](#hlc3)     | Average of the current row's high, low and close, `(high + low + close) / 3`.              |
| [`ohlc4`](#ohlc4)   | Average of the current row's open, high, low and close, `(open + high + low + close) / 4`. |
| [`hlcc4`](#hlcc4)   | Average of the current row's high, low and doubled close, `(high + low + 2 * close) / 4`.  |

## Price and volume

### open

Opening price of the current row.

```tea
series float open
```

Reads the host-supplied `open` column, like [`close`](./price-and-volume.md#close).

### high

Highest price of the current row.

```tea

```

Reads the host-supplied `high` column, like [`close`](./price-and-volume.md#close).

### low

Lowest price of the current row.

```tea

```

Reads the host-supplied `low` column, like [`close`](./price-and-volume.md#close).

### close

Closing price of the current row.

```tea
series float close
```

Reads the `close` column of the host's input stream. A row is one item of
that stream, such as one bar, and `close` is `na` on a row where the host
supplies `NaN`. Inside a [request](../../requests.md) expression, it reads the
stream bound to that request instead.

`close[1]` is the value one row earlier and is `na` on the first row. This
computes the change from the previous row, using [`nz`](./core.md#nz) to treat the
missing first value as no change:

```tea
previous = nz(close[1], close)
emit "change" close - previous
```

### volume

Traded volume of the current row.

```tea
series float volume
```

Reads the host-supplied `volume` column, like [`close`](./price-and-volume.md#close).

### hl2

Midpoint of the current row's high and low, `(high + low) / 2`.

```tea
series float hl2
```

Tea does not compute it: it reads the host-supplied `hl2` column, like
[`close`](./price-and-volume.md#close). `tea run` derives that column from `high` and `low` when the
CSV file lacks it.
