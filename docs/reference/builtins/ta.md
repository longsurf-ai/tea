Technical-analysis functions: moving averages, oscillators, volatility bands, crosses and running statistics.

Each written call keeps its own history and state, covering only the bars on
which that call runs. Call these functions on every bar and combine their
results with conditions afterwards: a call inside an `if` branch, one arm of a
ternary, or after `and` or `or` does not run when that code is skipped, so its
window reads the skipped bars as `na` and its running state does not change on
them. A call inside a loop shares one history and state across all iterations.
See [values and control flow](../../language-guide/values-and-control-flow.md).

Most results are `na` until enough bars have arrived; each entry states when.
After that, a window function leaves out the `na` values in its window and is
`na` only when none is left. A few, such as [`ta.swma`](./ta.md#swma) and
[`ta.change`](./ta.md#change), say instead that an `na` value makes the result `na`.
The [time-series guide](../../language-guide/time-series.md) covers warm-up and
crossing rules.

```tea
// Call on every bar, then combine the result with the condition.
risingThree = ta.rising(close, 3)
emit "signal" close > open and risingThree
```

Available in every script as `ta.name` without an import.

## Moving averages

### sma

Simple moving average of the last `length` values of `source`.

```tea
ta.sma(source, int length)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to average, usually [`close`](./market-data.md#close). |
| `length`  | `int` | Number of bars, a positive `int`.                             |

**Returns:** The mean; `na` for the first `length - 1` bars and when every value in the window is `na`.

Values that are `na` are left out: the mean is over the window's other
values.

### ema

Exponential moving average of `source`.

```tea
ta.ema(source, int length)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to average, usually [`close`](./market-data.md#close). |
| `length`  | `int` | Smoothing length in bars; larger values react more slowly.    |

**Returns:** The average; `na` before the first value of `source`.

Each bar moves the average toward `source` by `2 / (length + 1)` of the
difference. It starts from the first value of `source` instead of waiting for
`length` bars, and a bar where `source` is `na` leaves it unchanged.
Compare [`ta.rma`](./ta.md#rma), which waits for `length` values.

### rma

Wilder's moving average of `source`, the smoothing behind [`ta.rsi`](./ta.md#rsi), [`ta.atr`](./ta.md#atr) and [`ta.dmi`](./ta.md#dmi).

```tea
ta.rma(source, int length)
```

| Parameter | Type  | Description                                 |
| --------- | ----- | ------------------------------------------- |
| `source`  |       | Series to average.                          |
| `length`  | `int` | Smoothing length in bars, a positive `int`. |

**Returns:** The average; `na` until `length` values that are not `na` have arrived.

It starts as the simple average of the first `length` values that are not
`na`, then moves toward each new value by `1 / length` of the difference. An
`na` value is skipped: it does not count toward the first `length` values,
and later the previous result is kept.

### wma

Linearly weighted moving average of the last `length` values of `source`.

```tea
ta.wma(source, int length)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to average, usually [`close`](./market-data.md#close). |
| `length`  | `int` | Number of bars, a positive `int`.                             |

**Returns:** The weighted mean; `na` for the first `length - 1` bars and when every value in the window is `na`.

The newest value has weight `length`, the one before it `length - 1`, and so
on down to `1` for the oldest. Values that are `na` are left out with their
weights.

### vwma

Volume-weighted moving average of the last `length` values of `source`.

```tea
ta.vwma(source, int length)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to average, usually [`close`](./market-data.md#close). |
| `length`  | `int` | Number of bars, a positive `int`.                             |

**Returns:** The weighted mean; `na` for the first `length - 1` bars and when the bars used have no volume.

It is the sum of `source * volume` divided by the sum of [`volume`](./market-data.md#volume), over
the window's bars where both are known.

### hma

Hull moving average of `source`.

```tea
ta.hma(source, int length)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to average, usually [`close`](./market-data.md#close). |
| `length`  | `int` | Number of bars, an `int` of at least `2`.                     |

**Returns:** The average; `na` for the first `length + math.floor(math.sqrt(length)) - 2` bars.

It is the [`ta.wma`](./ta.md#wma) over `math.floor(math.sqrt(length))` bars of
`2 * ta.wma(source, length / 2) - ta.wma(source, length)`, with `length / 2`
rounded down. Like [`ta.wma`](./ta.md#wma), it leaves out `na` values.

### swma

Symmetrically weighted moving average of the last four values of `source`.

```tea
ta.swma(source)
```

| Parameter | Description                                                   |
| --------- | ------------------------------------------------------------- |
| `source`  | Series to average, usually [`close`](./market-data.md#close). |

**Returns:** The weighted mean; `na` for the first three bars and while any of the four values is `na`.

The weights are `1/6`, `2/6`, `2/6` and `1/6`, from the oldest value to the
newest.

### alma

Arnaud Legoux moving average: a bell-curve-weighted average of the last `length` values of `source`.

```tea
ta.alma(source, int length, offset, sigma, bool floor = false)
```

| Parameter | Type   | Default | Description                                                                  |
| --------- | ------ | ------- | ---------------------------------------------------------------------------- |
| `source`  |        |         | Series to average, usually [`close`](./market-data.md#close).                |
| `length`  | `int`  |         | Number of bars, a positive `int`.                                            |
| `offset`  |        |         | Position of the peak weight, from `0` (oldest value) to `1` (newest value).  |
| `sigma`   |        |         | Narrowness of the curve; larger values concentrate the weight near the peak. |
| `floor`   | `bool` | `false` | `true` rounds the peak position down to a whole bar.                         |

**Returns:** The weighted mean; `na` for the first `length - 1` bars and while any value in the window is `na`.

The weights follow a Gaussian curve whose peak sits at `offset` across the
window and whose standard deviation is `length / sigma` bars.

### linreg

Value of the least-squares line through the last `length` values of `source`, `offset` bars before the current bar.

```tea
ta.linreg(source, int length, int offset)
```

| Parameter | Type  | Description                                                                                |
| --------- | ----- | ------------------------------------------------------------------------------------------ |
| `source`  |       | Series to fit, usually [`close`](./market-data.md#close).                                  |
| `length`  | `int` | Number of bars, an `int` of at least `2`.                                                  |
| `offset`  | `int` | Bars back from the current bar at which to read the line; `0` reads it at the current bar. |

**Returns:** The line's value; `na` for the first `length - 1` bars and while any value in the window is `na`.

The line is fitted with the oldest value at position `0` and the current value
at position `length - 1`, then read at position `length - 1 - offset`. A
negative `offset` extends the line past the current bar.

### cog

Center of gravity of the last `length` values of `source`.

```tea
ta.cog(source, int length)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to measure, usually [`close`](./market-data.md#close). |
| `length`  | `int` | Number of bars, a positive `int`.                             |

**Returns:** The center of gravity; `na` for the first `length - 1` bars, when every value in the window is `na`, and when the known values sum to `0`.

It is minus the sum of `source[i] * (i + 1)` divided by the sum of
`source[i]`, for `i` from `0` (the current bar) to `length - 1`, so it is
negative when the values are positive. Values that are `na` are left out.

## Momentum

### change

Difference between `source` now and `length` bars ago.

```tea
ta.change(source, int length = 1)
```

| Parameter | Type  | Default | Description                            |
| --------- | ----- | ------- | -------------------------------------- |
| `source`  |       |         | Series to compare.                     |
| `length`  | `int` | `1`     | Number of bars back, a positive `int`. |

**Returns:** `source - source[length]`; `na` for the first `length` bars and when either value is `na`.

### mom

Momentum: `source` minus its value `length` bars ago.

```tea
ta.mom(source, int length)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to compare, usually [`close`](./market-data.md#close). |
| `length`  | `int` | Number of bars back, a positive `int`.                        |

**Returns:** `source - source[length]`; `na` for the first `length` bars and when either value is `na`.

It is the same as [`ta.change`](./ta.md#change), with `length` required.

### roc

Rate of change: the percentage change of `source` from `length` bars ago.

```tea
ta.roc(source, int length)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to compare, usually [`close`](./market-data.md#close). |
| `length`  | `int` | Number of bars back, a positive `int`.                        |

**Returns:** `100 * (source - source[length]) / source[length]`; `na` for the first `length` bars, when either value is `na`, and when `source[length]` is `0`.

### rsi

Relative strength index of `source`, from `0` to `100`.

```tea
ta.rsi(source, int length)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to measure, usually [`close`](./market-data.md#close). |
| `length`  | `int` | Smoothing length in bars, a positive `int`.                   |

**Returns:** The index; `na` for the first `length` bars.

Gains and losses from [`ta.change`](./ta.md#change) are each smoothed with
[`ta.rma`](./ta.md#rma) over `length` bars, and the result is
`100 - 100 / (1 + gain / loss)`. It is `100` when the smoothed loss is `0`,
including on a flat series, and `0` when the smoothed gain is `0`.

### cmo

Chande momentum oscillator of `source`, from `-100` to `100`.

```tea
ta.cmo(source, int length)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to measure, usually [`close`](./market-data.md#close). |
| `length`  | `int` | Number of changes, a positive `int`.                          |

**Returns:** The oscillator; `na` for the first `length` bars, when no change in the window is known, and when `source` did not change over the window.

Over the last `length` bar-to-bar changes, it is
`100 * (gains - losses) / (gains + losses)`. A change that involves an `na`
value is left out.

### tsi

True strength index of `source`, from `-1` to `1`.

```tea
ta.tsi(source, int short_length, int long_length)
```

| Parameter      | Type  | Description                                                   |
| -------------- | ----- | ------------------------------------------------------------- |
| `source`       |       | Series to measure, usually [`close`](./market-data.md#close). |
| `short_length` | `int` | Length of the second smoothing, in bars.                      |
| `long_length`  | `int` | Length of the first smoothing, in bars.                       |

**Returns:** The index; `na` on the first bar and until `source` has changed.

The bar-to-bar change of `source` is smoothed twice with [`ta.ema`](./ta.md#ema),
first over `long_length` bars and then over `short_length` bars, and divided
by the absolute change smoothed the same way.

### stoch

Stochastic oscillator: where `source` sits between the lowest `l` and highest `h` of the last `length` bars.

```tea
ta.stoch(source, h, l, int length)
```

| Parameter | Type  | Description                                                                                  |
| --------- | ----- | -------------------------------------------------------------------------------------------- |
| `source`  |       | Series to place in the range, usually [`close`](./market-data.md#close).                     |
| `h`       |       | Series whose highest value is the top of the range, usually [`high`](./market-data.md#high). |
| `l`       |       | Series whose lowest value is the bottom of the range, usually [`low`](./market-data.md#low). |
| `length`  | `int` | Number of bars, a positive `int`.                                                            |

**Returns:** The percentage; `na` for the first `length - 1` bars, when `source` is `na` or a window has no known value, and when the range is `0`. Values that are `na` are left out of the windows.

It is `100 * (source - lowest) / (highest - lowest)`, from `0` to `100` when
`source` lies within that range. The result is not smoothed; pass it to
[`ta.sma`](./ta.md#sma) to smooth it.

```tea
k = ta.sma(ta.stoch(close, high, low, 14), 3)
d = ta.sma(k, 3)
emit "k" k
emit "d" d
```

### cci

Commodity channel index of `source`.

```tea
ta.cci(source, int length)
```

| Parameter | Type  | Description                                                 |
| --------- | ----- | ----------------------------------------------------------- |
| `source`  |       | Series to measure, such as [`hlc3`](./market-data.md#hlc3). |
| `length`  | `int` | Number of bars, a positive `int`.                           |

**Returns:** The index; `na` for the first `length - 1` bars, when `source` is `na`, and when the known values in the window are all equal.

It is `(source - mean) / (0.015 * deviation)`, where `mean` is the
[`ta.sma`](./ta.md#sma) and `deviation` the [`ta.dev`](./ta.md#dev) of the last `length` values.
Values that are `na` are left out of both.

### wpr

Williams %R: where [`close`](./market-data.md#close) sits within the range of the last `length` bars, from `-100` to `0`.

```tea
ta.wpr(int length)
```

| Parameter | Type  | Description                       |
| --------- | ----- | --------------------------------- |
| `length`  | `int` | Number of bars, a positive `int`. |

**Returns:** The percentage; `na` for the first `length - 1` bars, while any price in the window is `na`, and when the range is `0`.

It is `100 * (close - highest) / (highest - lowest)`, using the highest
[`high`](./market-data.md#high) and the lowest [`low`](./market-data.md#low) of the last `length` bars.

### mfi

Money flow index of `source`, from `0` to `100`.

```tea
ta.mfi(source, int length)
```

| Parameter | Type  | Description                                            |
| --------- | ----- | ------------------------------------------------------ |
| `source`  |       | Price series, usually [`hlc3`](./market-data.md#hlc3). |
| `length`  | `int` | Number of bars, a positive `int`.                      |

**Returns:** The index; `na` for the first `length` bars and when no bar in the window fell, and `0` when bars fell but none rose.

Money flow is `source * volume`, using [`volume`](./market-data.md#volume). Over the last `length`
bars, the flows of bars where `source` rose and of bars where it fell are
summed separately, and the result is `100 - 100 / (1 + rising / falling)`. A
bar whose change or flow involves an `na` value is left out.

### macd

Moving average convergence divergence of `source`, with its signal line and histogram.

```tea
ta.macd(source, int fastlen, int slowlen, int siglen)
```

| Parameter | Type  | Description                                                   |
| --------- | ----- | ------------------------------------------------------------- |
| `source`  |       | Series to measure, usually [`close`](./market-data.md#close). |
| `fastlen` | `int` | Length of the fast average, in bars.                          |
| `slowlen` | `int` | Length of the slow average, in bars.                          |
| `siglen`  | `int` | Length of the signal line's average, in bars.                 |

**Returns:** A tuple `[macdLine, signalLine, histogram]`, where `histogram` is `macdLine - signalLine`.

The MACD line is `ta.ema(source, fastLength) - ta.ema(source, slowLength)`,
the signal line is its [`ta.ema`](./ta.md#ema) over `signalLength` bars, and the
histogram is their difference. The averages start from the first value of
`source`, so all three are `0` on the first bar.

```tea
[macdLine, signalLine, histogram] = ta.macd(close, 12, 26, 9)
emit "macd" macdLine
emit "signal" signalLine
emit "histogram" histogram
```

### dmi

Directional movement index: the +DI and -DI lines and the ADX trend strength, each from `0` to `100`.

```tea
ta.dmi(int diLength, int adxSmoothing)
```

| Parameter      | Type  | Description                                         |
| -------------- | ----- | --------------------------------------------------- |
| `diLength`     | `int` | Smoothing length for +DI and -DI, a positive `int`. |
| `adxSmoothing` | `int` | Smoothing length for ADX, a positive `int`.         |

**Returns:** A tuple `[plusDI, minusDI, adx]`. +DI and -DI are `na` for the first `diLength - 1` bars, and ADX for the first `diLength + adxSmoothing - 2` bars.

On each bar, the upward move of [`high`](./market-data.md#high) counts toward +DI and the
downward move of [`low`](./market-data.md#low) toward -DI, whichever is larger and positive.
Each is smoothed with [`ta.rma`](./ta.md#rma) over `diLength` bars and divided by the
true range ([`ta.tr`](./ta.md#tr)) smoothed the same way. ADX is `100` times the
[`ta.rma`](./ta.md#rma), over `adxSmoothing` bars, of the absolute difference between
+DI and -DI divided by their sum.

```tea
[plusDI, minusDI, adx] = ta.dmi(14, 14)
emit "+DI" plusDI
emit "-DI" minusDI
emit "ADX" adx
```

### kc

Keltner Channels: an exponential average of `source` with bands `mult` average ranges above and below it.

```tea
ta.kc(source, int length, mult, useTrueRange = true)
```

| Parameter      | Type  | Default | Description                                                                                                             |
| -------------- | ----- | ------- | ----------------------------------------------------------------------------------------------------------------------- |
| `source`       |       |         | Series to average, usually [`close`](./market-data.md#close).                                                           |
| `length`       | `int` |         | Smoothing length in bars.                                                                                               |
| `mult`         |       |         | Band distance in average ranges.                                                                                        |
| `useTrueRange` |       | `true`  | `true` measures each bar's range with `ta.tr(false)`, so the range is `na` on the first bar; `false` uses `high - low`. |

**Returns:** A tuple `[middle, upper, lower]`.

The middle line is `ta.ema(source, length)`. The distance is `mult` times the

```tea

emit "upper" upper
emit "lower" lower
```

Keltner Channel width as a fraction of the middle line.


| -------------- | ----- | ------- | --------------------------------------------------------------------------------------- |

| `mult`         |       |         | Band distance in average ranges.                                                        |
| `useTrueRange` |       | `true`  | `true` measures each bar's range with [`ta.tr`](./ta.md#tr); `false` uses `high - low`. |

**Returns:** The width as a ratio; `na` when the middle line is `0`.

### supertrend

Supertrend: a trailing line on one side of price, and the trend direction.

```tea
ta.supertrend(factor, int atrPeriod)
```

| Parameter   | Type  | Description                                              |
| ----------- | ----- | -------------------------------------------------------- |
| `factor`    |       | Band distance in average true ranges.                    |
| `atrPeriod` | `int` | Length of the [`ta.atr`](./ta.md#atr), a positive `int`. |

**Returns:** A tuple `[line, direction]`. `direction` is `-1` in an uptrend, where `line` is the lower band below price, and `1` in a downtrend, where `line` is the upper band above price; it is `1` until the ATR has a previous value. `line` is `0` on the first bar and `na` until the ATR has a value.

Bands sit `factor` times `ta.atr(atrPeriod)` above and below [`hl2`](./market-data.md#hl2).
The lower band never falls unless the previous [`close`](./market-data.md#close) was below it,
and the upper band never rises unless the previous close was above it. The
trend turns up when `close` rises above the upper band and turns down when
`close` falls below the lower band.

```tea
[line, direction] = ta.supertrend(3.0, 10)
emit "supertrend" line
emit "uptrend" direction == -1
```

### sar

Parabolic SAR: a trailing stop that moves faster toward price as the trend makes new extremes.

```tea
ta.sar(start, inc, max)
```

| Parameter | Description                                              |
| --------- | -------------------------------------------------------- |
| `start`   | Initial acceleration factor, such as `0.02`.             |
| `inc`     | Increase of the acceleration factor at each new extreme. |
| `max`     | Largest acceleration factor.                             |

**Returns:** The level; `na` on the first bar, and on every bar if this call did not run on the bar where `bar_index` is `1`.

The trend starts on the bar where [`bar_index`](./market-data.md#bar_index) is `1`: upward with the
level at the previous [`low`](./market-data.md#low) if [`close`](./market-data.md#close) rose, otherwise downward
with the level at the previous [`high`](./market-data.md#high). Each bar the level moves toward
the trend's extreme price by the acceleration factor, which starts at `start`
and grows by `inc`, up to `max`, whenever the trend makes a new extreme. When
the bar's low falls below the level in an uptrend, or its high rises above it
in a downtrend, the trend reverses and the level jumps to the extreme of the
trend that ended. In an uptrend the level stays at or below the previous two
lows; in a downtrend, at or above the previous two highs.

## Crosses and conditions

### crossover

True on the bar where `source1` moves above `source2`.

```tea
ta.crossover(source1, source2)
```

| Parameter | Description                    |
| --------- | ------------------------------ |
| `source1` | Series that crosses.           |
| `source2` | Series or level being crossed. |

**Returns:** `true` on the crossing bar, otherwise `false`.

It is `source1 > source2` on this bar and `source1 <= source2` on the
previous bar. Equality on the current bar is not a cross, and a comparison
with `na` is `false`, so the result is `false` on the first bar.

```tea
fast = ta.ema(close, 9)
slow = ta.ema(close, 21)
emit "crossedUp" ta.crossover(fast, slow)
emit "crossedLevel" ta.crossover(close, 100.0)
```

## Volume

### obv

On-balance volume: the running total of [`volume`](./market-data.md#volume), added on bars where [`close`](./market-data.md#close) rose and subtracted on bars where it fell.

```tea
obv = cum(math.sign(change(close)) * volume)
```

It is `ta.cum(math.sign(ta.change(close)) * volume)`, computed once per bar
for the whole script.

### accdist

Accumulation/distribution: the running total of each bar's volume, weighted by where [`close`](./market-data.md#close) sits between [`low`](./market-data.md#low) and [`high`](./market-data.md#high).

```tea
accdist = cum(high == low ? 0.0 : (2 * close - low - high) / (high - low) * volume)
```

Each bar adds `(2 * close - low - high) / (high - low) * volume`, or `0` when
`high` equals `low`.

### pvt

Price-volume trend: the running total of each bar's [`volume`](./market-data.md#volume), weighted by the relative change of [`close`](./market-data.md#close).

```tea
pvt = cum(change(close) / close[1] * volume)
```

It is `ta.cum(ta.change(close) / close[1] * volume)`.

### iii

Intraday intensity index of the current bar: where [`close`](./market-data.md#close) sits between [`low`](./market-data.md#low) and [`high`](./market-data.md#high), times [`volume`](./market-data.md#volume).

```tea
iii = (2 * close - high - low) / (high - low) * volume
```

It is `(2 * close - high - low) / (high - low) * volume`; `na` when `high`
equals `low`.

### wvad

Williams variable accumulation/distribution of the current bar.

```tea
wvad = (close - open) / (high - low) * volume
```

It is `(close - open) / (high - low) * volume`; `na` when `high` equals
`low`.

### wad

Williams accumulation/distribution: the running total of each bar's move from its true low on an up bar, or from its true high on a down bar.

```tea
wad = cum(williamsGain())
```

The true low is the lower of [`low`](./market-data.md#low) and the previous [`close`](./market-data.md#close); the
true high is the higher of [`high`](./market-data.md#high) and the previous close. A bar where
`close` did not change adds `0`.

### nvi

Negative volume index: starts at `1` and moves with [`close`](./market-data.md#close), by its relative change, only on bars whose [`volume`](./market-data.md#volume) fell from the previous bar.

```tea
nvi = volumeIndex(true)
```

### pvi

Positive volume index: starts at `1` and moves with [`close`](./market-data.md#close), by its relative change, only on bars whose [`volume`](./market-data.md#volume) rose from the previous bar.

```tea
pvi = volumeIndex(false)
```
