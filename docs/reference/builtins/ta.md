Technical-analysis functions and variables: moving averages, oscillators, volatility bands, crosses, pivots, volume indicators and running statistics.

Each written call keeps its own history and state, covering only the bars on
which that call runs. A call does not run on a bar when the code around it
is skipped, such as an `if` branch, `switch` arm or ternary arm that is not
taken, the right side of an `and` or `or` whose left side already decides
the result, or a loop that runs zero times. Its windows then read that bar
as `na`, and its running state does not change on it. A call inside a loop
shares one history and state across all iterations, so its running state
advances on each iteration. Call these functions on every bar and combine
their results with conditions afterwards; see
[values and control flow](../../language-guide/values-and-control-flow.md).

```tea
// Call on every bar, then combine the result with the condition.
risingThree = ta.rising(close, 3)
emit "signal" close > open and risingThree
```

The variables, such as [`ta.obv`](./ta/obv.md) and [`ta.wad`](./ta/wad.md), are not calls:
each is computed once per bar for the whole script, so every read sees the
same value, even one inside an `if`.

A window function reads the last `length` bars of its source and leaves out
the `na` values among them. When none is left, the result is `na`, or
`false` for [`ta.rising`](./ta/rising.md) and [`ta.falling`](./ta/falling.md). In [`ta.alma`](./ta/alma.md),
[`ta.linreg`](./ta/linreg.md), [`ta.percentrank`](./ta/percentrank.md) and [`ta.swma`](./ta/swma.md), an `na` value
anywhere in the window makes the result `na` instead, and [`ta.change`](./ta/change.md),
[`ta.mom`](./ta/mom.md) and [`ta.roc`](./ta/roc.md) are `na` when either value they compare is
`na`. [`ta.cci`](./ta/cci.md), [`ta.stoch`](./ta/stoch.md) and [`ta.wpr`](./ta/wpr.md) are `na`, and
[`ta.rising`](./ta/rising.md) and [`ta.falling`](./ta/falling.md) are `false`, when the current value
they measure is `na`. Most results are also `na` until enough bars have
arrived; each entry says when.

Most sources are typed `float`: an `int` source, such as [`bar_index`](./bar-and-time.md#bar_index),
is converted to `float`, and a `bool` or `string` source is a compile error.
[`ta.change`](./ta/change.md) keeps an `int` source `int`. A `simple` parameter, such as
the `length` of [`ta.ema`](./ta/ema.md), takes a value known when the script starts,
like a constant or an input; a `series` value, such as `bar_index + 1`, is a
compile error there.

A count, such as `length`, has a minimum, which its parameter states. A
value below it, or `na`, stops the run with an error that names the
function, such as `ta.sma: length must be at least 1`; a constant that low,
or `na`, is a compile error at the call. A `series` length, such as
`bar_index + 1`, reaches back at most 500 bars: older values read as `na`.
A constant or input length is not limited this way.

**Pine Script:** These differences apply across `ta`:

- Not in Tea yet: `ta.median`, `ta.mode`,
  `ta.percentile_linear_interpolation`, `ta.percentile_nearest_rank`,
  `ta.pivot_point_levels`, `ta.rci`, `ta.valuewhen`, `ta.vwap` (the function
  and the variable) and the variable `ta.tr`, which Tea writes as the call
  `ta.tr(false)`.
- The Pine manual states no minimum for counts such as `length`; in Tea a
  count below its minimum, such as a `length` of `0`, or an `na` count is an
  error.
- The Pine manual says that `na` values are ignored, and for some functions
  that the calculation uses `length` values that are not `na`. A Tea window
  function reads the last `length` bars and leaves out the `na` values among
  them, so it can use fewer than `length` values.

Available in every script as `ta.name` without an import.

## Moving averages

| Name                          | Description                                                                                                                                            |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`ta.sma`](./ta/sma.md)       | Simple moving average: the mean of the last `length` values of `source`.                                                                               |
| [`ta.ema`](./ta/ema.md)       | Exponential moving average of `source`: a running average that gives recent values more weight.                                                        |
| [`ta.rma`](./ta/rma.md)       | Wilder's smoothed moving average of `source`, the running average behind [`ta.rsi`](./ta/rsi.md), [`ta.atr`](./ta/atr.md) and [`ta.dmi`](./ta/dmi.md). |
| [`ta.wma`](./ta/wma.md)       | Weighted moving average: the mean of the last `length` values of `source`, with weights falling linearly from the newest value to the oldest.          |
| [`ta.vwma`](./ta/vwma.md)     | Volume-weighted moving average: the mean of the last `length` values of `source`, each weighted by its bar's [`volume`](./price-and-volume.md#volume). |
| [`ta.hma`](./ta/hma.md)       | Hull moving average of `source`, built from three [`ta.wma`](./ta/wma.md) averages to reduce lag.                                                      |
| [`ta.swma`](./ta/swma.md)     | Symmetrically weighted moving average: the mean of the last four values of `source`, with weights 1, 2, 2 and 1.                                       |
| [`ta.alma`](./ta/alma.md)     | Arnaud Legoux moving average: the mean of the last `length` values of `series`, weighted by a bell curve.                                              |
| [`ta.linreg`](./ta/linreg.md) | Linear regression curve: the value of the least-squares line through the last `length` values of `source`, read `offset` bars back.                    |

## Momentum

| Name                          | Description                                                                                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`ta.cog`](./ta/cog.md)       | Center of gravity (COG) of the last `length` values of `source`.                                                                                 |
| [`ta.change`](./ta/change.md) | Difference between `source` and its value `length` bars ago.                                                                                     |
| [`ta.mom`](./ta/mom.md)       | Momentum: `source` minus its value `length` bars ago.                                                                                            |
| [`ta.roc`](./ta/roc.md)       | Rate of change (ROC): the percentage change of `source` from its value `length` bars ago.                                                        |
| [`ta.rsi`](./ta/rsi.md)       | Relative Strength Index (RSI) of `source`, from `0` to `100`.                                                                                    |
| [`ta.cmo`](./ta/cmo.md)       | Chande Momentum Oscillator (CMO) of `series`, from `-100` to `100`.                                                                              |
| [`ta.tsi`](./ta/tsi.md)       | True Strength Index (TSI) of `source`, from `-1` to `1`.                                                                                         |
| [`ta.stoch`](./ta/stoch.md)   | Stochastic oscillator, the fast %K: where `source` sits between the lowest `l` and the highest `h` of the last `length` bars, from `0` to `100`. |
| [`ta.cci`](./ta/cci.md)       | Commodity Channel Index (CCI) of `source`.                                                                                                       |
| [`ta.wpr`](./ta/wpr.md)       | Williams %R: where [`close`](./price-and-volume.md#close) sits within the range of the last `length` bars, from `-100` to `0`.                   |
| [`ta.mfi`](./ta/mfi.md)       | Money Flow Index (MFI) of `series`, from `0` to `100`.                                                                                           |
| [`ta.macd`](./ta/macd.md)     | Moving Average Convergence Divergence (MACD) of `source`: the MACD line, its signal line and the histogram.                                      |
| [`ta.dmi`](./ta/dmi.md)       | Directional Movement Index (DMI): the +DI and -DI lines and the Average Directional Index (ADX), each from `0` to `100`.                         |

## Volatility and bands

| Name                    | Description                                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| [`ta.tr`](./ta/tr.md)   | True range of the current bar: its high-to-low range, extended to reach the previous close.                                    |
| [`ta.atr`](./ta/atr.md) | Average true range (ATR): the smoothed average of recent true ranges, a measure of volatility in price units.                  |
| [`ta.bb`](./ta/bb.md)   | Bollinger Bands: the simple moving average of `series`, with bands `mult` standard deviations above and below it.              |
| [`ta.bbw`](./ta/bbw.md) | Bollinger Band width: the distance between the upper and lower [`ta.bb`](./ta/bb.md) bands as a percentage of the middle band. |
| [`ta.kc`](./ta/kc.md)   | Keltner Channels: the exponential moving average of `series`, with bands `mult` average ranges above and below it.             |
| [`ta.kcw`](./ta/kcw.md) | Keltner Channel width: the distance between the upper and lower [`ta.kc`](./ta/kc.md) bands as a fraction of the middle line.  |

## Volume

| Name                            | Description                                                                                                                                                                                                                                                   |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`ta.obv`](./ta/obv.md)         | On-balance volume (OBV): the running total of [`volume`](./price-and-volume.md#volume), added on bars where [`close`](./price-and-volume.md#close) rose and subtracted on bars where it fell.                                                                 |
| [`ta.accdist`](./ta/accdist.md) | Accumulation/distribution (A/D): the running total of each bar's [`volume`](./price-and-volume.md#volume), weighted by where [`close`](./price-and-volume.md#close) sits between [`low`](./price-and-volume.md#low) and [`high`](./price-and-volume.md#high). |
| [`ta.pvt`](./ta/pvt.md)         | Price-volume trend (PVT): the running total of each bar's [`volume`](./price-and-volume.md#volume), weighted by the relative change of [`close`](./price-and-volume.md#close).                                                                                |
| [`ta.iii`](./ta/iii.md)         | Intraday intensity index (III) of the current bar: where [`close`](./price-and-volume.md#close) sits between [`low`](./price-and-volume.md#low) and [`high`](./price-and-volume.md#high), times [`volume`](./price-and-volume.md#volume).                     |
| [`ta.wvad`](./ta/wvad.md)       | Williams variable accumulation/distribution (WVAD) of the current bar: the move from [`open`](./price-and-volume.md#open) to [`close`](./price-and-volume.md#close) as a fraction of the bar's range, times [`volume`](./price-and-volume.md#volume).         |
| [`ta.wad`](./ta/wad.md)         | Williams accumulation/distribution (WAD): the running total of each bar's move from its true low on an up bar, or from its true high on a down bar.                                                                                                           |
| [`ta.nvi`](./ta/nvi.md)         | Negative volume index (NVI): starts at `1` and moves with [`close`](./price-and-volume.md#close), by its relative change, only on bars whose [`volume`](./price-and-volume.md#volume) fell from the previous bar.                                             |
| [`ta.pvi`](./ta/pvi.md)         | Positive volume index (PVI): starts at `1` and moves with [`close`](./price-and-volume.md#close), by its relative change, only on bars whose [`volume`](./price-and-volume.md#volume) rose from the previous bar.                                             |
