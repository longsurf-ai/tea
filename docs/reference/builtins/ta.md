Technical-analysis functions: moving averages, oscillators, volatility bands, crosses and running statistics.

Each written call keeps its own history and state, covering only the bars on
which that call runs. Call these functions on every bar and combine their
results with conditions afterwards: a call inside an `if` branch, one arm of a
ternary, or after `and` or `or` does not run when that code is skipped, so its
window reads the skipped bars as `na` and its running state does not change on
them. A call inside a loop shares one history and state across all iterations.
See [values and control flow](../../language-guide/values-and-control-flow.md).

Most results are `na` until enough bars have arrived; each entry states when.
After that, a window function leaves out the `na` values in its window and is
`na` only when none is left. A few, such as [`ta.swma`](./ta/swma.md) and
[`ta.change`](./ta/change.md), say instead that an `na` value makes the result `na`.
The [time-series guide](../../language-guide/time-series.md) covers warm-up and
crossing rules.

```tea
// Call on every bar, then combine the result with the condition.
risingThree = ta.rising(close, 3)
emit "signal" close > open and risingThree
```

Available in every script as `ta.name` without an import.

## Moving averages

| Name                          | Description                                                                                                                             |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| [`ta.sma`](./ta/sma.md)       | Simple moving average of the last `length` values of `source`.                                                                          |
| [`ta.ema`](./ta/ema.md)       | Exponential moving average of `source`.                                                                                                 |
| [`ta.rma`](./ta/rma.md)       | Wilder's moving average of `source`, the smoothing behind [`ta.rsi`](./ta/rsi.md), [`ta.atr`](./ta/atr.md) and [`ta.dmi`](./ta/dmi.md). |
| [`ta.wma`](./ta/wma.md)       | Linearly weighted moving average of the last `length` values of `source`.                                                               |
| [`ta.vwma`](./ta/vwma.md)     | Volume-weighted moving average of the last `length` values of `source`.                                                                 |
| [`ta.hma`](./ta/hma.md)       | Hull moving average of `source`.                                                                                                        |
| [`ta.swma`](./ta/swma.md)     | Symmetrically weighted moving average of the last four values of `source`.                                                              |
| [`ta.alma`](./ta/alma.md)     | Arnaud Legoux moving average: a bell-curve-weighted average of the last `length` values of `source`.                                    |
| [`ta.linreg`](./ta/linreg.md) | Value of the least-squares line through the last `length` values of `source`, `offset` bars before the current bar.                     |

## Momentum

| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| [`ta.cog`](./ta/cog.md)       | Center of gravity of the last `length` values of `source`.                                                                     |

| [`ta.tsi`](./ta/tsi.md)       | True strength index of `source`, from `-1` to `1`.                                                                             |
| [`ta.stoch`](./ta/stoch.md)   | Stochastic oscillator: where `source` sits between the lowest `l` and highest `h` of the last `length` bars.                   |
| [`ta.cci`](./ta/cci.md)       | Commodity channel index of `source`.                                                                                           |
| [`ta.wpr`](./ta/wpr.md)       | Williams %R: where [`close`](./price-and-volume.md#close) sits within the range of the last `length` bars, from `-100` to `0`. |
| [`ta.mfi`](./ta/mfi.md)       | Money flow index of `source`, from `0` to `100`.                                                                               |
| [`ta.macd`](./ta/macd.md)     | Moving average convergence divergence of `source`, with its signal line and histogram.                                         |
| [`ta.dmi`](./ta/dmi.md)       | Directional movement index: the +DI and -DI lines and the ADX trend strength, each from `0` to `100`.                          |

## Volatility and bands

| Name                    | Description                                                                                               |
| ----------------------- | --------------------------------------------------------------------------------------------------------- |
| [`ta.tr`](./ta/tr.md)   | True range of the current bar.                                                                            |
| [`ta.atr`](./ta/atr.md) | Average true range: [`ta.tr`](./ta/tr.md) smoothed with [`ta.rma`](./ta/rma.md) over `length` bars.       |
| [`ta.bb`](./ta/bb.md)   | Bollinger Bands: the average of `source` with bands `mult` standard deviations above and below it.        |

| [`ta.kc`](./ta/kc.md)   | Keltner Channels: an exponential average of `source` with bands `mult` average ranges above and below it. |
| [`ta.kcw`](./ta/kcw.md) | Keltner Channel width as a fraction of the middle line.                                                   |
