## Reading signatures

Built-in signatures read `name(param: type, optional?: type, ...rest: type) → result`. Parameter tables add the qualifier each argument may have — `const`, `input`, `simple` or `series`, from least to most variable — and any further requirement, such as a compile-time constant. Functions written in Tea, such as `ta` and the libraries, show their declaration as written; a parameter without a type accepts any argument the function body can use. See [Types and qualifiers](./language/types.md).
