Coordinator for independently accounted lots whose orders execute immediately, without waiting for a later bar.

```tea
type LotTrade<B: broker.ImmediateBroker, P: portfolio.LotLedger>
```

| Field                   | Description                                                                                                  |
| ----------------------- | ------------------------------------------------------------------------------------------------------------ |
| `B broker`              | Broker that validates and executes this coordinator's orders.                                                |
| `P portfolio`           | Portfolio that records each lot.                                                                             |
| `int idx = -1`          | Bar index from the latest `begin_bar`, or `-1` before the first; later orders record it as `signalBarIndex`. |
| `float closePrice = na` | Close captured by the latest `begin_bar`; `entry`, `close_trade` and `mark` use it as their price.           |

Create it with [`trade.lots`](./lots.md). `entry` and `close_trade` execute at the
close captured by `begin_bar`; `close_trade_at_stop` executes when the bar
reached the stop. Each entry opens a lot with its own trade id. Each bar,
call `begin_bar`, then entries and closes, then `mark`. Keep per-lot exit
rules, such as stops, in your own state keyed by the trade id. Use these
methods rather than calling `broker` or `portfolio` directly.

## Methods

### begin_bar

Starts a bar by recording the close and bar index that later calls in the bar use.

```tea
int begin_bar(float closePrice, int barIndex)
```

| Parameter    | Type    | Description                           |
| ------------ | ------- | ------------------------------------- |
| `closePrice` | `float` | the bar's close                       |
| `barIndex`   | `int`   | the bar's index, normally `bar_index` |

**Returns:** `barIndex`.

### entry

Opens a new lot at the captured close, first closing every lot on the opposite side.

```tea
broker.Fill entry(
    string commandId,
    string reversalCommandId,
    trade.Direction direction,
    float qty = na,
    float notional = na
)
```

| Parameter           | Type              | Default | Description                                                                  |
| ------------------- | ----------------- | ------- | ---------------------------------------------------------------------------- |
| `commandId`         | `string`          |         | name of the entry order                                                      |
| `reversalCommandId` | `string`          |         | name of the orders that close opposite lots                                  |
| `direction`         | `trade.Direction` |         | side of the new lot                                                          |
| `qty`               | `float`           | `na`    | quantity of the new lot                                                      |
| `notional`          | `float`           | `na`    | value of the new lot; the broker converts it to a quantity at the fill price |

**Returns:** the entry's fill, whose `tradeId` identifies the new lot, or `na` when no lot opened.

Give exactly one of `qty` and `notional`, positive; otherwise the entry is rejected before anything closes. If an opposite lot fails to close, the entry is skipped. The broker rejects entries beyond the portfolio's `maxOpenTrades`.

### close_trade

Closes the open lot `tradeId` now, at the captured close.

```tea
broker.Fill close_trade(string commandId, int tradeId)
```

| Parameter   | Type     | Description                              |
| ----------- | -------- | ---------------------------------------- |
| `commandId` | `string` | name of the closing order                |
| `tradeId`   | `int`    | trade id of the lot, from its entry fill |

**Returns:** the closing fill, or `na` when the close was rejected.

The close is rejected when no open lot has that id.

### close_trade_at_stop

Closes lot `tradeId` if this bar reached `stopPrice`; the broker decides the fill price.

```tea
broker.Fill close_trade_at_stop(
    string commandId,
    int tradeId,
    broker.Side entrySide,
    float openPrice,
    float highPrice,
    float lowPrice,
    float stopPrice
)
```

| Parameter   | Type          | Description                                                                                      |
| ----------- | ------------- | ------------------------------------------------------------------------------------------------ |
| `commandId` | `string`      | name of the closing order                                                                        |
| `tradeId`   | `int`         | trade id of the lot, from its entry fill                                                         |
| `entrySide` | `broker.Side` | side the lot was opened on: `broker.Side.buy` for a long lot, `broker.Side.sell` for a short one |
| `openPrice` | `float`       | the bar's open                                                                                   |
| `highPrice` | `float`       | the bar's high                                                                                   |
| `lowPrice`  | `float`       | the bar's low                                                                                    |
| `stopPrice` | `float`       | the lot's stop level                                                                             |

**Returns:** the closing fill, or `na` when the stop was not reached or the close was rejected.

A long lot's stop is reached when the low is at or below it, a short lot's when the high is at or above it. The fill is based on the open when the bar gapped past the stop, otherwise on the stop. If the stop was not reached, nothing happens; if it was, the close is rejected when the lot is missing or was not opened on `entrySide`.

### mark

Values the lots at the close captured by `begin_bar`, updating equity, peak equity and drawdown.

```tea
float mark()
```

**Returns:** the new equity.

### cash

Returns the portfolio's cash balance.

```tea
float cash() const
```

### position_quantity

Returns the signed total of the open lots: positive when long, negative when short.

```tea
float position_quantity() const
```

### position_avg_price

Returns the average entry price of the open lots, or `na` when none are open.

```tea
float position_avg_price() const
```

### snapshot

Returns the portfolio's metrics as one [`portfolio.PortfolioSnapshot`](../portfolio/PortfolioSnapshot.md).

```tea
portfolio.PortfolioSnapshot snapshot() const
```

Its `equity` is from the latest `mark`.
