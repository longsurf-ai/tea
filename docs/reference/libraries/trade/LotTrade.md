Coordinator for separately accounted lots whose orders execute at once, at the bar's close or at a stop.

```tea
type LotTrade<B: broker.ImmediateBroker, P: portfolio.LotLedger>
```

| Field                   | Description                                                                                                  |
| ----------------------- | ------------------------------------------------------------------------------------------------------------ |
| `B broker`              | Broker that validates and executes this coordinator's orders.                                                |
| `P portfolio`           | Portfolio that records each lot.                                                                             |
| `int idx = -1`          | Bar index from the latest `begin_bar`, or `-1` before the first; orders record it as their `signalBarIndex`. |
| `float closePrice = na` | Close captured by the latest `begin_bar`; `entry`, `close_trade` and `mark` use it as their price.           |

Create it with [`trade.lots`](./lots.md). Each bar, call `begin_bar`, then `entry`,
`close_trade` or `close_trade_at_stop`, then `mark`. Orders do not wait for a
later bar: `entry` and `close_trade` execute at the close captured by
`begin_bar`, and `close_trade_at_stop` executes when the bar reached the
stop. Each entry opens a lot with its own trade id, counting up from `1`, and
later closes name the lot by that id. Exit rules such as stops stay in the
script's own state, keyed by trade id. Strategies call these methods rather
than the broker's or the portfolio's own.

**Example:** Lot 1 buys 2 units at bar 0's close of 100 and lot 2 buys 3 at 104. Closing
lot 1 by its id at bar 2's close of 110 realizes 20 and leaves lot 2 open.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(broker.new(),
    portfolio.lots(initialCash = 1000.0, maxOpenTrades = 2))
var int first = 0
strat.begin_bar(close, bar_index)
if bar_index == 0
    filled = strat.entry("A", "Flip", trade.Direction.long, qty = 2.0)
    first := na(filled) ? 0 : filled.tradeId
if bar_index == 1
    strat.entry("B", "Flip", trade.Direction.long, qty = 3.0)
if bar_index == 2
    strat.close_trade("Exit A", first)
strat.mark()
metrics = strat.snapshot()
emit "close" close
emit "lots" metrics.openTradeCount
emit "position" metrics.positionQuantity
emit "realized" metrics.realizedPnl
```

```csv
time,close
0,100
1,104
2,110
3,108
```

**Output:**

```text
index  close  lots  position  realized
0      100    1     2         0
1      104    2     5         0
2      110    1     3         20
3      108    1     3         20
```

## Methods

### begin_bar

Starts a bar by recording the close and the bar index that later calls in the bar use.

```tea
int begin_bar(float closePrice, int barIndex)
```

| Parameter    | Type    | Description                            |
| ------------ | ------- | -------------------------------------- |
| `closePrice` | `float` | The bar's close.                       |
| `barIndex`   | `int`   | The bar's index, normally `bar_index`. |

**Returns:** `int`: `barIndex`.

**Example:** `begin_bar` returns the bar index it records. The entry on bar 1 executes
at that bar's close of 104, the price `begin_bar` captured.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(broker.new(),
    portfolio.lots(initialCash = 1000.0))
started = strat.begin_bar(close, bar_index)
float price = na
if bar_index == 1
    filled = strat.entry("Long", "Flip", trade.Direction.long, qty = 2.0)
    price := na(filled) ? na : filled.price
strat.mark()
emit "close" close
emit "begin_bar" started
emit "fill price" price
```

### entry

Opens a new lot at the captured close, after closing every lot on the opposite side.

```tea
broker.Fill entry(
    string commandId,
    string reversalCommandId,
    trade.Direction direction,
    float qty = na,
    float notional = na
)
```

| Parameter           | Type              | Default | Description                                                                      |
| ------------------- | ----------------- | ------- | -------------------------------------------------------------------------------- |
| `commandId`         | `string`          |         | Name of the entry order.                                                         |
| `reversalCommandId` | `string`          |         | Name of the orders that close opposite lots.                                     |
| `direction`         | `trade.Direction` |         | `trade.Direction.long` to buy or `trade.Direction.short` to sell.                |
| `qty`               | `float`           | `na`    | Quantity of the new lot.                                                         |
| `notional`          | `float`           | `na`    | Value of the new lot; the quantity is `notional` divided by the execution price. |

**Returns:** `broker.Fill`: the entry's fill, whose `tradeId` names the new lot, or `na` when no lot opened.

Give exactly one of `qty` and `notional`, positive; otherwise the broker
rejects the entry with `invalidQuantity` before anything closes. The
entry first closes each open lot on the other side, one fill per lot
under `reversalCommandId`, realizing its profit and loss; if one of those
closes fails, the entry stops there and returns `na`. Then the new lot
executes at the captured close plus adverse slippage. The broker rejects
it with `invalidAccountState` when the portfolio already holds
`maxOpenTrades` lots, or, unless the portfolio's margin for the side is
`0` (the default of [`portfolio.lots`](../portfolio/lots.md)), when
`notional * marginLong / 100 + fee` is more than the cash for a buy, or
`notional * marginShort / 100 + fee` is more than the equity at the
close for a sell. Lots closed before a rejected entry stay closed.

**Example:** Lots 1 and 2 buy 5 units at 100 and 2 at 104. The short entry on bar 2
first closes both at 110, realizing 5 _ 10 + 2 _ 6 = 62. Its 50 units at
110 need 5500 of equity under `marginShort = 100`, more than the 1062
left, so it is rejected and returns `na`, and the account is left flat.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(broker.new(), portfolio.lots(initialCash = 1000.0,
    maxOpenTrades = 2, marginShort = 100.0))
strat.begin_bar(close, bar_index)
int lot = na
if bar_index == 0
    filled = strat.entry("A", "Flip", trade.Direction.long, qty = 5.0)
    lot := na(filled) ? na : filled.tradeId
if bar_index == 1
    filled = strat.entry("B", "Flip", trade.Direction.long, qty = 2.0)
    lot := na(filled) ? na : filled.tradeId
if bar_index == 2
    filled = strat.entry("S", "Flip", trade.Direction.short, qty = 50.0)
    lot := na(filled) ? na : filled.tradeId
strat.mark()
emit "close" close
emit "new lot" lot
emit "position" strat.position_quantity()
emit "cash" strat.cash()
emit "realized" strat.snapshot().realizedPnl
```

```csv
time,close
0,100
1,104
2,110
3,110
```

**Output:**

```text
index  close  new lot  position  cash  realized
0      100    1        5         500   0
1      104    2        7         292   0
2      110    na       0         1062  62
3      110    na       0         1062  62
```

### close_trade

Closes the open lot `tradeId` now, at the captured close.

```tea
broker.Fill close_trade(string commandId, int tradeId)
```

| Parameter   | Type     | Description                               |
| ----------- | -------- | ----------------------------------------- |
| `commandId` | `string` | Name of the closing order.                |
| `tradeId`   | `int`    | Trade id of the lot, from its entry fill. |

**Returns:** `broker.Fill`: the closing fill, or `na` when the close was rejected.

The fill sells a long lot or buys back a short one at the close plus
adverse slippage, and realizes the lot's profit net of its entry and exit
commissions. The broker rejects the close with `invalidAccountState` when
no open lot has that id.

**Example:** Closing lot 1 at bar 1's close of 105 realizes 2 \* 5 = 10 and leaves lot
2 open. Trade id 7 names no open lot, so that close returns `na`.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(broker.new(),
    portfolio.lots(initialCash = 1000.0, maxOpenTrades = 2))
strat.begin_bar(close, bar_index)
int closedId = na
int unknownId = na
if bar_index == 0
    strat.entry("A", "Flip", trade.Direction.long, qty = 2.0)
    strat.entry("B", "Flip", trade.Direction.long, qty = 3.0)
if bar_index == 1
    closed = strat.close_trade("Exit", 1)
    unknown = strat.close_trade("Exit", 7)
    closedId := na(closed) ? na : closed.tradeId
    unknownId := na(unknown) ? na : unknown.tradeId
strat.mark()
emit "close" close
emit "closed lot" closedId
emit "unknown lot" unknownId
emit "lots" strat.snapshot().openTradeCount
emit "realized" strat.snapshot().realizedPnl
```

```csv
time,close
0,100
1,105
2,110
3,108
```

**Output:**

```text
index  close  closed lot  unknown lot  lots  realized
0      100    na          na           2     0
1      105    1           na           1     10
2      110    na          na           1     10
3      108    na          na           1     10
```

### close_trade_at_stop

Closes lot `tradeId` if this bar reached `stopPrice`; the broker decides the fill price.

```tea
broker.Fill close_trade_at_stop(
    string commandId,
    int tradeId,
    broker.Side entrySide,
    float openPrice,
    float highPrice,
    float lowPrice,
    float stopPrice
)
```

| Parameter   | Type          | Description                                                                                       |
| ----------- | ------------- | ------------------------------------------------------------------------------------------------- |
| `commandId` | `string`      | Name of the closing order.                                                                        |
| `tradeId`   | `int`         | Trade id of the lot, from its entry fill.                                                         |
| `entrySide` | `broker.Side` | Side the lot was opened on: `broker.Side.buy` for a long lot, `broker.Side.sell` for a short one. |
| `openPrice` | `float`       | The bar's open.                                                                                   |
| `highPrice` | `float`       | The bar's high.                                                                                   |
| `lowPrice`  | `float`       | The bar's low.                                                                                    |
| `stopPrice` | `float`       | The lot's stop price.                                                                             |

**Returns:** `broker.Fill`: the closing fill, or `na` when the stop was not reached or the close was rejected.

With `entrySide` buy, a long lot, the stop is reached when the low is at
or below it; with sell, when the high is at or above it. The fill is at
the open when the bar opened at or past the stop, otherwise at the stop,
plus adverse slippage. When the stop was not reached, nothing happens;
when it was, the broker rejects the close with `invalidAccountState` if
no open lot has that id or the lot was not opened on `entrySide`.

**Example:** Bar 1's low of 97 reaches lot 1's stop of 97, so it closes at the stop.
Bar 2 opens at 95, below lot 2's stop of 96, so lot 2 closes at the open.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(broker.new(),
    portfolio.lots(initialCash = 1000.0, maxOpenTrades = 2))
var int lotA = 0
var int lotB = 0
strat.begin_bar(close, bar_index)
float exitA = na
float exitB = na
if bar_index == 0
    a = strat.entry("A", "Flip", trade.Direction.long, qty = 2.0)
    b = strat.entry("B", "Flip", trade.Direction.long, qty = 3.0)
    lotA := na(a) ? 0 : a.tradeId
    lotB := na(b) ? 0 : b.tradeId
if bar_index > 0 and lotA > 0
    filled = strat.close_trade_at_stop("Stop A", lotA, broker.Side.buy,
        open, high, low, 97.0)
    if not na(filled)
        exitA := filled.price
        lotA := 0
if bar_index > 0 and lotB > 0
    filled = strat.close_trade_at_stop("Stop B", lotB, broker.Side.buy,
        open, high, low, 96.0)
    if not na(filled)
        exitB := filled.price
        lotB := 0
strat.mark()
emit "open" open
emit "low" low
emit "lot 1 exit" exitA
emit "lot 2 exit" exitB
emit "lots" strat.snapshot().openTradeCount
```

```csv
time,open,high,low,close
0,100,101,99,100
1,99,100,97,98
2,95,96,90,92
3,92,94,91,93
```

**Output:**

```text
index  open  low  lot 1 exit  lot 2 exit  lots
0      100   99   na          na          2
1      99    97   97          na          1
2      95    90   na          95          0
3      92    91   na          na          0
```

### mark

Values the open lots at the close captured by `begin_bar` and updates equity, peak equity and maximum drawdown.

```tea
float mark()
```

**Returns:** `float`: the new equity.

Equity is cash plus each lot's signed quantity times that close.

**Example:** After 2 units bought at 100 and 3 at 110, cash is 470, so equity at bar
1's close is 470 + 5 \* 110 = 1020, and 995 at 105.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(broker.new(),
    portfolio.lots(initialCash = 1000.0, maxOpenTrades = 2))
strat.begin_bar(close, bar_index)
if bar_index == 0
    strat.entry("A", "Flip", trade.Direction.long, qty = 2.0)
if bar_index == 1
    strat.entry("B", "Flip", trade.Direction.long, qty = 3.0)
equity = strat.mark()
emit "close" close
emit "cash" strat.cash()
emit "equity" equity
```

```csv
time,close
0,100
1,110
2,105
3,115
```

**Output:**

```text
index  close  cash  equity
0      100    800   1000
1      110    470   1020
2      105    470   995
3      115    470   1045
```

### cash

Returns the portfolio's cash balance.

```tea
float cash() const
```

**Returns:** `float`: the cash balance.

A buy subtracts its notional and commission; a sell, including a short
sale, adds its notional and subtracts its commission.

**Example:** With a 1% commission, the lot of 2 units bought at 100 takes 200 + 2 from
cash, and closing it at 110 adds 220 - 2.2.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(
    broker.new(commission = broker.commissionPercent(1.0)),
    portfolio.lots(initialCash = 1000.0))
strat.begin_bar(close, bar_index)
if bar_index == 0
    strat.entry("A", "Flip", trade.Direction.long, qty = 2.0)
if bar_index == 1
    strat.close_trade("Exit", 1)
strat.mark()
emit "close" close
emit "cash" strat.cash()
```

```csv
time,close
0,100
1,110
2,108
3,112
```

**Output:**

```text
index  close  cash
0      100    798
1      110    1015.8
2      108    1015.8
3      112    1015.8
```

### position_quantity

```tea
float position_quantity() const
```

**Returns:** `float`: the position quantity.

**Example:** Two long lots make 5 units. The short entry on bar 2 closes both, then
opens a short lot of 4.

```tea

var strat = trade.lots(broker.new(),
```

### position_avg_price

Returns the quantity-weighted average entry price of the open lots, or `na` when none are open.

```tea
float position_avg_price() const
```

**Returns:** `float`: the average entry price, or `na` when no lot is open.

Entry prices are execution prices, after slippage.

**Example:** Lots of 2 units at 100 and 3 at 110 average (200 + 330) / 5 = 106. After
lot 1 closes, the average is lot 2's price.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(broker.new(),
    portfolio.lots(initialCash = 1000.0, maxOpenTrades = 2))
strat.begin_bar(close, bar_index)
if bar_index == 0
    strat.entry("A", "Flip", trade.Direction.long, qty = 2.0)
if bar_index == 1
    strat.entry("B", "Flip", trade.Direction.long, qty = 3.0)
if bar_index == 2
    strat.close_trade("Exit", 1)
strat.mark()
emit "close" close
emit "average" strat.position_avg_price()
```

```csv
time,close
0,100
1,110
2,108
3,112
```

**Output:**

```text
index  close  average
0      100    100
1      110    106
2      108    110
3      112    110
```

### snapshot

Returns the portfolio's metrics as one [`portfolio.PortfolioSnapshot`](../portfolio/PortfolioSnapshot.md).

```tea
portfolio.PortfolioSnapshot snapshot() const
```

**Returns:** `portfolio.PortfolioSnapshot`: cash, position, equity, profit and risk statistics.

Its `equity` is from the latest `mark`, and `openTradeCount` counts the
open lots.

**Example:** Two lots are open at once on bar 1, so `maxLongStack` is 2. Closing lot 1
at 110 is one winning round trip.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(broker.new(),
    portfolio.lots(initialCash = 1000.0, maxOpenTrades = 2))
strat.begin_bar(close, bar_index)
if bar_index == 0
    strat.entry("A", "Flip", trade.Direction.long, qty = 2.0)
if bar_index == 1
    strat.entry("B", "Flip", trade.Direction.long, qty = 3.0)
if bar_index == 2
    strat.close_trade("Exit", 1)
strat.mark()
metrics = strat.snapshot()
emit "lots" metrics.openTradeCount
emit "max long stack" metrics.maxLongStack
emit "round trips" metrics.roundTripCount
emit "win rate" metrics.winRate
emit "equity" metrics.equity
```
