Which equity a [`trade.Sizing`](./Sizing.md) percentage is taken from: the marked equity when `entry` is called, or the equity when the order fills.

```tea
enum SizingKind
```

| Member                  | Description                                                                         |
| ----------------------- | ----------------------------------------------------------------------------------- |
| `percentOfEquity`       | Equity from the latest `mark` or `end_bar`, read when `entry` is called.            |
| `percentOfEquityAtFill` | Equity at the order's matched price before slippage, computed when the order fills. |

**Example:** Both coordinators hold 5 units bought at 100 and add 12% of equity with an
order sent on bar 2. `percentOfEquity` takes the equity marked at bar 1's
close, 1200, and buys 144 / 150 = 0.96 units at bar 3's open of 150.
`percentOfEquityAtFill` takes the equity at that open, 1250, and buys 1.

```tea
import broker
import portfolio
import trade

var byMark = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0, pyramiding = 2))
var atFill = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0, pyramiding = 2))
a = byMark.begin_bar(open, bar_index)
b = atFill.begin_bar(open, bar_index)
if bar_index == 0
    byMark.entry("Long", trade.Direction.long, qty = 5.0)
    atFill.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 2
    byMark.entry("Long", trade.Direction.long,
        sizing = trade.percentOfEquity(12.0))
    atFill.entry("Long", trade.Direction.long,
        sizing = trade.percentOfEquityAtFill(12.0))
byMark.end_bar(close, false)
atFill.end_bar(close, false)
emit "open" open
emit "close" close
emit "percentOfEquity" na(a) ? na : a.quantity
emit "percentOfEquityAtFill" na(b) ? na : b.quantity
```
