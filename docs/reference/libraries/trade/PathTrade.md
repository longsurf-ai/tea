Coordinator that replays each bar as an ordered price path and matches orders, stop entries and fixed or trailing exits along it.

```tea
type PathTrade<B: broker.PathBroker, P: portfolio.NetLedger>
```

| Field          | Description                                                                                                                             |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `B broker`     | Broker that validates and fills this coordinator's orders.                                                                              |
| `P portfolio`  | Portfolio that records this coordinator's fills.                                                                                        |
| `int idx = -1` | Bar index from the latest `begin_bar`, or `-1` before the first; orders submitted later in the bar record it as their `signalBarIndex`. |

Create it with [`trade.path`](./path.md). The path runs from the open to the nearer
of the high and the low, then to the farther one, then to the close; when the
high and the low are equally far from the open, the low comes first. An exit
only sees the part of the path after its entry filled. Each bar, call
`begin_bar`, attach or adjust exits, call `continue_bar`, submit new orders,
then call `end_bar`. Orders never fill at a close in this family. The broker
holds one pending order and one attached exit at a time, and makes at most
two fills per bar. Strategies call these methods rather than the broker's or
the portfolio's own.

**Example:** On bar 1 the path runs 100, 95, 106, 104. The buy stop at 105 fills on the
way up from 95, so its exit, active on the entry's bar, only sees 105, 106
and 104: the low of 95, earlier on the path, does not trigger the exit's stop
of 96.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
matches = strat.begin_bar(open, high, low, close, bar_index)
exitFill = strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.entry("Breakout", trade.Direction.long, qty = 5.0,
        stop = 105.0)
    strat.exit("Stop", fromEntry = "Breakout", stop = 96.0,
        activateOnEntryBar = true)
strat.end_bar(close, false)
emit "open" open
emit "high" high
emit "low" low
emit "close" close
emit "entry" na(matches.pending) ? na : matches.pending.price
emit "exit" na(exitFill) ? na : exitFill.price
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,106,95,104
2,104,105,103,104
3,104,106,103,105
```

**Output:**

```text
index  open  high  low  close  entry  exit  position
0      100   101   99   100    na     na    0
1      100   106   95   104    105    na    5
2      104   105   103  104    na     na    5
3      104   106   103  105    na     na    5
```

**See also:** [`trade.path`](./path.md), [`trade.OhlcTrade`](./OhlcTrade.md)

## Methods

### begin_bar

Starts a bar: fills the pending order along this bar's path and records where on the path it filled.

```tea
broker.BarMatches begin_bar(
    float openPrice,
    float highPrice,
    float lowPrice,
    float closePrice,
    int barIndex
)
```

| Parameter    | Type    | Description                            |
| ------------ | ------- | -------------------------------------- |
| `openPrice`  | `float` | The bar's open.                        |
| `highPrice`  | `float` | The bar's high.                        |
| `lowPrice`   | `float` | The bar's low.                         |
| `closePrice` | `float` | The bar's close.                       |
| `barIndex`   | `int`   | The bar's index, normally `bar_index`. |

**Returns:** `broker.BarMatches`: `pending` holds the order's fill (after a reversal, the opening fill) and `reversalClose` the closing fill of a reversal, each `na` when absent; `exit` is always `na`. When a reversal's opening fill is rejected, `pending` holds the closing fill and `reversalClose` is `na`.

The pending order can fill from the bar after it was submitted. A market
order fills at the open. A stop entry fills at the open when the bar
opens at or past its stop, otherwise at the stop on the first segment of
the path that reaches it. A reversal completes at the same price. The
attached exit is not checked here: `continue_bar` checks it on the rest
of the path, so an exit derived from this fill can be attached first.

**Example:** On bar 1, `pending` holds the long's fill at the open. The sell stop at
98, sent on bar 1, is reached on bar 2's path 99, 100, 96, 97 on the way
down from 100. It reverses the long: `reversalClose` holds the sale of
the 5 units and `pending` the 3-unit short at 98.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
matches = strat.begin_bar(open, high, low, close, bar_index)
strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 1
    strat.entry("Short", trade.Direction.short, qty = 3.0, stop = 98.0)
strat.end_bar(close, false)
closed = matches.reversalClose
emit "open" open
emit "high" high
emit "low" low
emit "closed qty" na(closed) ? na : closed.quantity
emit "opened qty" na(matches.pending) ? na : matches.pending.quantity
emit "price" na(matches.pending) ? na : matches.pending.price
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,102,99,101
2,99,100,96,97
3,97,98,96,97
```

**Output:**

```text
index  open  high  low  closed qty  opened qty  price  position
0      100   101   99   na          na          na     0
1      100   102   99   na          5           100    5
2      99    100   96   5           3           98     -3
3      97    98    96   na          na          na     -3
```

### continue_bar

Checks the attached exit, including its trailing stop, along the part of the bar's path after `begin_bar`'s fill.

```tea
broker.Fill continue_bar(
    float openPrice,
    float highPrice,
    float lowPrice,
    float closePrice
)
```

| Parameter    | Type    | Description      |
| ------------ | ------- | ---------------- |
| `openPrice`  | `float` | The bar's open.  |
| `highPrice`  | `float` | The bar's high.  |
| `lowPrice`   | `float` | The bar's low.   |
| `closePrice` | `float` | The bar's close. |

**Returns:** `broker.Fill`: the exit's fill, or `na` when the exit did not trigger.

Call it after `begin_bar` and any exit changes, with the same prices.
When `begin_bar` filled nothing, or filled at the open, it checks the
whole path. The exit fills at the first price on the path that reaches
its stop or target: at the level, or at the starting point when that is
already past it. Once the path reaches `trailPrice`, the trailing stop
moves at the end of each segment that goes the position's way and applies
from the next segment.

**Example:** The entry fills at bar 1's open of 100, and a stop 3 below the fill is
attached before `continue_bar`. The path then runs 101, 96, 98, so the
stop fills at 97 on the same bar.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
matches = strat.begin_bar(open, high, low, close, bar_index)
if not na(matches.pending)
    stopPrice = matches.pending.price - 3.0
    strat.exit("Stop", fromEntry = "Long", stop = stopPrice,
        activateOnEntryBar = true)
exitFill = strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
strat.end_bar(close, false)
emit "open" open
emit "high" high
emit "low" low
emit "exit" na(exitFill) ? na : exitFill.price
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,101,96,98
2,98,99,97,98
3,98,100,97,99
```

**Output:**

```text
index  open  high  low  exit  position
0      100   101   99   na    0
1      100   101   96   97    0
2      98    99    97   na    0
3      98    100   97   na    0
```

### entry

Submits a market or stop entry order that opens, adds to or reverses the position on a later bar.

```tea
broker.Order entry(
    string commandId,
    trade.Direction direction,
    float qty = na,
    trade.Sizing sizing = na,
    float stop = na
)
```

| Parameter   | Type              | Default | Description                                                                                                                                   |
| ----------- | ----------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `commandId` | `string`          |         | Name of the order; exits and `cancel` refer to it, and later entries that add to the position reuse it.                                       |
| `direction` | `trade.Direction` |         | `trade.Direction.long` to buy or `trade.Direction.short` to sell.                                                                             |
| `qty`       | `float`           | `na`    | Quantity to open or add; must be positive.                                                                                                    |
| `sizing`    | `trade.Sizing`    | `na`    | Percent-of-equity sizing from [`trade.percentOfEquity`](./percentOfEquity.md) or [`trade.percentOfEquityAtFill`](./percentOfEquityAtFill.md). |
| `stop`      | `float`           | `na`    | Stop price that makes this a stop entry, or `na` for a market order.                                                                          |

**Returns:** `broker.Order`: the accepted order, or `na` when the broker rejects it on submission.

Without `stop` it is a market order that fills at the next open. With
`stop` it fills where the path first reaches the stop: a buy at or above
it, a sell at or below it; `begin_bar` gives the fill price. Resubmitting
a pending stop entry under the same `commandId` with a `stop` replaces
it, and an exit attached to it stays attached.

Sizing, reversals, adding to a position and the checks work as for
[`trade.NextOpenTrade.entry`](./NextOpenTrade.md#entry). Give at most one of `qty` and
`sizing`; without either, the entry spends all available capital. It
returns `na` when another order is pending, when an entry on the
position's side uses another `commandId`, or when `stop` is not positive.
Size, room under `pyramiding` and capital are checked when the order
would fill.

**Example:** The buy stop at 125 is sized at 50% of the 1000 equity. Bar 2's path runs
122, 121, 127, 126 and reaches the stop on the way up, buying 500 / 125 =
4 units at 125.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
matches = strat.begin_bar(open, high, low, close, bar_index)
strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.entry("Breakout", trade.Direction.long, stop = 125.0,
        sizing = trade.percentOfEquity(50.0))
strat.end_bar(close, false)
emit "open" open
emit "high" high
emit "low" low
emit "fill price" na(matches.pending) ? na : matches.pending.price
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,120,121,119,120
1,120,124,119,122
2,122,127,121,126
3,126,128,125,127
```

**Output:**

```text
index  open  high  low  fill price  position
0      120   121   119  na          0
1      120   124   119  na          0
2      122   127   121  125         4
3      126   128   125  na          4
```

**See also:** [`trade.NextOpenTrade.entry`](./NextOpenTrade.md#entry)

### exit

Attaches a fixed and/or trailing exit that closes the whole position opened by entry `fromEntry`.

```tea
broker.Order exit(
    string commandId,
    string fromEntry,
    float stop = na,
    float target = na,
    bool activateOnEntryBar = false,
    float trailPrice = na,
    float trailOffset = na
)
```

| Parameter            | Type     | Default | Description                                                                                        |
| -------------------- | -------- | ------- | -------------------------------------------------------------------------------------------------- |
| `commandId`          | `string` |         | Name of the exit; `cancel` takes it.                                                               |
| `fromEntry`          | `string` |         | `commandId` of the entry the exit belongs to.                                                      |
| `stop`               | `float`  | `na`    | Stop-loss price, or `na` for none.                                                                 |
| `target`             | `float`  | `na`    | Take-profit price, or `na` for none.                                                               |
| `activateOnEntryBar` | `bool`   | `false` | Whether the exit may fill on the bar its entry fills.                                              |
| `trailPrice`         | `float`  | `na`    | Price the path must reach to start the trailing stop, or `na` for none.                            |
| `trailOffset`        | `float`  | `na`    | Distance the trailing stop keeps behind the best price reached since it started, or `na` for none. |

**Returns:** `broker.Order`: the accepted exit, or `na` when the broker rejects it on submission.

Give any of `stop`, `target` and the trailing pair `trailPrice` with
`trailOffset`, all positive; for a long the stop must be below the
target, for a short above it. `trailPrice` is a price and `trailOffset` a
price distance: once the path reaches `trailPrice`, the trailing stop
sits `trailOffset` behind the best price reached since, and it replaces
`stop` whenever it is tighter. `continue_bar` checks the exit, from the
bar after its entry fills, or from the entry's own bar with
`activateOnEntryBar`. Adverse slippage applies to exit fills too, so a
target is not a limit price.

`fromEntry` must name the pending entry or the entry that opened the
position. One exit is attached at a time: resubmitting with the same
`commandId` and `fromEntry` replaces it and starts its trailing stop
over, and another exit returns `na`, as do invalid prices, only one of
the trailing pair, and a `fromEntry` that matches no entry. A fill that
closes or reverses the position cancels the exit, unless the exit is
attached to the reversing entry itself, and so does the failure of the
pending entry it is attached to.

**Example:** The trailing stop starts when bar 1's path rises from 99 to 112, past the
activation price of 105, and then sits 2 below that best price, at 110.
Bar 2's path falls from 111.5 to 108, so the exit fills at 110.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
matches = strat.begin_bar(open, high, low, close, bar_index)
if not na(matches.pending)
    strat.exit("Trail", fromEntry = "Long", stop = 95.0,
        activateOnEntryBar = true, trailPrice = 105.0, trailOffset = 2.0)
exitFill = strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
strat.end_bar(close, false)
emit "open" open
emit "high" high
emit "low" low
emit "exit" na(exitFill) ? na : exitFill.price
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,112,99,111
2,111,111.5,108,109
3,109,110,108,109
```

**Output:**

```text
index  open  high   low  exit  position
0      100   101    99   na    0
1      100   112    99   na    5
2      111   111.5  108  110   0
3      109   110    108  na    0
```

### close

Submits an order that closes the whole position at a later bar's open.

```tea
broker.Order close(string commandId)
```

| Parameter   | Type     | Description                           |
| ----------- | -------- | ------------------------------------- |
| `commandId` | `string` | Name of the order; `cancel` takes it. |

**Returns:** `broker.Order`: the accepted order, or `na` when another order is pending.

When it fills, it also cancels the attached exit. It returns `na` when
another order is pending; if the position is flat when it would fill, the
broker rejects it with `invalidAccountState`.

**Example:** Even with `processOrdersOnClose = true` on the broker, the close sent on
bar 1 does not fill at that bar's close of 104; it fills at bar 2's open
of 106.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(processOrdersOnClose = true),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, close, bar_index)
strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 1
    strat.close("Exit")
strat.end_bar(close, false)
emit "open" open
emit "close" close
emit "position" strat.position_quantity()
emit "cash" strat.cash()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,105,99,104
2,106,107,105,106
3,106,108,105,107
```

**Output:**

```text
index  open  close  position  cash
0      100   100    0         1000
1      100   104    5         500
2      106   106    0         1030
3      106   107    0         1030
```

### rebalance

Submits an order that moves the position to a target size at a later bar's open.

```tea
broker.Order rebalance(
    string commandId,
    broker.PositionTarget target
)
```

| Parameter   | Type                    | Description                                                                                                               |
| ----------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `commandId` | `string`                | Name of the order; `cancel` takes it.                                                                                     |
| `target`    | `broker.PositionTarget` | Target from [`trade.targetQuantity`](./targetQuantity.md) or [`trade.targetPercentOfEquity`](./targetPercentOfEquity.md). |

**Returns:** `broker.Order`: the accepted order, or `na` when the broker rejects it on submission.

It works as [`trade.NextOpenTrade.rebalance`](./NextOpenTrade.md#rebalance) does. When it fills,
the broker trades the difference between the target and the position in
one fill, and cancels the order when the difference is at most 0.0000001.
Unless the portfolio's `marginLong` is `0`, a buy from a flat or long
position is cut, without a rejection, to what the cash pays for; a sell
that opens or adds to a short, and a fill that crosses zero, must pass a
capital check. A fill that closes the position or crosses zero also
cancels the attached exit.

`pyramiding` never limits a rebalance. A rebalance that opens or reverses
the position counts as its first entry, and its `commandId` becomes the
position's entry id, which a later `entry` on that side must use and an
exit can name in `fromEntry`. A rebalance that adds to or reduces the
position leaves the entry id and the entry count unchanged.

**Example:** The rebalance opens 5 units at bar 1 under the id `Alloc`, which the stop
then names in `fromEntry`. A target of 0 sells the 5 units at bar 3's
open and cancels the stop.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, close, bar_index)
strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.rebalance("Alloc", trade.targetQuantity(5.0))
if bar_index == 1
    strat.exit("Stop", fromEntry = "Alloc", stop = 90.0)
if bar_index == 2
    strat.rebalance("Alloc", trade.targetQuantity(0.0))
strat.end_bar(close, false)
emit "open" open
emit "position" strat.position_quantity()
emit "pending" strat.has_pending() ? 1 : 0
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,103,99,102
2,102,104,101,103
3,104,105,103,104
```

**Output:**

```text
index  open  position  pending
0      100   0         1
1      100   5         1
2      102   5         1
3      104   0         0
```

**See also:** [`trade.targetQuantity`](./targetQuantity.md), [`trade.targetPercentOfEquity`](./targetPercentOfEquity.md)

### cancel

Cancels the pending order or the attached exit named `commandId`.

```tea
int cancel(string commandId)
```

| Parameter   | Type     | Description                                |
| ----------- | -------- | ------------------------------------------ |
| `commandId` | `string` | Name the order or exit was submitted with. |

**Returns:** `int`: the number of orders cancelled, from `0` to `2`.

Cancelling a pending entry also cancels an exit attached to it, unless
that exit protects the open position of the same entry id.

**Example:** Cancelling the attached stop on bar 1 returns 1. Bar 2's low of 94 would
have reached it; the 5 units stay open.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, close, bar_index)
strat.continue_bar(open, high, low, close)
int cancelled = na
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
    strat.exit("Stop", fromEntry = "Long", stop = 95.0)
if bar_index == 1
    cancelled := strat.cancel("Stop")
strat.end_bar(close, false)
emit "low" low
emit "cancelled" cancelled
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,102,98,101
2,101,102,94,96
3,96,98,95,97
```

**Output:**

```text
index  low  cancelled  position
0      99   na         0
1      98   1          5
2      94   na         5
3      95   na         5
```

### end_bar

Ends the bar: marks the portfolio at `closePrice` and, on the last bar, expires the pending order and the attached exit.

```tea
broker.FinishResult end_bar(float closePrice, bool isLast)
```

| Parameter    | Type    | Description                               |
| ------------ | ------- | ----------------------------------------- |
| `closePrice` | `float` | The bar's close.                          |
| `isLast`     | `bool`  | Whether this is the last bar of the data. |

**Returns:** `broker.FinishResult`: the orders expired on the last bar, or `na` when `isLast` is `false`.

This family never fills orders at a close, even with
`processOrdersOnClose = true` on the broker. Tea has no builtin that
tells the last bar, so pass `false` unless the script knows it, for
example from an input.

**Example:** Equity is marked at each close. The close sent on the last bar, bar 3,
can no longer fill, so `end_bar` returns it as expired, order 2.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, close, bar_index)
strat.continue_bar(open, high, low, close)
isLast = bar_index == 3
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if isLast
    strat.close("Exit")
expired = strat.end_bar(close, isLast)
emit "close" close
emit "equity" strat.snapshot().equity
emit "expired" na(expired) ? na : expired.pending.id
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,104,99,103
2,103,106,102,105
3,105,107,104,106
```

**Output:**

```text
index  close  equity  expired  position
0      100    1000    na       0
1      103    1015    na       5
2      105    1025    na       5
3      106    1030    2        5
```

### cash

Returns the portfolio's cash balance.

```tea
float cash() const
```

**Returns:** `float`: the cash balance.

A buy subtracts its notional and commission; a sell, including a short
sale, adds its notional and subtracts its commission.

**Example:** With a 1% commission, the short sale of 5 units at 100 adds 500 - 5, and
the stop exit at 104 buys them back for 520 + 5.2.

```tea
import broker
import portfolio
import trade

var strat = trade.path(
    broker.new(commission = broker.commissionPercent(1.0)),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, close, bar_index)
strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.entry("Short", trade.Direction.short, qty = 5.0)
    strat.exit("Cover", fromEntry = "Short", stop = 104.0)
strat.end_bar(close, false)
emit "open" open
emit "high" high
emit "cash" strat.cash()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,102,98,101
2,101,105,100,103
3,103,104,102,103
```

**Output:**

```text
index  open  high  cash
0      100   101   1000
1      100   102   1495
2      101   105   969.8
3      103   104   969.8
```

### position_avg_price

Returns the average entry price of the open position, or `na` when flat.

```tea
float position_avg_price() const
```

**Returns:** `float`: the average entry price, or `na` when flat.

It is the quantity-weighted mean of the execution prices, after slippage,
of the fills that opened and added to the position; a fill that reduces
the position does not change it.

**Example:** With `pyramiding = 2`, 5 units bought at bar 1's open of 100 and 5 added
by the buy stop at 104 average 102.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 2000.0, pyramiding = 2))
strat.begin_bar(open, high, low, close, bar_index)
strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 1
    strat.entry("Long", trade.Direction.long, qty = 5.0, stop = 104.0)
strat.end_bar(close, false)
emit "high" high
emit "position" strat.position_quantity()
emit "average" strat.position_avg_price()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,103,99,102
2,102,106,101,105
3,105,107,104,106
```

**Output:**

```text
index  high  position  average
0      101   0         na
1      103   5         100
2      106   10        102
3      107   10        102
```

### snapshot

Returns the portfolio's metrics as one [`portfolio.PortfolioSnapshot`](../portfolio/PortfolioSnapshot.md).

```tea
portfolio.PortfolioSnapshot snapshot() const
```

**Returns:** `portfolio.PortfolioSnapshot`: cash, position, equity, profit and risk statistics.

Its `equity` is from the latest `end_bar`.

**Example:** The target exit sells the 5 units bought at 100 for 106, so the round
trip realizes 30 and counts as a win.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, close, bar_index)
strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
    strat.exit("Target", fromEntry = "Long", target = 106.0)
strat.end_bar(close, false)
metrics = strat.snapshot()
emit "high" high
emit "equity" metrics.equity
emit "realized" metrics.realizedPnl
emit "round trips" metrics.roundTripCount
emit "win rate" metrics.winRate
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,104,99,103
2,103,107,102,104
3,104,105,103,104
```

**Output:**

```text
index  high  equity  realized  round trips  win rate
0      101   1000    0         0            0
1      104   1015    0         0            0
2      107   1030    30        1            1
3      105   1030    30        1            1
```

### has_pending

Returns whether an order or an attached exit is pending.

```tea
bool has_pending() const
```

**Returns:** `bool`: `true` while an order waits to fill or an exit is attached.

**Example:** After the entry fills at bar 1's open, the attached stop keeps
`has_pending` true; `has_pending_entry` is false once the entry has
filled.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, close, bar_index)
strat.continue_bar(open, high, low, close)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
    strat.exit("Stop", fromEntry = "Long", stop = 90.0)
strat.end_bar(close, false)
emit "pending" strat.has_pending() ? 1 : 0
emit "pending entry" strat.has_pending_entry() ? 1 : 0
emit "position" strat.position_quantity()
```

### has_pending_entry

Returns whether the pending order is an entry.

```tea
bool has_pending_entry() const
```

**Returns:** `bool`: `true` when an entry is pending; `false` for a pending close or rebalance, for an attached exit alone, or when nothing is pending.

**Example:** The buy stop at 105 is a pending entry until bar 2's path reaches it.

```tea
import broker
import portfolio
import trade

var strat = trade.path(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, close, bar_index)

if bar_index == 0
    strat.entry("Breakout", trade.Direction.long, qty = 5.0,
        stop = 105.0)
strat.end_bar(close, false)
emit "high" high
emit "pending entry" strat.has_pending_entry() ? 1 : 0
emit "position" strat.position_quantity()
```
