Creates a coordinator that opens and closes independently accounted lots immediately, within the current bar.

```tea
trade.lots(broker, portfolio)
```

| Parameter   | Description                                                                                                                              |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `broker`    | A broker with the [`broker.ImmediateBroker`](../broker/ImmediateBroker.md) methods, normally from [`broker.new`](../broker/new.md).      |
| `portfolio` | A portfolio with the [`portfolio.LotLedger`](../portfolio/LotLedger.md) methods, normally from [`portfolio.lots`](../portfolio/lots.md). |

**Returns:** A [`trade.LotTrade`](./LotTrade.md) that owns both values.

Each bar, call `begin_bar(close, bar_index)`, then `entry`, `close_trade` or
`close_trade_at_stop`, then `mark()`. Each entry fill carries the `tradeId`
that later closes refer to.

```tea
import broker
import portfolio
import trade

basis = ta.sma(close, 20)
crossedUp = ta.crossover(close, basis)
crossedDown = ta.crossunder(close, basis)

var strat = trade.lots(broker.new(), portfolio.lots(initialCash = 10000.0))
var int lotId = 0
var float lotStop = na
strat.begin_bar(close, bar_index)
if lotId > 0
    stopFill = strat.close_trade_at_stop("Stop", lotId, broker.Side.buy, open, high, low, lotStop)
    if not na(stopFill)
        lotId := 0
if lotId > 0 and crossedDown
    strat.close_trade("Exit", lotId)
    lotId := 0
if lotId == 0 and crossedUp
    entryFill = strat.entry("Long", "Cover", trade.Direction.long, notional = 1000.0)
    if not na(entryFill)
        lotId := entryFill.tradeId
        lotStop := close * 0.97
strat.mark()
```
