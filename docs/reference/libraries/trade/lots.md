Creates a coordinator that opens and closes separately accounted lots at once, within the current bar.

```tea
trade.lots(broker, portfolio)
```

| Parameter   | Description                                                                                                                              |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `broker`    | A broker with the [`broker.ImmediateBroker`](../broker/ImmediateBroker.md) methods, normally from [`broker.new`](../broker/new.md).      |
| `portfolio` | A portfolio with the [`portfolio.LotLedger`](../portfolio/LotLedger.md) methods, normally from [`portfolio.lots`](../portfolio/lots.md). |

**Returns:** `trade.LotTrade`: a coordinator that owns both values.

Each bar, call `begin_bar(close, bar_index)`, then `entry`, `close_trade` or
`close_trade_at_stop`, then `mark()`. Each entry fill carries the `tradeId`
that later closes name. A broker or portfolio without the required methods is
a compile error.

**Example:** The close crosses above its 3-bar average on bar 3, and lot 1 buys 500 of
notional, 5 units, at the close of 100, with a stop 3% below at 97. Bar 4's
low reaches the stop, which closes the lot at 97. Lot 2 opens at the next
cross, on bar 5, and closes at bar 7's close of 101, when the close crosses
back under the average.

```tea
import broker
import portfolio
import trade

basis = ta.sma(close, 3)
crossedUp = ta.crossover(close, basis)
crossedDown = ta.crossunder(close, basis)
var strat = trade.lots(broker.new(),
    portfolio.lots(initialCash = 1000.0))
var int lot = 0
var float lotStop = na
strat.begin_bar(close, bar_index)
if lot > 0
    stopFill = strat.close_trade_at_stop("Stop", lot, broker.Side.buy, open,
        high, low, lotStop)
    if not na(stopFill)
        lot := 0
if lot > 0 and crossedDown
    strat.close_trade("Exit", lot)
    lot := 0
if lot == 0 and crossedUp
    entryFill = strat.entry("Long", "Cover", trade.Direction.long,
        notional = 500.0)
    if not na(entryFill)
        lot := entryFill.tradeId
        lotStop := close * 0.97
strat.mark()
emit "close" close
emit "lot" lot
emit "cash" strat.cash()
emit "equity" strat.snapshot().equity
```
