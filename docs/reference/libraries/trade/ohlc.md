Creates a coordinator that matches orders and one stop/target exit against each bar's high-low range.

```tea
trade.ohlc(broker, portfolio)
```

| Parameter   | Description                                                                                                                            |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `broker`    | A broker with the [`broker.OhlcBroker`](../broker/OhlcBroker.md) methods, normally from [`broker.new`](../broker/new.md).              |
| `portfolio` | A portfolio with the [`portfolio.NetLedger`](../portfolio/NetLedger.md) methods, normally from [`portfolio.new`](../portfolio/new.md). |

**Returns:** A [`trade.OhlcTrade`](./OhlcTrade.md) that owns both values.

Each bar, call `begin_bar(open, high, low, bar_index)`, submit orders and
exits, then call `end_bar(close, false)`. Use [`trade.path`](./path.md) instead
when the order of the high and low matters or you need trailing exits.

```tea
import broker
import portfolio
import trade

upper = ta.highest(high, 20)

var strat = trade.ohlc(broker.new(), portfolio.new(initialCash = 10000.0))
strat.begin_bar(open, high, low, bar_index)
if strat.position_quantity() == 0.0 and not na(upper)
    // Resubmitting the same ids each bar moves the pending stop entry and its exit.
    strat.entry("Breakout", trade.Direction.long, qty = 10.0, stop = upper)
    strat.exit("Bracket", fromEntry = "Breakout", stop = upper * 0.95, target = upper * 1.1)
strat.end_bar(close, false)
```
