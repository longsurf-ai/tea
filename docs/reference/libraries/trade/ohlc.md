Creates a coordinator that matches orders and one stop-loss and/or take-profit exit against each bar's open, high and low.

```tea
trade.ohlc(broker, portfolio)
```

| Parameter   | Description                                                                                                                            |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `broker`    | A broker with the [`broker.OhlcBroker`](../broker/OhlcBroker.md) methods, normally from [`broker.new`](../broker/new.md).              |
| `portfolio` | A portfolio with the [`portfolio.NetLedger`](../portfolio/NetLedger.md) methods, normally from [`portfolio.new`](../portfolio/new.md). |

**Returns:** `trade.OhlcTrade`: a coordinator that owns both values.

Each bar, call `begin_bar(open, high, low, bar_index)`, submit orders and
exits, then call `end_bar(close, false)`. [`trade.path`](./path.md) replays the bar
as an ordered path instead and has trailing exits. A broker or portfolio
without the required methods is a compile error.

**Example:** From bar 2, a buy stop sits at the highest high of the last three bars, 125,
with an exit 5% below and 10% above it. Bar 3's high reaches 125 and buys 50%
of the 1000 equity, 4 units. Bar 5's high reaches the target of 137.5, which
sells them for a gain of 50.

```tea
import broker
import portfolio
import trade

upper = ta.highest(high, 3)
var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
matches = strat.begin_bar(open, high, low, bar_index)
if strat.position_quantity() == 0.0 and not na(upper)
    // The same ids move the pending stop entry and its exit each bar.
    strat.entry("Breakout", trade.Direction.long, stop = upper,
        sizing = trade.percentOfEquity(50.0))
    strat.exit("Bracket", fromEntry = "Breakout", stop = upper * 0.95,
        target = upper * 1.1)
strat.end_bar(close, false)
emit "high" high
emit "entry" na(matches.pending) ? na : matches.pending.price
emit "exit" na(matches.exit) ? na : matches.exit.price
emit "position" strat.position_quantity()
emit "equity" strat.snapshot().equity
```
