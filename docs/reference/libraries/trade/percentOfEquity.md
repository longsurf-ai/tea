Sizes an entry as a percentage of the portfolio's marked equity, read when `entry` is called.

```tea
trade.percentOfEquity(
    float percent,
    bool commissionIncluded = false
)
```

| Parameter            | Type    | Default | Description                                        |
| -------------------- | ------- | ------- | -------------------------------------------------- |
| `percent`            | `float` |         | Percentage of equity, above `0` and at most `100`. |
| `commissionIncluded` | `bool`  | `false` | Whether the budget also pays the commission.       |

**Returns:** A [`trade.Sizing`](./Sizing.md) for the `sizing` argument of `entry`.

Marked equity comes from the latest `mark` or `end_bar`, or is the initial
cash before the first one. With `commissionIncluded`, the commission is paid
out of the budget; otherwise it is charged on top. If the percentage is not
above `0` and at most `100`, or the marked equity is not positive, the
broker rejects the order when it would fill.
