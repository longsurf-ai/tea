Creates a coordinator whose orders fill at a later bar's open, or at a bar's close when the broker processes orders on close.

```tea
trade.nextOpen(broker, portfolio)
```

| Parameter   | Description                                                                                                                            |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `broker`    | A broker with the [`broker.NextOpenBroker`](../broker/NextOpenBroker.md) methods, normally from [`broker.new`](../broker/new.md).      |
| `portfolio` | A portfolio with the [`portfolio.NetLedger`](../portfolio/NetLedger.md) methods, normally from [`portfolio.new`](../portfolio/new.md). |

**Returns:** `trade.NextOpenTrade`: a coordinator that owns both values.

Each bar, call `begin_bar(open, bar_index)` before the signal logic and
`end_bar(close, false)` after it. With a broker created with
`processOrdersOnClose = true`, `end_bar` also fills orders at the close,
including orders submitted earlier in the same bar. A broker or portfolio
without the required methods is a compile error.

**Example:** A close above the highest of the three previous closes buys with 50% of
equity, and a close below the lowest of them sells. With
`processOrdersOnClose = true`, each order fills at the close of the bar that
sends it: the buy of 500 / 125 = 4 units at bar 3's close of 125, and the
sale at bar 6's close of 110.

```tea
import broker
import portfolio
import trade

highest = ta.highest(close, 3)
lowest = ta.lowest(close, 3)
var strat = trade.nextOpen(broker.new(processOrdersOnClose = true),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, bar_index)
if close > highest[1] and strat.position_quantity() == 0.0
    strat.entry("Breakout", trade.Direction.long,
        sizing = trade.percentOfEquity(50.0))
if close < lowest[1] and strat.position_quantity() > 0.0
    strat.close("Breakdown")
strat.end_bar(close, false)
emit "close" close
emit "position" strat.position_quantity()
emit "equity" strat.snapshot().equity
```
