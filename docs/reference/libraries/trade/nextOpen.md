Creates a coordinator whose orders fill at the next bar's open, or at this bar's close when enabled.

```tea
trade.nextOpen(broker, portfolio)
```

| Parameter   | Description                                                                                                                            |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `broker`    | A broker with the [`broker.NextOpenBroker`](../broker/NextOpenBroker.md) methods, normally from [`broker.new`](../broker/new.md).      |
| `portfolio` | A portfolio with the [`portfolio.NetLedger`](../portfolio/NetLedger.md) methods, normally from [`portfolio.new`](../portfolio/new.md). |

**Returns:** A [`trade.NextOpenTrade`](./NextOpenTrade.md) that owns both values.

Each bar, call `begin_bar(open, bar_index)` before your signal logic and
`end_bar(close, false)` after it. With a broker created with
`processOrdersOnClose = true`, `end_bar` also fills orders at the close,
including orders submitted earlier in the same bar. A broker or portfolio
without the required methods is a compile error.

```tea
import broker
import portfolio
import trade

upper = ta.highest(high, 20)
lower = ta.lowest(low, 20)

var strat = trade.nextOpen(
    broker.new(processOrdersOnClose = true),
    portfolio.new(initialCash = 10000.0)
)
strat.begin_bar(open, bar_index)
if close > upper[1] and strat.position_quantity() == 0.0
    strat.entry("Breakout", trade.Direction.long, sizing = trade.percentOfEquity(50.0))
if close < lower[1] and strat.position_quantity() > 0.0
    strat.close("Breakdown")
// processOrdersOnClose lets end_bar fill these orders at this bar's close.
strat.end_bar(close, false)
```
