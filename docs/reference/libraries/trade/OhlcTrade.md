Coordinator that matches orders, stop entries and one stop-loss and/or take-profit exit against each bar's open, high and low.

```tea
type OhlcTrade<B: broker.OhlcBroker, P: portfolio.NetLedger>
```

| Field          | Description                                                                                                                             |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `B broker`     | Broker that validates and fills this coordinator's orders.                                                                              |
| `P portfolio`  | Portfolio that records this coordinator's fills.                                                                                        |
| `int idx = -1` | Bar index from the latest `begin_bar`, or `-1` before the first; orders submitted later in the bar record it as their `signalBarIndex`. |

Create it with [`trade.ohlc`](./ohlc.md). Each bar, call `begin_bar`, submit orders
and exits, then call `end_bar`. `begin_bar` gives the matching rules,
including which level fills when the bar reaches both an exit's stop and its
target. [`trade.PathTrade`](./PathTrade.md) replays each bar as an ordered path instead,
so an exit only sees prices after its entry, and it adds trailing exits. The
broker holds one pending order and one attached exit at a time, and makes at
most two fills per bar. Strategies call these methods rather than the
broker's or the portfolio's own.

**Example:** The buy stop at 105 fills when bar 1's high reaches it. On bar 2 the range
reaches both exit levels; the high of 112 is nearer the open of 106 than the
low of 95 is, so the target of 111 fills.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
matches = strat.begin_bar(open, high, low, bar_index)
if bar_index == 0
    strat.entry("Breakout", trade.Direction.long, qty = 5.0,
        stop = 105.0)
    strat.exit("Bracket", fromEntry = "Breakout", stop = 96.0,
        target = 111.0)
strat.end_bar(close, false)
emit "open" open
emit "high" high
emit "low" low
emit "entry" na(matches.pending) ? na : matches.pending.price
emit "exit" na(matches.exit) ? na : matches.exit.price
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,100,102,98,101
1,101,106,100,105
2,106,112,95,100
3,100,101,99,100
```

**Output:**

```text
index  open  high  low  entry  exit  position
0      100   102   98   na     na    0
1      101   106   100  105    na    5
2      106   112   95   na     111   0
3      100   101   99   na     na    0
```

**See also:** [`trade.ohlc`](./ohlc.md), [`trade.PathTrade`](./PathTrade.md)

## Methods

### begin_bar

Starts a bar: fills the pending order, then the attached exit, against this bar's open, high and low.

```tea
broker.BarMatches begin_bar(
    float openPrice,
    float highPrice,
    float lowPrice,
    int barIndex
)
```

| Parameter   | Type    | Description                            |
| ----------- | ------- | -------------------------------------- |
| `openPrice` | `float` | The bar's open.                        |
| `highPrice` | `float` | The bar's high.                        |
| `lowPrice`  | `float` | The bar's low.                         |
| `barIndex`  | `int`   | The bar's index, normally `bar_index`. |

**Returns:** `broker.BarMatches`: `pending` holds the order's fill (after a reversal, the opening fill), `reversalClose` the closing fill of a reversal, and `exit` the exit's fill; each is `na` when absent. When a reversal's opening fill is rejected, `pending` holds the closing fill and `reversalClose` is `na`.

The pending order can fill from the bar after it was submitted. A market
order fills at the open. A stop entry fills at the open when the bar
opens at or past its stop, otherwise at the stop when the high, for a
buy, or the low, for a sell, reaches it. A reversal's opening fill
follows at the same price; one left waiting because the previous bar
already had two fills completes at this open.

The exit is then checked against the whole bar, from the bar after its
entry filled, or from the entry's own bar with `activateOnEntryBar` when
the entry filled at that bar's open. It
fills at the open when the bar opens at or past its stop or target,
otherwise at the level the range reaches, and closes the whole position.
When the range reaches both levels, the extreme nearer the open is taken
to come first: a long's target fills when the high is nearer the open
than the low, a short's target when the low is nearer than the high, and
otherwise the stop fills, including when both are equally far.

**Example:** The market entry fills at bar 1's open. On bar 2 the high and the low
are both 6 from the open of 100, so the stop of 95 fills rather than the
target of 105.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
matches = strat.begin_bar(open, high, low, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
    strat.exit("Bracket", fromEntry = "Long", stop = 95.0,
        target = 105.0)
strat.end_bar(close, false)
emit "open" open
emit "high" high
emit "low" low
emit "entry" na(matches.pending) ? na : matches.pending.price
emit "exit" na(matches.exit) ? na : matches.exit.price
emit "position" strat.position_quantity()
```

```csv

0,100,101,99,100
1,100,103,97,101
2,100,106,94,98
3,98,100,96,99
```

**Output:**

```text
index  open  high  low  entry  exit  position
0      100   101   99   na     na    0
1      100   103   97   100    na    5
2      100   106   94   na     95    0
3      98    100   96   na     na    0
```

### entry

Submits a market or stop entry order that opens, adds to or reverses the position on a later bar, or at a close when the broker processes orders on close.

```tea
broker.Order entry(
    string commandId,
    trade.Direction direction,
    float qty = na,
    trade.Sizing sizing = na,
    float stop = na
)
```

| Parameter   | Type              | Default | Description                                                                                                                                   |
| ----------- | ----------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `commandId` | `string`          |         | Name of the order; exits and `cancel` refer to it, and later entries that add to the position reuse it.                                       |
| `direction` | `trade.Direction` |         | `trade.Direction.long` to buy or `trade.Direction.short` to sell.                                                                             |
| `qty`       | `float`           | `na`    | Quantity to open or add; must be positive.                                                                                                    |
| `sizing`    | `trade.Sizing`    | `na`    | Percent-of-equity sizing from [`trade.percentOfEquity`](./percentOfEquity.md) or [`trade.percentOfEquityAtFill`](./percentOfEquityAtFill.md). |
| `stop`      | `float`           | `na`    | Stop price that makes this a stop entry, or `na` for a market order.                                                                          |

**Returns:** `broker.Order`: the accepted order, or `na` when the broker rejects it on submission.

Without `stop` it is a market order. With `stop` it fills once price
reaches the stop: a buy at or above it, a sell at or below it.
`begin_bar` and `process_close` give the fill prices. Resubmitting a
pending stop entry under the same `commandId` with a `stop` replaces it,
and an exit attached to it stays attached.

Sizing, reversals, adding to a position and the checks work as for
[`trade.NextOpenTrade.entry`](./NextOpenTrade.md#entry). Give at most one of `qty` and
`sizing`; without either, the entry spends all available capital. It
returns `na` when another order is pending, when an entry on the
position's side uses another `commandId`, or when `stop` is not positive.
Size, room under `pyramiding` and capital are checked when the order
would fill.

**Example:** The buy stop at 110 is not reached on bar 1, so the same id moves it to 105. Bar 2 opens at 106, past the stop, so the order fills at the open.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
matches = strat.begin_bar(open, high, low, bar_index)
if bar_index == 0
    strat.entry("Breakout", trade.Direction.long, qty = 5.0,
        stop = 110.0)
if bar_index == 1
    strat.entry("Breakout", trade.Direction.long, qty = 5.0,
        stop = 105.0)
strat.end_bar(close, false)
emit "open" open
emit "high" high
emit "fill" na(matches.pending) ? na : matches.pending.price
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,104,99,103
2,106,108,105,107
3,107,109,106,108
```

**Output:**

```text
index  open  high  fill  position
0      100   101   na    0
1      100   104   na    0
2      106   108   106   5
3      107   109   na    5
```

**See also:** [`trade.NextOpenTrade.entry`](./NextOpenTrade.md#entry)

### exit

Attaches a stop-loss and/or take-profit exit that closes the whole position opened by entry `fromEntry`.

```tea
broker.Order exit(
    string commandId,
    string fromEntry,
    float stop = na,
    float target = na,
    bool activateOnEntryBar = false
)
```

| Parameter            | Type     | Default | Description                                                                                               |
| -------------------- | -------- | ------- | --------------------------------------------------------------------------------------------------------- |
| `commandId`          | `string` |         | Name of the exit; `cancel` takes it.                                                                      |
| `fromEntry`          | `string` |         | `commandId` of the entry the exit belongs to.                                                             |
| `stop`               | `float`  | `na`    | Stop-loss price, or `na` for none.                                                                        |
| `target`             | `float`  | `na`    | Take-profit price, or `na` for none.                                                                      |
| `activateOnEntryBar` | `bool`   | `false` | Whether the exit may fill on the bar its entry fills; it applies when the entry fills at that bar's open. |

**Returns:** `broker.Order`: the accepted exit, or `na` when the broker rejects it on submission.

Give `stop`, `target` or both, positive; for a long the stop must be
below the target, for a short above it. `fromEntry` must name the pending
entry or the entry that opened the position. `begin_bar` checks the exit
from the bar after its entry fills, or from the entry's own bar with
`activateOnEntryBar`, and gives the fill prices. On the entry's own bar
it checks the whole bar only when the entry filled at the open: after a
stop entry that filled later in the bar, the high and low cannot tell
whether a level came before or after the entry, so the exit starts on
the next bar. [`trade.PathTrade`](./PathTrade.md) checks the rest of the bar instead.
Adverse
slippage applies to exit fills too, so a target is not a limit price.

One exit is attached at a time: resubmitting with the same `commandId`
and `fromEntry` replaces it, and another exit returns `na`, as do invalid
prices and a `fromEntry` that matches no entry. A fill that closes or
reverses the position cancels the exit, unless the exit is attached to
the reversing entry itself, and so does the failure of the pending entry
it is attached to.

**Example:** Both coordinators attach a stop at 97 to their pending entry. Bar 1's low
of 96 reaches it on the bar the entries fill: only the stop with
`activateOnEntryBar = true` fills there, and the other one fills on bar 2.

```tea
import broker
import portfolio
import trade

var later = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
var sameBar = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
a = later.begin_bar(open, high, low, bar_index)
b = sameBar.begin_bar(open, high, low, bar_index)
if bar_index == 0
    later.entry("Long", trade.Direction.long, qty = 5.0)
    later.exit("Stop", fromEntry = "Long", stop = 97.0)
    sameBar.entry("Long", trade.Direction.long, qty = 5.0)
    sameBar.exit("Stop", fromEntry = "Long", stop = 97.0,
        activateOnEntryBar = true)
later.end_bar(close, false)
sameBar.end_bar(close, false)
emit "open" open
emit "low" low
emit "later exit" na(a.exit) ? na : a.exit.price
emit "same bar exit" na(b.exit) ? na : b.exit.price
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,101,96,99
2,99,100,96,98
3,98,99,97,98
```

**Output:**

```text
index  open  low  later exit  same bar exit
0      100   99   na          na
1      100   96   na          97
2      99    96   97          na
3      98    97   na          na
```

### close

Submits an order that closes the whole position at a later bar's open, or at a close when the broker processes orders on close.

```tea
broker.Order close(string commandId)
```

| Parameter   | Type     | Description                           |
| ----------- | -------- | ------------------------------------- |
| `commandId` | `string` | Name of the order; `cancel` takes it. |

**Returns:** `broker.Order`: the accepted order, or `na` when another order is pending.

When it fills, it also cancels the attached exit. It returns `na` when
another order is pending; if the position is flat when it would fill, the
broker rejects it with `invalidAccountState`.

**Example:** The close sent on bar 1 sells the 5 units at bar 2's open of 104 and
cancels the attached stop, so nothing is pending afterward.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
    strat.exit("Stop", fromEntry = "Long", stop = 90.0)
if bar_index == 1
    strat.close("Exit")
strat.end_bar(close, false)
emit "open" open
emit "position" strat.position_quantity()
emit "pending" strat.has_pending() ? 1 : 0
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,103,99,102
2,104,105,103,104
3,104,106,103,105
```

**Output:**

```text

0      100   0         1
1      100   5         1
2      104   0         0
3      104   0         0
```

### rebalance

Submits an order that moves the position to a target size at a later bar's open, or at a close when the broker processes orders on close.

```tea
broker.Order rebalance(
    string commandId,
    broker.PositionTarget target
)
```

| Parameter   | Type                    | Description                                                                                                               |
| ----------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `commandId` | `string`                | Name of the order; `cancel` takes it.                                                                                     |
| `target`    | `broker.PositionTarget` | Target from [`trade.targetQuantity`](./targetQuantity.md) or [`trade.targetPercentOfEquity`](./targetPercentOfEquity.md). |

**Returns:** `broker.Order`: the accepted order, or `na` when the broker rejects it on submission.

It works as [`trade.NextOpenTrade.rebalance`](./NextOpenTrade.md#rebalance) does. When it fills,
the broker trades the difference between the target and the position in
one fill, and cancels the order when the difference is at most 0.0000001.
Unless the portfolio's `marginLong` is `0`, a buy from a flat or long
position is cut, without a rejection, to what the cash pays for; a sell
that opens or adds to a short, and a fill that crosses zero, must pass a
capital check. A fill that closes the position or crosses zero also
cancels the attached exit.

`pyramiding` never limits a rebalance. A rebalance that opens or reverses
the position counts as its first entry, and its `commandId` becomes the
position's entry id, which a later `entry` on that side must use and an
exit can name in `fromEntry`. A rebalance that adds to or reduces the
position leaves the entry id and the entry count unchanged.

**Example:** The 50% target buys 5 units at bar 1's open of 100. The rebalance's id
becomes the position's entry id, so a stop can name it in `fromEntry`;
the stop fills at 95 on bar 2.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
matches = strat.begin_bar(open, high, low, bar_index)
if bar_index == 0
    strat.rebalance("Alloc", trade.targetPercentOfEquity(50.0))
if bar_index == 1
    strat.exit("Stop", fromEntry = "Alloc", stop = 95.0)
strat.end_bar(close, false)
emit "low" low
emit "fill qty" na(matches.pending) ? na : matches.pending.quantity
emit "exit" na(matches.exit) ? na : matches.exit.price
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,102,98,101
2,101,102,94,96
3,96,97,95,96
```

**Output:**

```text
index  low  fill qty  exit  position
0      99   na        na    0
1      98   5         na    5
2      94   na        95    0
3      95   na        na    0
```

**See also:** [`trade.targetQuantity`](./targetQuantity.md), [`trade.targetPercentOfEquity`](./targetPercentOfEquity.md)

### cancel

Cancels the pending order or the attached exit named `commandId`.

```tea
int cancel(string commandId)
```

| Parameter   | Type     | Description                                |
| ----------- | -------- | ------------------------------------------ |
| `commandId` | `string` | Name the order or exit was submitted with. |

**Returns:** `int`: the number of orders cancelled, from `0` to `2`.

Cancelling a pending entry also cancels an exit attached to it, unless
that exit protects the open position of the same entry id.

**Example:** Cancelling the pending stop entry on bar 1 also cancels the stop attached
to it, so `cancel` returns 2, and bar 2's high of 108 fills nothing.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, bar_index)
int cancelled = na
if bar_index == 0
    strat.entry("Breakout", trade.Direction.long, qty = 5.0,
        stop = 105.0)
    strat.exit("Stop", fromEntry = "Breakout", stop = 95.0)
if bar_index == 1
    cancelled := strat.cancel("Breakout")
strat.end_bar(close, false)
emit "high" high
emit "cancelled" cancelled
emit "pending" strat.has_pending() ? 1 : 0
emit "position" strat.position_quantity()
```


### process_close

Fills the pending order at `closePrice` when the broker processes orders on close, and applies the fill.

```tea
broker.Fill process_close(float closePrice)
```

| Parameter    | Type    | Description      |
| ------------ | ------- | ---------------- |
| `closePrice` | `float` | The bar's close. |

**Returns:** `broker.Fill`: the last fill applied, or `na` when nothing filled.

Without `processOrdersOnClose = true` on the broker it fills nothing. A
market order fills at the close, and a stop entry fills at the close when
the close is at or past its stop. It never checks the attached exit; the
next `begin_bar` does. Use it with `mark` and `finish` in place of
`end_bar` to act between those steps: after one fill, a new order fills
at the same close with a second call. A bar has at most two fills.

**Example:** The buy stop at 104 is sent on bar 1, after `begin_bar`. The close of 105
is past the stop, so `process_close` fills it at the close, not at 104.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(processOrdersOnClose = true),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, bar_index)
float price = na
if bar_index == 1
    strat.entry("Long", trade.Direction.long, qty = 5.0, stop = 104.0)
    filled = strat.process_close(close)
    price := na(filled) ? na : filled.price
strat.mark(close)
emit "close" close
emit "fill price" price
emit "position" strat.position_quantity()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,106,99,105
2,105,107,104,106
3,106,108,105,107
```

**Output:**

```text
index  close  fill price  position
0      100    na          0
1      105    105         5
2      106    na          5
3      107    na          5
```

### mark

Values the portfolio at `price` and updates equity, peak equity and maximum drawdown.

```tea
float mark(float price)
```

| Parameter | Type    | Description                                                                                   |
| --------- | ------- | --------------------------------------------------------------------------------------------- |
| `price`   | `float` | Price to value the position at, normally [`close`](../../builtins/price-and-volume.md#close). |

**Returns:** `float`: the new equity.

Equity is cash plus the signed position times `price`. `end_bar` marks at
the close; call `mark` directly when using `process_close` and `finish`
instead.

**Example:** The 5 units bought at bar 1's open of 100 are valued at each close:
equity is 500 of cash plus 5 times the close.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
equity = strat.mark(close)
emit "close" close
emit "equity" equity
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,108,99,106
2,106,107,95,96
3,96,99,95,98
```

**Output:**

```text

0      100    1000

3      98     990
```

### finish

On the last bar, expires the pending order and the attached exit without closing the position.

```tea
broker.FinishResult finish(bool isLast)
```

| Parameter | Type   | Description                               |
| --------- | ------ | ----------------------------------------- |
| `isLast`  | `bool` | Whether this is the last bar of the data. |

**Returns:** `broker.FinishResult`: the expired order in `pending` and the expired exit in `exit`, or `na` when `isLast` is `false`.

Does nothing when `isLast` is `false`. Tea has no builtin that tells the
last bar, so the script has to know it, for example from an input.

**Example:** The buy stop at 110 is never reached. On the last bar, bar 3, `finish`
expires it, order 1, and the stop attached to it, order 2.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, bar_index)
isLast = bar_index == 3
if bar_index == 0
    strat.entry("Breakout", trade.Direction.long, qty = 5.0,
        stop = 110.0)
    strat.exit("Stop", fromEntry = "Breakout", stop = 95.0)
strat.process_close(close)
strat.mark(close)
expired = strat.finish(isLast)
emit "high" high
emit "expired entry" na(expired) ? na : expired.pending.id
emit "expired exit" na(expired) ? na : expired.exit.id
emit "pending" strat.has_pending() ? 1 : 0
```

```csv

0,100,101,99,100
1,100,102,99,101
2,101,103,100,102
3,102,104,101,103
```

**Output:**

```text
0      101   na             na            1
1      102   na             na            1
2      103   na             na            1
3      104   1              2             0
```

### end_bar

Ends the bar: runs `process_close`, `mark` and `finish` in that order.

```tea
broker.FinishResult end_bar(float closePrice, bool isLast)
```

| Parameter    | Type    | Description                               |
| ------------ | ------- | ----------------------------------------- |
| `closePrice` | `float` | The bar's close.                          |
| `isLast`     | `bool`  | Whether this is the last bar of the data. |

**Returns:** `broker.FinishResult`: the orders expired on the last bar, or `na` when `isLast` is `false`.

With `processOrdersOnClose = true` on the broker, the pending order can
fill at `closePrice`, including one submitted on this bar; the attached
exit is not checked. The portfolio is then marked at `closePrice`, and on
the last bar the pending order and the attached exit expire. Tea has no
builtin that tells the last bar, so pass `false` unless the script knows
it, for example from an input.

**Example:** Without close processing, the entry sent on bar 0 fills at bar 1's open
and equity is marked at each close. On the last bar, bar 3, the attached
stop expires: `end_bar` returns it, order 2.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, bar_index)
isLast = bar_index == 3
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
    strat.exit("Stop", fromEntry = "Long", stop = 90.0)
expired = strat.end_bar(close, isLast)
emit "close" close
emit "equity" strat.snapshot().equity
emit "expired exit" na(expired) ? na : expired.exit.id
emit "position" strat.position_quantity()
```

```csv

1,100,104,99,103
2,103,106,102,105
3,105,107,104,106
```

**Output:**


### cash

Returns the portfolio's cash balance.

```tea
float cash() const
```

**Returns:** `float`: the cash balance.

Every fill, an exit's included, changes it: a buy subtracts its notional
and commission, and a sell, including a short sale, adds its notional
and subtracts its commission.

**Example:** With a 1% commission, the stop entry buys 5 units at 105 for 525 + 5.25,
and the target exit sells them at 111 for 555 - 5.55.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(
    broker.new(commission = broker.commissionPercent(1.0)),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, bar_index)
if bar_index == 0
    strat.entry("Breakout", trade.Direction.long, qty = 5.0,
        stop = 105.0)
    strat.exit("Target", fromEntry = "Breakout", target = 111.0)
strat.end_bar(close, false)
emit "high" high
emit "cash" strat.cash()
```

```csv
time,open,high,low,close
0,100,102,98,101
1,101,106,100,105
2,106,112,104,110
3,110,111,108,109
```

**Output:**

```text
index  high  cash
0      102   1000
1      106   469.75
2      112   1019.2
3      111   1019.2
```

### position_avg_price

Returns the average entry price of the open position, or `na` when flat.

```tea
float position_avg_price() const
```

**Returns:** `float`: the average entry price, or `na` when flat.

It is the quantity-weighted mean of the execution prices, after slippage,
of the fills that opened and added to the position; a fill that reduces
the position does not change it.

**Example:** With `pyramiding = 2`, a market entry buys 5 units at bar 1's open of 100
and a stop entry adds 5 at 106; the average is 103.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 2000.0, pyramiding = 2))
strat.begin_bar(open, high, low, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 1
    strat.entry("Long", trade.Direction.long, qty = 5.0, stop = 106.0)
strat.end_bar(close, false)
emit "high" high
emit "position" strat.position_quantity()
emit "average" strat.position_avg_price()
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,104,99,103
2,103,108,102,107
3,107,109,106,108
```

**Output:**

```text
index  high  position  average
0      101   0         na
1      104   5         100
2      108   10        103
3      109   10        103
```

### snapshot

Returns the portfolio's metrics as one [`portfolio.PortfolioSnapshot`](../portfolio/PortfolioSnapshot.md).

```tea
portfolio.PortfolioSnapshot snapshot() const
```

**Returns:** `portfolio.PortfolioSnapshot`: cash, position, equity, profit and risk statistics.

Its `equity` is from the latest `mark` or `end_bar`, so before `end_bar`
it still holds the previous bar's value.

**Example:** The stop exit sells the 5 units bought at 100 for 97, so the round trip
realizes -15 and counts as a loss.

```tea
import broker
import portfolio
import trade

var strat = trade.ohlc(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, high, low, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
    strat.exit("Stop", fromEntry = "Long", stop = 97.0)
strat.end_bar(close, false)
metrics = strat.snapshot()
emit "low" low
emit "equity" metrics.equity
emit "realized" metrics.realizedPnl
emit "round trips" metrics.roundTripCount
emit "win rate" metrics.winRate
```

```csv
time,open,high,low,close
0,100,101,99,100
1,100,102,98,101
2,101,102,96,98
3,98,99,97,98
```

**Output:**

```text
index  low  equity  realized  round trips  win rate

1      98   1005    0         0            0

```
