Side of a new position: long or short.

```tea
enum Direction
```

| Member  | Description                          |
| ------- | ------------------------------------ |
| `long`  | A long position, opened by buying.   |
| `short` | A short position, opened by selling. |

A coordinator's `entry` buys for `long` and sells for `short`. A short sale
adds its proceeds to cash, and equity is cash plus the signed position times
the mark price, so a short loses equity as the price rises.

**Example:** Two coordinators enter 5 units at bar 1's open of 100, one long and one
short. The short sale adds 500 to cash, and the short's equity falls as the
close rises: 980 at 104 and 950 at 110.

```tea
import broker
import portfolio
import trade

var buyer = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
var seller = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
buyer.begin_bar(open, bar_index)
seller.begin_bar(open, bar_index)
if bar_index == 0
    buyer.entry("Long", trade.Direction.long, qty = 5.0)
    seller.entry("Short", trade.Direction.short, qty = 5.0)
buyer.end_bar(close, false)
seller.end_bar(close, false)
emit "close" close
emit "long equity" buyer.snapshot().equity
emit "short position" seller.position_quantity()
emit "short cash" seller.cash()
emit "short equity" seller.snapshot().equity
```
