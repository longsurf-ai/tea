Coordinator whose orders fill at a later bar's open, or at a bar's close when the broker processes orders on close.

```tea
type NextOpenTrade<B: broker.NextOpenBroker, P: portfolio.NetLedger>
```

| Field          | Description                                                                                                                             |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `B broker`     | Broker that validates and fills this coordinator's orders.                                                                              |
| `P portfolio`  | Portfolio that records this coordinator's fills.                                                                                        |
| `int idx = -1` | Bar index from the latest `begin_bar`, or `-1` before the first; orders submitted later in the bar record it as their `signalBarIndex`. |

Create it with [`trade.nextOpen`](./nextOpen.md). Each bar, call `begin_bar` before the
signal logic, submit orders, then call `end_bar`. An order fills at the open
of a bar after the one it was submitted on. With a broker created with
`processOrdersOnClose = true`, it can also fill at a close, including the
close of its own bar. The broker holds one pending order at a time and makes
at most two fills per bar; this family has no stop entries and no attached
exits. Strategies call these methods rather than the broker's or the
portfolio's own.

**Example:** The entry sent on bar 0 fills at bar 1's open of 100, and the close sent on
bar 2 fills at bar 3's open of 120. Equity is marked at each close.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 2
    strat.close("Exit")
strat.end_bar(close, false)
emit "open" open
emit "close" close
emit "position" strat.position_quantity()
emit "cash" strat.cash()
emit "equity" strat.snapshot().equity
```

```csv
time,open,close
0,100,100
1,100,110
2,110,115
3,120,125
4,125,130
```

**Output:**

```text
index  open  close  position  cash  equity
0      100   100    0         1000  1000
1      100   110    5         500   1050
2      110   115    5         500   1075
3      120   125    0         1100  1100
4      125   130    0         1100  1100
```

## Methods

### begin_bar

Starts a bar: fills the pending order at `openPrice` and applies the fill to the portfolio.

```tea
broker.Fill begin_bar(float openPrice, int barIndex)
```

| Parameter   | Type    | Description                            |
| ----------- | ------- | -------------------------------------- |
| `openPrice` | `float` | The bar's open.                        |
| `barIndex`  | `int`   | The bar's index, normally `bar_index`. |

**Returns:** `broker.Fill`: the last fill applied, which for a reversal is the opening fill, or `na` when nothing filled.

Call it once per bar, before the signal logic. An order can fill here
from the bar after it was submitted, so orders submitted later in this
bar wait. An entry against the open position fills twice at this open:
once to close the position, then once to open the new side. A reversal
whose opening fill did not fit in an earlier bar's two fills completes
here.

**Example:** The entry sent on bar 0 fills at bar 1's open. The short entry sent on
bar 2 reverses the position at bar 3's open: it sells the 5 units, then 2
more to open the short, and `begin_bar` returns that last fill.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
filled = strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 2
    strat.entry("Short", trade.Direction.short, qty = 2.0)
strat.end_bar(close, false)
emit "open" open
emit "fill qty" na(filled) ? na : filled.quantity
emit "fill price" na(filled) ? na : filled.price
emit "position" strat.position_quantity()
```

```csv
time,open,close
0,100,100
1,100,110
2,110,115
3,120,125
```

**Output:**

```text
index  open  fill qty  fill price  position
0      100   na        na          0
1      100   5         100         5
2      110   na        na          5
3      120   2         120         -2
```

### entry

Submits an entry order that opens, adds to or reverses the position at a later bar's open, or at a close when the broker processes orders on close.

```tea
broker.Order entry(
    string commandId,
    trade.Direction direction,
    float qty = na,
    trade.Sizing sizing = na
)
```

| Parameter   | Type              | Default | Description                                                                                                                                   |
| ----------- | ----------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `commandId` | `string`          |         | Name of the order; `cancel` takes it, and later entries that add to the position reuse it.                                                    |
| `direction` | `trade.Direction` |         | `trade.Direction.long` to buy or `trade.Direction.short` to sell.                                                                             |
| `qty`       | `float`           | `na`    | Quantity to open or add; must be positive.                                                                                                    |
| `sizing`    | `trade.Sizing`    | `na`    | Percent-of-equity sizing from [`trade.percentOfEquity`](./percentOfEquity.md) or [`trade.percentOfEquityAtFill`](./percentOfEquityAtFill.md). |

**Returns:** `broker.Order`: the accepted order, or `na` when the broker rejects it on submission.

Give at most one of `qty` and `sizing`. With neither, the entry spends
all available capital, commission included: the cash for a buy, the
equity for a sell. The quantity is `qty`, or the sizing budget divided by
the execution price, the matched price after adverse slippage, once any
commission the sizing includes is taken out ([`trade.percentOfEquity`](./percentOfEquity.md)
gives the formula).

An entry against the open position reverses it with two fills: the first
closes the whole position, and the second opens the new side at the same
price, or at the next open when the first was the bar's second fill. An
entry without a size, or sized with [`trade.percentOfEquityAtFill`](./percentOfEquityAtFill.md),
is sized from the account after the first fill, and a per-order
commission is charged on the first fill only. If the second fill is
rejected, the position is left flat. An entry on the position's side adds
to it only under the `commandId` of the entry that opened it, and only
while the position has fewer entries than the portfolio's `pyramiding`.

On submission the broker checks only the pending order and the id: the
method returns `na` when another order is pending, or when an entry on
the position's side uses another `commandId` (`entryIdMismatch`). The
rest is checked when the order would fill, and a rejection then shows
only as a [`broker.OrderRejected`](../broker/OrderRejected.md) event:

- `invalidQuantity` for both `qty` and `sizing`, a `qty` that is not
  positive, or invalid sizing;
- `invalidAccountState` for an add with no room under `pyramiding`, or
  for too little capital. Unless the portfolio's margin for the order's
  side is `0`, an order with `qty` or `sizing` needs
  `notional * marginLong / 100 + fee <= cash` for a buy and
  `notional * marginShort / 100 + fee <= equity` for a sell, with equity
  valued at the matched price; with the commission included in percent
  sizing, the budget must fit instead. An order with neither needs
  capital above `0`.

**Example:** On bar 0 the first entry is accepted as order 1, and the second returns
`na` because the first is pending. The first buys 50% of the 1000 equity,
500 / 100 = 5 units, at bar 1's open. The short entry sent on bar 2,
without a size, reverses at bar 3's open of 125: it sells the 5 units,
then sells short the whole equity of 1125, 9 units.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
filled = strat.begin_bar(open, bar_index)
int firstId = na
int secondId = na
if bar_index == 0
    first = strat.entry("Long", trade.Direction.long,
        sizing = trade.percentOfEquity(50.0))
    second = strat.entry("Other", trade.Direction.long, qty = 1.0)
    firstId := na(first) ? na : first.id
    secondId := na(second) ? na : second.id
if bar_index == 2
    strat.entry("Short", trade.Direction.short)
strat.end_bar(close, false)
emit "open" open
emit "first id" firstId
emit "second id" secondId
emit "fill qty" na(filled) ? na : filled.quantity
emit "position" strat.position_quantity()
```

```csv
time,open,close
0,100,100
1,100,110
2,110,120
3,125,125
```

**Output:**

```text
index  open  first id  second id  fill qty  position
0      100   1         na         na        0
1      100   na        na         5         5
2      110   na        na         na        5
3      125   na        na         9         -9
```

### close

Submits an order that closes the whole position at a later bar's open, or at a close when the broker processes orders on close.

```tea
broker.Order close(string commandId)
```

| Parameter   | Type     | Description                           |
| ----------- | -------- | ------------------------------------- |
| `commandId` | `string` | Name of the order; `cancel` takes it. |

**Returns:** `broker.Order`: the accepted order, or `na` when another order is pending.

It closes whatever position is open when it fills. It returns `na` when
another order is pending; if the position is flat when it would fill, the
broker rejects it with `invalidAccountState`.

**Example:** The close sent on bar 2 sells all 5 units at bar 3's open of 120 and
realizes 5 \* (120 - 100) = 100.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 2
    strat.close("Exit")
strat.end_bar(close, false)
emit "open" open
emit "position" strat.position_quantity()
emit "cash" strat.cash()
emit "realized" strat.snapshot().realizedPnl
```

```csv
time,open,close
0,100,100
1,100,110
2,110,115
3,120,125
```

### rebalance

Submits an order that moves the position to a target size at a later bar's open, or at a close when the broker processes orders on close.

```tea
broker.Order rebalance(
    string commandId,
    broker.PositionTarget target
)
```

| Parameter   | Type                    | Description                                                                                                               |
| ----------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `commandId` | `string`                | Name of the order; `cancel` takes it.                                                                                     |
| `target`    | `broker.PositionTarget` | Target from [`trade.targetQuantity`](./targetQuantity.md) or [`trade.targetPercentOfEquity`](./targetPercentOfEquity.md). |

**Returns:** `broker.Order`: the accepted order, or `na` when the broker rejects it on submission.

When it fills, the broker trades the difference between the target and
the position at that moment, in one fill even when the target is on the
other side of zero, and cancels the order when the difference is at most
0.0000001. Submitting again under the same `commandId` while the order is
pending replaces the target. It returns `na` when another order is
pending, when the target or its value is `na`, or when a percent target
is beyond `100` in either direction.

The position can stop short of the target. Unless the portfolio's
`marginLong` is `0`, a buy from a flat or long position is cut, without a
rejection, to the quantity whose notional plus commission spends the
cash. A sell that opens or adds to a short, and a fill that crosses zero,
must pass a capital check, or the broker rejects it with
`invalidAccountState`; [`trade.targetQuantity`](./targetQuantity.md) gives the rules.

`pyramiding` never limits a rebalance. A rebalance that opens or reverses
the position counts as its first entry, and its `commandId` becomes the
position's entry id, so a later `entry` on that side must use that id or
returns `na` (`entryIdMismatch`). A rebalance that adds to or reduces the
position leaves the entry id and the entry count unchanged, and one that
closes it clears them.

**Example:** Bar 1 buys the 4 units of the first target. The target of 20 needs 16
more, but the 600 of cash buys only 6, so bar 2 stops at 10 units without
a rejection. The target of -2 sells 12 units in one fill at bar 3's open.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
filled = strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.rebalance("Target", trade.targetQuantity(4.0))
if bar_index == 1
    strat.rebalance("Target", trade.targetQuantity(20.0))
if bar_index == 2
    strat.rebalance("Target", trade.targetQuantity(-2.0))
strat.end_bar(close, false)
emit "open" open
emit "fill qty" na(filled) ? na : filled.quantity
emit "position" strat.position_quantity()
emit "cash" strat.cash()
```

```csv
time,open,close
0,100,100
1,100,100
2,100,100
3,120,120
```

**Output:**

```text
index  open  fill qty  position  cash
0      100   na        0         1000
1      100   4         4         600
2      100   6         10        0
3      120   12        -2        1440
```

**Example:** The rebalance opens the position at bar 1, counts as its first entry and
gives it the id `Target`. An entry named `Long` then returns `na`; one
named `Target` is accepted and adds the second entry that
`pyramiding = 2` allows.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0, pyramiding = 2))
strat.begin_bar(open, bar_index)
int accepted = na
if bar_index == 0
    strat.rebalance("Target", trade.targetQuantity(5.0))
if bar_index == 1
    order = strat.entry("Long", trade.Direction.long, qty = 1.0)
    accepted := na(order) ? 0 : 1
if bar_index == 2
    order = strat.entry("Target", trade.Direction.long, qty = 1.0)
    accepted := na(order) ? 0 : 1
strat.end_bar(close, false)
emit "accepted" accepted
emit "position" strat.position_quantity()
emit "entries" strat.snapshot().openTradeCount
```

```csv
time,open,close
0,100,100
1,100,100
2,100,100
3,100,100
```

**Output:**

```text
index  accepted  position  entries
0      na        0         0
1      0         5         1
2      1         5         1
3      na        6         2
```

**See also:** [`trade.targetQuantity`](./targetQuantity.md), [`trade.targetPercentOfEquity`](./targetPercentOfEquity.md)

### cancel

Cancels the pending order named `commandId`.

```tea
int cancel(string commandId)
```

| Parameter   | Type     | Description                        |
| ----------- | -------- | ---------------------------------- |
| `commandId` | `string` | Name the order was submitted with. |

**Returns:** `int`: `1` when the pending order had that name, otherwise `0`.

**Example:** No pending order is named `Short`, so that call returns 0. Cancelling

### process_close

Fills the pending order at `closePrice` when the broker processes orders on close, and applies the fill.

```tea
broker.Fill process_close(float closePrice)
```

| Parameter    | Type    | Description      |
| ------------ | ------- | ---------------- |
| `closePrice` | `float` | The bar's close. |

**Returns:** `broker.Fill`: the last fill applied, or `na` when nothing filled.

Without `processOrdersOnClose = true` on the broker it fills nothing. Use
it with `mark` and `finish` in place of `end_bar` to act between those
steps: after one fill at the close, a new order submitted on the same bar
fills at the same close with a second call. A bar has at most two fills;
a third order waits for the next open, and so does the opening fill of a
reversal that would be the third.

**Example:** On bar 1, the entry fills at the close of 110, and a close sent next
fills at the same close: the bar's two fills. The third order waits and
fills at bar 2's open of 112.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(processOrdersOnClose = true),
    portfolio.new(initialCash = 1000.0))
opened = strat.begin_bar(open, bar_index)
float first = na
float second = na
float third = na
if bar_index == 1
    strat.entry("Long", trade.Direction.long, qty = 5.0)
    a = strat.process_close(close)
    strat.close("Exit")
    b = strat.process_close(close)
    strat.entry("Long", trade.Direction.long, qty = 2.0)
    c = strat.process_close(close)
    first := na(a) ? na : a.quantity
    second := na(b) ? na : b.quantity
    third := na(c) ? na : c.quantity
strat.mark(close)
emit "close" close
emit "first" first
emit "second" second
emit "third" third
emit "at open" na(opened) ? na : opened.quantity
emit "position" strat.position_quantity()
```

```csv

0,100,100
1,100,110
2,112,115
3,115,118
```

**Output:**

```text
index  close  first  second  third  at open  position
0      100    na     na      na     na       0
1      110    5      5       na     na       0
2      115    na     na      na     2        2
3      118    na     na      na     na       2
```

### mark

Values the portfolio at `price` and updates equity, peak equity and maximum drawdown.

```tea
float mark(float price)
```

| Parameter | Type    | Description                                                                                   |
| --------- | ------- | --------------------------------------------------------------------------------------------- |
| `price`   | `float` | Price to value the position at, normally [`close`](../../builtins/price-and-volume.md#close). |

**Returns:** `float`: the new equity.

Equity is cash plus the signed position times `price`. `end_bar` marks at
the close; call `mark` directly when using `process_close` and `finish`
instead.

**Example:** The 5 units bought at 100 are valued at each close. Equity peaks at 1050
and falls to 950, a drawdown of 100 / 1050.

```tea
if bar_index == 0

emit "close" close
```

### finish

On the last bar, expires the pending order without closing the position.

```tea
broker.FinishResult finish(bool isLast)
```

| Parameter | Type   | Description                               |
| --------- | ------ | ----------------------------------------- |
| `isLast`  | `bool` | Whether this is the last bar of the data. |

**Returns:** `broker.FinishResult`: the expired order in `pending`, or `na` when `isLast` is `false`.

Does nothing when `isLast` is `false`. Tea has no builtin that tells the
last bar, so the script has to know it, for example from an input.

**Example:** Bar 3 is the last bar. The close sent there can no longer fill, so
`finish` expires it, order 2, and the 5 units stay open.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, bar_index)
isLast = bar_index == 3
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if isLast
    strat.close("Exit")
strat.mark(close)
expired = strat.finish(isLast)
emit "expired" na(expired) ? na : expired.pending.id
emit "position" strat.position_quantity()
emit "pending" strat.has_pending() ? 1 : 0
```

```csv
time,open,close
0,100,100
1,100,110
2,110,120
3,120,130
```

**Output:**

```text
index  expired  position  pending
0      na       0         1
1      na       5         0
2      na       5         0
3      2        5         0
```

### end_bar

Ends the bar: runs `process_close`, `mark` and `finish` in that order.

```tea
broker.FinishResult end_bar(float closePrice, bool isLast)
```

| Parameter    | Type    | Description                               |
| ------------ | ------- | ----------------------------------------- |
| `closePrice` | `float` | The bar's close.                          |
| `isLast`     | `bool`  | Whether this is the last bar of the data. |

**Returns:** `broker.FinishResult`: the orders expired on the last bar, or `na` when `isLast` is `false`.

With `processOrdersOnClose = true` on the broker, the pending order can
fill at `closePrice`, including one submitted on this bar. The portfolio
is then marked at `closePrice`, and on the last bar the pending order
expires. Tea has no builtin that tells the last bar, so pass `false`
unless the script knows it, for example from an input.

**Example:** With `processOrdersOnClose = true`, the entry sent on bar 1 fills at that
bar's close of 110 before equity is marked, and the close sent on bar 2
fills at 120.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(processOrdersOnClose = true),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, bar_index)
if bar_index == 1
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 2
    strat.close("Exit")
strat.end_bar(close, false)
emit "close" close
emit "position" strat.position_quantity()
emit "cash" strat.cash()
emit "equity" strat.snapshot().equity
```

### cash

Returns the portfolio's cash balance.

```tea
float cash() const
```

**Returns:** `float`: the cash balance.

A buy subtracts its notional and commission; a sell, including a short
sale, adds its notional and subtracts its commission.

**Example:** With a 1% commission, buying 5 units at 100 takes 500 + 5 from cash, and
selling them at 110 adds 550 - 5.5.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(
    broker.new(commission = broker.commissionPercent(1.0)),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 1
    strat.close("Exit")
strat.end_bar(close, false)
emit "open" open
emit "cash" strat.cash()
```

```csv
3,110,112
```

### position_avg_price

Returns the average entry price of the open position, or `na` when flat.

```tea
float position_avg_price() const
```

**Returns:** `float`: the average entry price, or `na` when flat.

It is the quantity-weighted mean of the execution prices, after slippage,
of the fills that opened and added to the position; a fill that reduces
the position does not change it.

**Example:** With 1% slippage and `pyramiding = 2`, 5 units bought at 101 (open 100)
and 5 more at 111.1 (open 110) average 106.05. The close at bar 3 leaves
`na`.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(
    broker.new(slippage = broker.slippagePercent(1.0)),
    portfolio.new(initialCash = 2000.0, pyramiding = 2))
strat.begin_bar(open, bar_index)
if bar_index <= 1
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 2
    strat.close("Exit")
strat.end_bar(close, false)
emit "open" open
emit "position" strat.position_quantity()
emit "average" strat.position_avg_price()
```

```csv
time,open,close
0,100,100
1,100,110
2,110,110
3,120,120
```

**Output:**

```text
index  open  position  average
0      100   0         na
1      100   5         101
2      110   10        106.05
3      120   0         na
```

### snapshot

Returns the portfolio's metrics as one [`portfolio.PortfolioSnapshot`](../portfolio/PortfolioSnapshot.md).

```tea
portfolio.PortfolioSnapshot snapshot() const
```

**Returns:** `portfolio.PortfolioSnapshot`: cash, position, equity, profit and risk statistics.

Its `equity` is from the latest `mark` or `end_bar`, so before `end_bar`
it still holds the previous bar's value.

**Example:** One round trip, 5 units bought at 100 and sold at 120, realizes 100 and
counts as a win.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 2
    strat.close("Exit")
strat.end_bar(close, false)
metrics = strat.snapshot()
emit "equity" metrics.equity
emit "realized" metrics.realizedPnl
emit "round trips" metrics.roundTripCount
emit "win rate" metrics.winRate
```

```csv
time,open,close
0,100,100
1,100,110
2,110,115
3,120,125
```

**Output:**

```text
index  equity  realized  round trips  win rate
0      1000    0         0            0
1      1050    0         0            0
2      1075    0         0            0
3      1100    100       1            1
```

### has_pending

Returns whether an order is pending.

```tea
bool has_pending() const
```

**Returns:** `bool`: `true` from submission until the order fills, is rejected when it would fill, is cancelled or expires.

**Example:** The entry sent on bar 0 is pending until it fills at bar 1's open.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
strat.end_bar(close, false)
emit "pending" strat.has_pending() ? 1 : 0
emit "position" strat.position_quantity()
```

```csv
time,open,close
0,100,100
1,100,110
2,110,120
3,120,125
```

**Output:**

```text
index  pending  position
0      1        0
1      0        5
2      0        5
3      0        5
```

### has_pending_entry

Returns whether the pending order is an entry.

```tea
bool has_pending_entry() const
```

**Returns:** `bool`: `true` when an entry is pending; `false` for a pending close or rebalance, or when nothing is pending.

**Example:** The entry pending after bar 0 counts; the close pending after bar 2 does
not, although `has_pending` is true for both.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 2
    strat.close("Exit")
strat.end_bar(close, false)
emit "pending" strat.has_pending() ? 1 : 0
emit "pending entry" strat.has_pending_entry() ? 1 : 0
```

```csv
time,open,close
0,100,100
1,100,110
2,110,115
3,120,125
```

**Output:**

```text
index  pending  pending entry
0      1        1
1      0        0
2      1        0
3      0        0
```
