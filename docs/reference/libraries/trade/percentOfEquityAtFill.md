Sizes an entry as a percentage of the equity at the moment the order fills.

```tea
trade.percentOfEquityAtFill(
    float percent,
    bool commissionIncluded = false
)
```

| Parameter            | Type    | Default | Description                                        |
| -------------------- | ------- | ------- | -------------------------------------------------- |
| `percent`            | `float` |         | Percentage of equity, above `0` and at most `100`. |
| `commissionIncluded` | `bool`  | `false` | Whether the budget also pays the commission.       |

**Returns:** `trade.Sizing`: sizing for the `sizing` argument of `entry`.

The broker values equity as cash plus the position at the matched price,
before slippage; for the opening fill of a reversal, that is after the
closing fill, with no position left. The quantity is the budget divided by
the execution price, the matched price after adverse slippage, once an
included commission is taken out, and the capital check of
[`trade.percentOfEquity`](./percentOfEquity.md) applies. When the order would fill, the broker
rejects it with `invalidQuantity` for a `percent` of `0` or less, above
`100` or `na`, and with `invalidAccountState` when that equity is not
positive.

In the formula, Q is the position just before the fill, r the matched price,
B the budget, q the quantity, x the execution price and c the commission
setting. The opening fill of a reversal pays no per-order commission, as the
closing fill already did.

**Formula**

$$
\begin{aligned}
E &= \mathit{cash} + Q \cdot r \\
B &= \frac{\mathit{percent}}{100} \cdot E \\
q &= \begin{cases}
B / x & \text{commission on top} \\
B / \bigl(x\,(1 + c)\bigr) & \text{included, commission rate } c \\
B / (x + c) & \text{included, } c \text{ per contract} \\
(B - c) / x & \text{included, } c \text{ per order}
\end{cases}
\end{aligned}
$$

**Example:** The short entry sent on bar 2 reverses the long at bar 3's open of 125.
Selling the 5 units leaves 1125 of cash and no position, so 50% of equity at
the fill is 562.5, which sells 562.5 / 125 = 4.5 units short.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(),
    portfolio.new(initialCash = 1000.0))
filled = strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 5.0)
if bar_index == 2
    strat.entry("Short", trade.Direction.short,
        sizing = trade.percentOfEquityAtFill(50.0))
strat.end_bar(close, false)
emit "open" open
emit "fill qty" na(filled) ? na : filled.quantity
emit "position" strat.position_quantity()
emit "cash" strat.cash()
```
