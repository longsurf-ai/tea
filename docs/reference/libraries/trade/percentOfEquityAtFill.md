Sizes an entry as a percentage of equity at the moment the order fills.

```tea
trade.percentOfEquityAtFill(
    float percent,
    bool commissionIncluded = false
)
```

| Parameter            | Type    | Default | Description                                        |
| -------------------- | ------- | ------- | -------------------------------------------------- |
| `percent`            | `float` |         | Percentage of equity, above `0` and at most `100`. |
| `commissionIncluded` | `bool`  | `false` | Whether the budget also pays the commission.       |

**Returns:** A [`trade.Sizing`](./Sizing.md) for the `sizing` argument of `entry`.

The broker values equity as cash plus the position at the matched price
before slippage; when the entry reverses a position, that is after the
closing fill. With `commissionIncluded`, the commission is paid out of the
budget; otherwise it is charged on top. If the percentage is not above `0`
and at most `100`, the broker rejects the order when it would fill.
