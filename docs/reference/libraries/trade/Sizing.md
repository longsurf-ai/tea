Percent-of-equity sizing for an entry, made by [`trade.percentOfEquity`](./percentOfEquity.md) or [`trade.percentOfEquityAtFill`](./percentOfEquityAtFill.md).

```tea
type Sizing
```

| Field                             | Description                                                                                  |
| --------------------------------- | -------------------------------------------------------------------------------------------- |
| `trade.SizingKind kind`           | Which equity the percentage is taken from.                                                   |
| `float value`                     | Value of the order as a percentage of equity; valid values are above `0` and at most `100`.  |
| `bool commissionIncluded = false` | Whether the budget also pays the commission; when `false`, the commission is charged on top. |

Pass it as the `sizing` argument of `entry` on [`trade.NextOpenTrade`](./NextOpenTrade.md),
[`trade.OhlcTrade`](./OhlcTrade.md) or [`trade.PathTrade`](./PathTrade.md). Nothing is checked when
it is made: if `value` is `0` or less, above `100` or `na`, the broker
rejects the order with `invalidQuantity` when it would fill.

**Example:** The helpers only fill in the fields, even with an out-of-range 150.

```tea
import trade

marked = trade.percentOfEquity(25.0)
atFill = trade.percentOfEquityAtFill(150.0, true)
emit "marked value" marked.value
emit "marked included" marked.commissionIncluded ? 1 : 0
emit "at fill value" atFill.value
emit "at fill included" atFill.commissionIncluded ? 1 : 0
atFillKind = atFill.kind == trade.SizingKind.percentOfEquityAtFill
emit "at fill kind" atFillKind ? 1 : 0
```

**Output:**

```text
index  marked value  marked included  at fill value  at fill included  at fill kind
0      25            0                150            1                 1
```
