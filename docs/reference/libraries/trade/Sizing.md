Percent-of-equity sizing for an entry.

```tea
type Sizing
```

| Field                             | Description                                                                                                                       |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `trade.SizingKind kind`           | Which equity the percentage is taken from.                                                                                        |
| `float value`                     | Position value as a percentage of equity, above `0` and at most `100`. The broker rejects other values when the order would fill. |
| `bool commissionIncluded = false` | Whether the budget also pays the commission; when `false`, commission is charged on top.                                          |

Create it with [`trade.percentOfEquity`](./percentOfEquity.md) or
[`trade.percentOfEquityAtFill`](./percentOfEquityAtFill.md) and pass it as the `sizing` argument of a
coordinator's `entry`.
