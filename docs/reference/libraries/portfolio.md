Portfolios that apply a strategy's fills and track its cash, position, equity, profit and loss, and drawdown.

Add `import portfolio` together with `import broker` and `import trade`.
Create a portfolio with [`portfolio.new`](./portfolio/new.md) for one net position, or with
[`portfolio.lots`](./portfolio/lots.md) for separately tracked lots, and pass it with a
broker to a coordinator such as [`trade.nextOpen`](./trade/nextOpen.md), whose page shows a
complete strategy. The coordinator applies every [`broker.Fill`](./broker/Fill.md) to the
portfolio and values the position at a mark price, normally each bar's
close. Read the results with the coordinator's `snapshot()`, which returns
a [`portfolio.PortfolioSnapshot`](./portfolio/PortfolioSnapshot.md).

A portfolio never decides whether, when or at what price an order fills.
Commission and slippage are broker settings, such as
[`broker.commissionRate`](./broker/commissionRate.md) and [`broker.slippageRate`](./broker/slippageRate.md), and each
fill arrives with its price and commission already set.

The interfaces list the methods a coordinator, or code that only reads
results, needs from a portfolio. A type satisfies one when it has every
listed method with the same parameter types, result type and `const`
marking; parameter names do not matter.

Add `import portfolio` to a script to use these as `portfolio.name`.

## Creating portfolios

| Name                                      | Description                                                                                                                                                        |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`portfolio.new`](./portfolio/new.md)     | Creates a portfolio that holds one net position, for [`trade.nextOpen`](./trade/nextOpen.md), [`trade.ohlc`](./trade/ohlc.md) and [`trade.path`](./trade/path.md). |
| [`portfolio.lots`](./portfolio/lots.md)   | Creates a portfolio that tracks each entry as its own lot, for [`trade.lots`](./trade/lots.md).                                                                    |
| [`portfolio.basic`](./portfolio/basic.md) | Creates a net portfolio with the given starting cash and default settings.                                                                                         |

## Interfaces

| Name                                                      | Description                                                                                                                                        |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`portfolio.PortfolioView`](./portfolio/PortfolioView.md) | Read-only reporting methods that every portfolio provides.                                                                                         |
| [`portfolio.NetLedger`](./portfolio/NetLedger.md)         | Net-position accounting that [`trade.nextOpen`](./trade/nextOpen.md), [`trade.ohlc`](./trade/ohlc.md) and [`trade.path`](./trade/path.md) require. |
| [`portfolio.LotLedger`](./portfolio/LotLedger.md)         | Per-lot accounting that [`trade.lots`](./trade/lots.md) requires.                                                                                  |
