Coordinators that run a strategy's orders through a broker and record the fills in a portfolio.

Add `import trade` together with `import broker` and `import portfolio`. A
coordinator owns one broker value and one portfolio value: it submits your
orders to the broker, applies each fill to the portfolio, and refreshes the
account the broker checks before matching continues. Pick the family that
matches how your orders should fill: [`trade.nextOpen`](./trade/nextOpen.md) (next open, or
this bar's close), [`trade.ohlc`](./trade/ohlc.md) (anywhere in the bar's range),
[`trade.path`](./trade/path.md) (along an ordered intrabar path, with trailing exits) or
[`trade.lots`](./trade/lots.md) (separate lots, executed immediately). The broker
from [`broker.new`](./broker/new.md) holds one pending order and one attached exit at a
time. Store the coordinator in a `var` so its state persists across bars.
The [strategy model](../../strategy.md) describes each lifecycle in detail.

```tea
import broker
import portfolio
import trade

fast = ta.ema(close, 10)
slow = ta.ema(close, 30)
crossedUp = ta.crossover(fast, slow)
crossedDown = ta.crossunder(fast, slow)

var strat = trade.nextOpen(broker.new(), portfolio.new(initialCash = 10000.0))
strat.begin_bar(open, bar_index)
if crossedUp and strat.position_quantity() == 0.0
    strat.entry("Long", trade.Direction.long)
if crossedDown and strat.position_quantity() > 0.0
    strat.close("Exit")
strat.end_bar(close, false)
plot("equity", strat.snapshot().equity)
```

Add `import trade` to a script to use these as `trade.name`.

## Creating coordinators

| Name                                    | Description                                                                                                   |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| [`trade.nextOpen`](./trade/nextOpen.md) | Creates a coordinator whose orders fill at the next bar's open, or at this bar's close when enabled.          |
| [`trade.ohlc`](./trade/ohlc.md)         | Creates a coordinator that matches orders and one stop/target exit against each bar's high-low range.         |
| [`trade.path`](./trade/path.md)         | Creates a coordinator that replays each bar as an ordered price path, with fixed and trailing exits.          |
| [`trade.lots`](./trade/lots.md)         | Creates a coordinator that opens and closes independently accounted lots immediately, within the current bar. |
