Trade coordinators that send a strategy's orders to a broker and record every fill in a portfolio, plus helpers that size entries and set rebalance targets.

Add `import trade` together with `import broker` and `import portfolio`. A
coordinator owns one broker value and one portfolio value. It submits orders
to the broker and applies each fill to the portfolio before the broker
matches anything else, so later checks see the new cash and position. The
four coordinators, made by [`trade.nextOpen`](./trade/nextOpen.md), [`trade.ohlc`](./trade/ohlc.md),
[`trade.path`](./trade/path.md) and [`trade.lots`](./trade/lots.md), differ in when and at what price
orders fill, and [`trade.lots`](./trade/lots.md) keeps each entry as a separate lot;
[Strategies](../../strategy.md) compares them.

A complete strategy that uses all three libraries:

```tea
import broker
import portfolio
import trade

fast = ta.ema(close, 10)
slow = ta.ema(close, 30)
crossedUp = ta.crossover(fast, slow)
crossedDown = ta.crossunder(fast, slow)

// `var` keeps the coordinator, its orders and its books from bar to bar.
var strat = trade.nextOpen(
    broker.new(commission = broker.commissionPercent(0.1)),
    portfolio.new(initialCash = 10000.0)
)
strat.begin_bar(open, bar_index)
if crossedUp and strat.position_quantity() == 0.0
    strat.entry("Long", trade.Direction.long,
        sizing = trade.percentOfEquity(50.0))
if crossedDown and strat.position_quantity() > 0.0
    strat.close("Exit")
strat.end_bar(close, false)

metrics = strat.snapshot()
plot("equity", metrics.equity)
plot("max drawdown", metrics.maxDrawdown)
```

Add `import trade` to a script to use these as `trade.name`.

## Sizing and targets

| Name                                                              | Description                                                                                                                                                                |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`trade.percentOfEquity`](./trade/percentOfEquity.md)             | Sizes an entry as a percentage of the portfolio's equity, read when `entry` is called.                                                                                     |
| [`trade.percentOfEquityAtFill`](./trade/percentOfEquityAtFill.md) | Sizes an entry as a percentage of the equity at the moment the order fills.                                                                                                |
| [`trade.targetQuantity`](./trade/targetQuantity.md)               | Creates a rebalance target for an exact signed position size.                                                                                                              |
| [`trade.targetPercentOfEquity`](./trade/targetPercentOfEquity.md) | Creates a rebalance target worth a signed percentage of equity when the order fills.                                                                                       |
| [`trade.SizingKind`](./trade/SizingKind.md)                       | Which equity a [`trade.Sizing`](./trade/Sizing.md) percentage is taken from: the marked equity when `entry` is called, or the equity when the order fills.                 |
| [`trade.Sizing`](./trade/Sizing.md)                               | Percent-of-equity sizing for an entry, made by [`trade.percentOfEquity`](./trade/percentOfEquity.md) or [`trade.percentOfEquityAtFill`](./trade/percentOfEquityAtFill.md). |

## Creating coordinators

| Name                                    | Description                                                                                                                   |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| [`trade.nextOpen`](./trade/nextOpen.md) | Creates a coordinator whose orders fill at a later bar's open, or at a bar's close when the broker processes orders on close. |
| [`trade.ohlc`](./trade/ohlc.md)         | Creates a coordinator that matches orders and one stop-loss and/or take-profit exit against each bar's open, high and low.    |
| [`trade.path`](./trade/path.md)         | Creates a coordinator that replays each bar as an ordered price path, with fixed and trailing exits.                          |
| [`trade.lots`](./trade/lots.md)         | Creates a coordinator that opens and closes separately accounted lots at once, within the current bar.                        |
