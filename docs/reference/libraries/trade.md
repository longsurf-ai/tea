Coordinators that run a strategy's orders through a broker and record the fills in a portfolio.

Add `import trade` together with `import broker` and `import portfolio`. A
coordinator owns one broker value and one portfolio value: it submits your
orders to the broker, applies each fill to the portfolio, and refreshes the
account the broker checks before matching continues. Pick the family that
matches how your orders should fill: [`trade.nextOpen`](./trade.md#nextopen) (next open, or
this bar's close), [`trade.ohlc`](./trade.md#ohlc) (anywhere in the bar's range),
[`trade.path`](./trade.md#path) (along an ordered intrabar path, with trailing exits) or
[`trade.lots`](./trade.md#lots) (separate lots, executed immediately). The broker
from [`broker.new`](./broker.md#new) holds one pending order and one attached exit at a
time. Store the coordinator in a `var` so its state persists across bars.
The [strategy model](../../strategy.md) describes each lifecycle in detail.

```tea
import broker
import portfolio
import trade

fast = ta.ema(close, 10)
slow = ta.ema(close, 30)
crossedUp = ta.crossover(fast, slow)
crossedDown = ta.crossunder(fast, slow)

var strat = trade.nextOpen(broker.new(), portfolio.new(initialCash = 10000.0))
strat.begin_bar(open, bar_index)
if crossedUp and strat.position_quantity() == 0.0
    strat.entry("Long", trade.Direction.long)
if crossedDown and strat.position_quantity() > 0.0
    strat.close("Exit")
strat.end_bar(close, false)
plot("equity", strat.snapshot().equity)
```

Add `import trade` to a script to use these as `trade.name`.

## Sizing and targets

### percentOfEquity

Sizes an entry as a percentage of the portfolio's marked equity, read when `entry` is called.

```tea
trade.percentOfEquity(float percent, bool commissionIncluded = false)
```

| Parameter            | Type    | Default | Description                                        |
| -------------------- | ------- | ------- | -------------------------------------------------- |
| `percent`            | `float` |         | Percentage of equity, above `0` and at most `100`. |
| `commissionIncluded` | `bool`  | `false` | Whether the budget also pays the commission.       |

**Returns:** A [`trade.Sizing`](./trade.md#sizing) for the `sizing` argument of `entry`.

Marked equity comes from the latest `mark` or `end_bar`, or is the initial
cash before the first one. With `commissionIncluded`, the commission is paid
out of the budget; otherwise it is charged on top. If the percentage is not
above `0` and at most `100`, or the marked equity is not positive, the
broker rejects the order when it would fill.

### percentOfEquityAtFill

Sizes an entry as a percentage of equity at the moment the order fills.

```tea
trade.percentOfEquityAtFill(float percent, bool commissionIncluded = false)
```

| Parameter            | Type    | Default | Description                                        |
| -------------------- | ------- | ------- | -------------------------------------------------- |
| `percent`            | `float` |         | Percentage of equity, above `0` and at most `100`. |
| `commissionIncluded` | `bool`  | `false` | Whether the budget also pays the commission.       |

**Returns:** A [`trade.Sizing`](./trade.md#sizing) for the `sizing` argument of `entry`.

The broker values equity as cash plus the position at the matched price
before slippage; when the entry reverses a position, that is after the
closing fill. With `commissionIncluded`, the commission is paid out of the
budget; otherwise it is charged on top. If the percentage is not above `0`
and at most `100`, the broker rejects the order when it would fill.

### targetQuantity

Creates a rebalance target for an exact signed position size.

```tea
trade.targetQuantity(float quantity)
```

| Parameter  | Type    | Description                                                           |
| ---------- | ------- | --------------------------------------------------------------------- |
| `quantity` | `float` | Target position: positive for long, negative for short, `0` for flat. |

**Returns:** A [`broker.PositionTarget`](./broker.md#positiontarget) for a coordinator's `rebalance`.

### targetPercentOfEquity

Creates a rebalance target worth a signed percentage of equity when the order fills.

```tea
trade.targetPercentOfEquity(float percent)
```

| Parameter | Type    | Description                                                                                  |
| --------- | ------- | -------------------------------------------------------------------------------------------- |
| `percent` | `float` | Target position value as a percentage of equity, from `-100` to `100`; negative means short. |

**Returns:** A [`broker.PositionTarget`](./broker.md#positiontarget) for a coordinator's `rebalance`.

The broker rejects a target beyond `100` percent in either direction when it
is submitted, and rejects the order when equity at the fill price is not
positive.

### Sizing

Percent-of-equity sizing for an entry.

```tea
type Sizing
```

| Member                            | Description                                                                                                                       |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `SizingKind kind`                 | Which equity the percentage is taken from.                                                                                        |
| `float value`                     | Position value as a percentage of equity, above `0` and at most `100`. The broker rejects other values when the order would fill. |

## Creating coordinators

### nextOpen

Creates a coordinator whose orders fill at the next bar's open, or at this bar's close when enabled.

```tea
trade.nextOpen(broker, portfolio)
```

| Parameter   | Description                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `broker`    | A broker with the [`broker.NextOpenBroker`](./broker.md#nextopenbroker) methods, normally from [`broker.new`](./broker.md#new).      |
| `portfolio` | A portfolio with the [`portfolio.NetLedger`](./portfolio.md#netledger) methods, normally from [`portfolio.new`](./portfolio.md#new). |

**Returns:** A [`trade.NextOpenTrade`](./trade.md#nextopentrade) that owns both values.

Each bar, call `begin_bar(open, bar_index)` before your signal logic and
`end_bar(close, false)` after it. With a broker created with
`processOrdersOnClose = true`, `end_bar` also fills orders at the close,
including orders submitted earlier in the same bar. A broker or portfolio
without the required methods is a compile error.

```tea
import broker
import portfolio
import trade

upper = ta.highest(high, 20)
lower = ta.lowest(low, 20)

var strat = trade.nextOpen(
    broker.new(processOrdersOnClose = true),
    portfolio.new(initialCash = 10000.0)
)
strat.begin_bar(open, bar_index)
if close > upper[1] and strat.position_quantity() == 0.0
    strat.entry("Breakout", trade.Direction.long, sizing = trade.percentOfEquity(50.0))
if close < lower[1] and strat.position_quantity() > 0.0
    strat.close("Breakdown")
// processOrdersOnClose lets end_bar fill these orders at this bar's close.
strat.end_bar(close, false)
```

### ohlc

Creates a coordinator that matches orders and one stop/target exit against each bar's high-low range.

```tea
trade.ohlc(broker, portfolio)
```

| Parameter   | Description                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `broker`    | A broker with the [`broker.OhlcBroker`](./broker.md#ohlcbroker) methods, normally from [`broker.new`](./broker.md#new).              |
| `portfolio` | A portfolio with the [`portfolio.NetLedger`](./portfolio.md#netledger) methods, normally from [`portfolio.new`](./portfolio.md#new). |

**Returns:** A [`trade.OhlcTrade`](./trade.md#ohlctrade) that owns both values.

Each bar, call `begin_bar(open, high, low, bar_index)`, submit orders and
exits, then call `end_bar(close, false)`. Use [`trade.path`](./trade.md#path) instead
when the order of the high and low matters or you need trailing exits.

```tea
import broker
import portfolio
import trade

upper = ta.highest(high, 20)

var strat = trade.ohlc(broker.new(), portfolio.new(initialCash = 10000.0))
strat.begin_bar(open, high, low, bar_index)
if strat.position_quantity() == 0.0 and not na(upper)
    // Resubmitting the same ids each bar moves the pending stop entry and its exit.
    strat.entry("Breakout", trade.Direction.long, qty = 10.0, stop = upper)
    strat.exit("Bracket", fromEntry = "Breakout", stop = upper * 0.95, target = upper * 1.1)
strat.end_bar(close, false)
```

### path

Creates a coordinator that replays each bar as an ordered price path, with fixed and trailing exits.

```tea
trade.path(broker, portfolio)
```

| Parameter   | Description                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `broker`    | A broker with the [`broker.PathBroker`](./broker.md#pathbroker) methods, normally from [`broker.new`](./broker.md#new).              |
| `portfolio` | A portfolio with the [`portfolio.NetLedger`](./portfolio.md#netledger) methods, normally from [`portfolio.new`](./portfolio.md#new). |

**Returns:** A [`trade.PathTrade`](./trade.md#pathtrade) that owns both values.

Each bar, call `begin_bar(open, high, low, close, bar_index)`, attach or
adjust exits, call `continue_bar(open, high, low, close)`, submit new
orders, then call `end_bar(close, false)`.

```tea
import broker
import portfolio
import trade

fast = ta.ema(close, 10)
slow = ta.ema(close, 30)
crossedUp = ta.crossover(fast, slow)

var strat = trade.path(broker.new(), portfolio.new(initialCash = 10000.0))
fills = strat.begin_bar(open, high, low, close, bar_index)
if not na(fills.pending) and strat.position_quantity() > 0.0
    // Derive the exit from the entry price; continue_bar checks the rest of this bar.
    entryPrice = strat.position_avg_price()
    strat.exit("Trail", fromEntry = "Long", stop = entryPrice * 0.95, activateOnEntryBar = true, trailPrice = entryPrice * 1.05, trailOffset = entryPrice * 0.02)
strat.continue_bar(open, high, low, close)
if crossedUp and strat.position_quantity() == 0.0
    strat.entry("Long", trade.Direction.long, qty = 10.0)
strat.end_bar(close, false)
```

### lots

Creates a coordinator that opens and closes independently accounted lots immediately, within the current bar.

```tea
trade.lots(broker, portfolio)
```

| Parameter   | Description                                                                                                                            |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `broker`    | A broker with the [`broker.ImmediateBroker`](./broker.md#immediatebroker) methods, normally from [`broker.new`](./broker.md#new).      |
| `portfolio` | A portfolio with the [`portfolio.LotLedger`](./portfolio.md#lotledger) methods, normally from [`portfolio.lots`](./portfolio.md#lots). |

**Returns:** A [`trade.LotTrade`](./trade.md#lottrade) that owns both values.

Each bar, call `begin_bar(close, bar_index)`, then `entry`, `close_trade` or
`close_trade_at_stop`, then `mark()`. Each entry fill carries the `tradeId`
that later closes refer to.

```tea
import broker
import portfolio
import trade

basis = ta.sma(close, 20)
crossedUp = ta.crossover(close, basis)
crossedDown = ta.crossunder(close, basis)

var strat = trade.lots(broker.new(), portfolio.lots(initialCash = 10000.0))
var int lotId = 0
var float lotStop = na
strat.begin_bar(close, bar_index)
if lotId > 0
    stopFill = strat.close_trade_at_stop("Stop", lotId, broker.Side.buy, open, high, low, lotStop)
    if not na(stopFill)
        lotId := 0
if lotId > 0 and crossedDown
    strat.close_trade("Exit", lotId)
    lotId := 0
if lotId == 0 and crossedUp
    entryFill = strat.entry("Long", "Cover", trade.Direction.long, notional = 1000.0)
    if not na(entryFill)
        lotId := entryFill.tradeId
        lotStop := close * 0.97
strat.mark()
```

Create it with [`trade.ohlc`](./trade.md#ohlc). It does not assume whether the high or
the low came first and has no trailing exits; use [`trade.PathTrade`](./trade.md#pathtrade)
when either matters. Each bar, call `begin_bar`, submit orders and exits,
then call `end_bar`. Use these methods rather than calling `broker` or
`portfolio` directly.

```tea
type PathTrade<B: broker.PathBroker, P: portfolio.NetLedger>
```

| `P portfolio`                                                                                                                                                               | Portfolio that records this coordinator's fills.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

Market orders fill at the open; a stop entry fills at the open when the bar gaps past its stop, otherwise where the path crosses it. | `broker.Fill continue_bar(float openPrice, float highPrice, float lowPrice, float closePrice)`                                                                              | Checks the attached exit, including its trailing stop, along the part of the bar after `begin_bar`'s fill. Call it after `begin_bar` and any exit changes, with the same prices. When nothing filled in `begin_bar`, it checks the whole bar. `openPrice`: the bar's open. `highPrice`: the bar's high. `lowPrice`: the bar's low. `closePrice`: the bar's close. An entry against the open position reverses it: the broker closes the position, then opens the new one. Adding to a position requires the same `commandId` and room under the portfolio's `pyramiding`. Resubmitting a pending stop entry with the same `commandId` and a new `stop` replaces it. `commandId`: name of the order; exits and `cancel` refer to it. `direction`: `trade.Direction.long` to buy or `trade.Direction.short` to sell. `qty`: quantity to open or add; must be positive. `sizing`: percent-of-equity sizing from [`trade.percentOfEquity`](./trade.md#percentofequity) or [`trade.percentOfEquityAtFill`](./trade.md#percentofequityatfill). `stop`: stop price that makes this a stop entry: a long triggers at or above it, a short at or below it. Once active, the trailing stop takes the place of `stop` whenever it is tighter. `fromEntry` must name the pending entry or the entry that opened the position. One exit is attached at a time: resubmitting the same `commandId` and `fromEntry` replaces it, and closing the position cancels it. `commandId`: name of the exit; `cancel` takes it. `fromEntry`: `commandId` of the entry the exit belongs to. `stop`: stop price. `target`: target price. `activateOnEntryBar`: whether the exit may fill on the bar its entry fills. `trailPrice`: price that activates the trailing stop. `trailOffset`: distance the trailing stop keeps from the best price reached since activation. | `int cancel(string commandId)`                                                                                                                                              | Cancels the pending order or attached exit named `commandId`. ### LotTrade

```tea
type LotTrade<B: broker.ImmediateBroker, P: portfolio.LotLedger>
```
