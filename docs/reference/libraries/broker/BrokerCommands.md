Command and pending-state methods common to brokers that schedule commands.

```tea
interface BrokerCommands
```

It says nothing about when matching runs or whether immediate execution
exists. None of the trade coordinators require it; generic code can use it
to accept any broker that takes commands. Like every Tea interface, it
constrains types at compile time and never exists as a runtime value.
