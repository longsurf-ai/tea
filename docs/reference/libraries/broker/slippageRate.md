Adverse slippage as a fraction of the matched price.

```tea
broker.slippageRate(float rate = 0.0)
```

| Parameter | Type    | Default | Description                     |
| --------- | ------- | ------- | ------------------------------- |
| `rate`    | `float` | `0.0`   | slippage as a fraction of price |

**Returns:** a `rate` [`broker.Slippage`](./Slippage.md).

`0.001` fills buys 0.1% above and sells 0.1% below the matched price. The
rate must be at least `0` and below `1`; otherwise the broker rejects every
fill with `invalidConfiguration`.
