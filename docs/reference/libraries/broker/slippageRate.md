Adverse slippage as a fraction of the matched price.

```tea
broker.slippageRate(float rate = 0.0)
```

| Parameter | Type    | Default | Description                     |
| --------- | ------- | ------- | ------------------------------- |
| `rate`    | `float` | `0.0`   | slippage as a fraction of price |

**Returns:** `broker.Slippage`: a `rate` slippage holding `rate`.

`0.001` fills buys 0.1% above and sells 0.1% below the matched price. The
rate must be at least `0` and below `1`; otherwise the broker rejects every
order with `invalidConfiguration` when it would fill.

**Example:** A 10-unit buy at the open of 110 on index 1 fills 1% higher, at 111.1; the
sale at the open of 120 on index 2 fills 1% lower, at 118.8.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(
    broker.new(slippage = broker.slippageRate(0.01)),
    portfolio.new(initialCash = 10000.0)
)
filled = strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 10.0)
if bar_index == 1
    strat.close("Long")
strat.end_bar(close, false)
emit "open" open
emit "price" filled.price
```

```csv
0,100,100
1,110,112
2,120,118
```

**Output:**

```text

0      100   na
1      110   111.1
2      120   118.8
```
