Why the broker refused a command, carried by [`broker.OrderRejected`](./OrderRejected.md).

```tea
enum Rejection
```

| Member                 | Description                                                                                                                                                                            |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pendingOrder`         | The broker already holds a different pending command, or a different attached exit.                                                                                                    |
| `invalidAccountState`  | The command does not fit the broker or account state, for example a wrong kind or side, no matching entry or lot, no position to close, no pyramiding capacity, or too little capital. |
| `invalidConfiguration` | Commission or slippage settings are invalid, or the account reports invalid portfolio settings.                                                                                        |
| `invalidQuantity`      | The size is invalid: more than one sizing field, a nonpositive size, or an equity percent above `100`. Immediate execution also requires exactly one of `quantity` and `notional`.     |
| `invalidPrice`         | A stop, target, trailing value or rebalance target is missing, nonpositive or inconsistent, such as a long exit whose stop is not below its target.                                    |
| `entryIdMismatch`      | An entry on the open position's side uses a different command id; adding to a position must reuse the id that opened it.                                                               |
