Why the broker refused a command, carried by [`broker.OrderRejected`](./OrderRejected.md).

```tea
enum Rejection
```

| Member                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pendingOrder`         | At submission: the broker already holds a different pending command, or a different attached exit.                                                                                                                                                                                                                                                                                                                                    |
| `invalidAccountState`  | The command does not fit the broker or account state. At submission: a wrong kind or side, or an exit whose entry is neither pending nor open. At fill: a close with no position to close, no pyramiding capacity, too little capital, a nonpositive execution price or quantity, or a percent target while equity or the reference price is not positive. A trailing exit is also refused when matched outside the path coordinator. |
| `invalidConfiguration` | At fill: the commission or slippage settings are invalid, or the account reports invalid portfolio settings.                                                                                                                                                                                                                                                                                                                          |
| `invalidQuantity`      | At fill: more than one sizing field, a nonpositive size, or an equity percent above `100`. Immediate execution needs exactly one of `quantity` and `notional`.                                                                                                                                                                                                                                                                        |
| `invalidPrice`         | At submission: an entry stop that is not positive; exit levels that are missing, nonpositive or inconsistent, such as a long exit whose stop is not below its target; or a rebalance target that is `na` or a percent outside `-100` to `100`. In immediate execution: a touched stop that is not positive.                                                                                                                           |
| `entryIdMismatch`      | At submission: an entry on the open position's side uses a different command id; adding to a position must reuse the id that opened it, which can be a rebalance's id.                                                                                                                                                                                                                                                                |

A scheduled command is checked twice. When it is submitted, the broker
checks its kind, side, prices and entry id, and whether another order is
waiting. Its size, the commission, slippage and portfolio settings, and the
capital are checked only on the bar the order would fill, so a command
accepted with [`broker.OrderSubmitted`](./OrderSubmitted.md) can still be rejected there.
Immediate execution checks the command, the settings and the account at
once. The [`broker.BrokerEmulator`](./BrokerEmulator.md) page lists each check by stage.
