Commission charged as a percent of each fill's notional.

```tea
broker.commissionPercent(float percent = 0.0)
```

| Parameter | Type    | Default | Description                         |
| --------- | ------- | ------- | ----------------------------------- |
| `percent` | `float` | `0.0`   | commission as a percent of notional |

**Returns:** `broker.Commission`: a `rate` commission holding `percent / 100`.

`0.1` charges 0.1%; the same as `commissionRate(percent / 100)`.

**Example:** `commissionPercent(0.1)` holds the rate 0.001, so a 10-unit buy at the
open of 110 on index 1 pays 1.1, as with `commissionRate(0.001)`.

```tea
import broker
import portfolio
import trade

setting = broker.commissionPercent(0.1)
var strat = trade.nextOpen(
    broker.new(commission = setting),
    portfolio.new(initialCash = 10000.0)
)
filled = strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 10.0)
strat.end_bar(close, false)
emit "open" open
emit "rate" setting.value
emit "fee" filled.fee
```

```csv
time,open,close
0,100,100
1,110,112
```

**Output:**

```text
index  open  rate   fee
0      100   0.001  na
1      110   0.001  1.1
```
