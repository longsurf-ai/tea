Commission charged as fixed cash per unit of filled quantity.

```tea
broker.commissionCashPerContract(float cash = 0.0)
```

| Parameter | Type    | Default | Description   |
| --------- | ------- | ------- | ------------- |
| `cash`    | `float` | `0.0`   | cash per unit |

**Returns:** `broker.Commission`: a `cashPerContract` commission holding `cash`.

The fee does not depend on the price. A negative or `na` amount makes the
broker reject every order with `invalidConfiguration` when it would fill.

**Example:** 2.5 per unit: the 10-unit buy at the open of 110 on index 1 and its sale
at the open of 120 on index 2 each pay 25, so cash goes from 10000 to 8875
and then to 10050.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(
    broker.new(commission = broker.commissionCashPerContract(2.5)),
    portfolio.new(initialCash = 10000.0)
)
filled = strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 10.0)
if bar_index == 1
    strat.close("Long")
strat.end_bar(close, false)
emit "open" open
emit "fee" filled.fee
emit "cash" strat.cash()
```

```csv
time,open,close
0,100,100
1,110,112
2,120,118
```

**Output:**

```text
index  open  fee  cash
0      100   na   10000
1      110   25   8875
2      120   25   10050
```
