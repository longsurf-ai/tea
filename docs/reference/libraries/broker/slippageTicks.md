Adverse slippage as a number of price ticks.

```tea
broker.slippageTicks(float ticks = 0.0, float tickSize = 0.0)
```

| Parameter  | Type    | Default | Description              |
| ---------- | ------- | ------- | ------------------------ |
| `ticks`    | `float` | `0.0`   | number of ticks per fill |
| `tickSize` | `float` | `0.0`   | price size of one tick   |

**Returns:** a `ticks` [`broker.Slippage`](./Slippage.md).

Buys fill `ticks * tickSize` above the matched price and sells the same
distance below. Neither may be negative, and `tickSize` must be positive
whenever `ticks` is not zero; otherwise the broker rejects every fill with
`invalidConfiguration`.

```tea
import broker
import portfolio
import trade

// Two ticks of 0.25 against every fill, plus 2.5 per contract.
var strat = trade.nextOpen(
    broker.new(
        commission = broker.commissionCashPerContract(2.5),
        slippage = broker.slippageTicks(2.0, 0.25)
    ),
    portfolio.new(initialCash = 50000.0)
)
```
