Adverse slippage as a number of price ticks.

```tea
broker.slippageTicks(float ticks = 0.0, float tickSize = 0.0)
```

| Parameter  | Type    | Default | Description              |
| ---------- | ------- | ------- | ------------------------ |
| `ticks`    | `float` | `0.0`   | number of ticks per fill |
| `tickSize` | `float` | `0.0`   | price size of one tick   |

**Returns:** `broker.Slippage`: a `ticks` slippage holding `ticks` and `tickSize`.

Buys fill `ticks * tickSize` above the matched price and sells the same
distance below. Neither may be negative, and `tickSize` must be positive
whenever `ticks` is not zero; otherwise the broker rejects every order
with `invalidConfiguration` when it would fill. An attached exit fills at
no less than one tick, even when the slipped price would be lower.

**Example:** Two ticks of 0.25: the 10-unit buy at the open of 110 on index 1 fills 0.5
higher, at 110.5, and the sale at the open of 120 on index 2 fills 0.5
lower, at 119.5.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(
    broker.new(slippage = broker.slippageTicks(2.0, 0.25)),
    portfolio.new(initialCash = 10000.0)
)
filled = strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 10.0)
if bar_index == 1
    strat.close("Long")
strat.end_bar(close, false)
emit "open" open
emit "price" filled.price
```

```csv
0,100,100
1,110,112
2,120,118
```

**Output:**

```text

0      100   na
1      110   110.5
2      120   119.5
```
