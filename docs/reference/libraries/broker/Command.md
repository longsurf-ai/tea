One instruction from a strategy to the broker, built by the trade coordinators from calls such as `entry` and `exit`.

```tea
type Command
```

| Field                                       | Description                                                                                                                                                                       |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `string commandId`                          | Strategy-chosen id; it names the order for replacement and cancellation, and an entry for `fromEntry`.                                                                            |
| `broker.CommandKind kind`                   | What the command asks for.                                                                                                                                                        |
| `broker.Side side`                          | Side of an entry or close; an exit takes the side that closes its entry, and a rebalance fills on the side that moves toward its target.                                          |
| `float quantity`                            | Explicit size in units, or `na`; a scheduled close ignores it and closes the whole position.                                                                                      |
| `int signalBarIndex`                        | Bar index where the command was issued; a scheduled command fills only on a later bar, or from this bar's close on when close processing is enabled.                              |
| `float notional = na`                       | Size as cash value; the quantity is `notional` divided by the execution price.                                                                                                    |
| `string fromEntry = na`                     | For an exit, the `commandId` of the entry it protects.                                                                                                                            |
| `float stop = na`                           | For an entry, the stop price that triggers it; for an exit, the stop-loss price.                                                                                                  |
| `bool activateOnEntryBar = false`           | For an exit, whether it may trigger on the bar its entry fills; otherwise it starts on the next bar. With OHLC matching it applies only when the entry filled at that bar's open. |
| `float target = na`                         | For an exit, the take-profit price.                                                                                                                                               |
| `float cashBudget = na`                     | For an entry, cash to spend including commission: notional plus commission equals this budget.                                                                                    |
| `float equityPercent = na`                  | For an entry, size as a percent of equity at the fill's reference price, above `0` and at most `100`.                                                                             |
| `bool commissionIncluded = false`           | With `equityPercent`, whether commission comes out of the budget instead of on top of it.                                                                                         |
| `broker.PositionTarget positionTarget = na` | For a rebalance, the target position.                                                                                                                                             |
| `float trailPrice = na`                     | For an exit, the price at which the trailing stop activates.                                                                                                                      |
| `float trailOffset = na`                    | For an exit, the price distance the trailing stop keeps behind the best price since activation.                                                                                   |
| `int tradeId = 0`                           | For an immediate close, the stable id of the lot to close; `0` otherwise.                                                                                                         |

The broker turns it into an [`broker.Order`](./Order.md), checking its kind, side,
prices and entry id when it is submitted, and its size, the settings and
the capital when the order would fill; immediate execution checks
everything at once. Which fields apply depends on `kind`; the rest keep
their defaults, and prices are absolute levels. An entry uses at most one
of `quantity`, `notional`, `cashBudget` and `equityPercent`; with none set,
a scheduled entry spends all available capital, cash for a buy and equity
for a sell.
