Event appended to the `broker.OrderCancelled` output when an order is cancelled or replaced.

```tea
type OrderCancelled
```

| Field                | Description          |
| -------------------- | -------------------- |
| `broker.Order order` | The cancelled order. |

Besides explicit cancellation, the broker cancels a replaced order, an
attached exit whose position was closed or reversed or whose entry failed,
and a rebalance that needs no change.
