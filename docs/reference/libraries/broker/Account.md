Read-only view of the portfolio that the broker uses to validate and size fills.

```tea
type Account
```

| Field                            | Description                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `float buyingPower`              | Cash the account can spend; equity is this plus the position valued at the reference price.                                                                                                                                                                                                                                                             |
| `float positionQuantity`         | Signed net position: positive long, negative short, `0` flat.                                                                                                                                                                                                                                                                                           |
| `int openEntryCount`             | Number of open entries counted against `pyramiding`.                                                                                                                                                                                                                                                                                                    |
| `int pyramiding`                 | Maximum number of open entries; adding an entry needs `openEntryCount` below it.                                                                                                                                                                                                                                                                        |
| `float marginLong`               | Capital required for long exposure, as a percent of notional; `0` skips the capital check and the rebalance buy cap, though an entry without a size still needs cash above `0`. The reference portfolios support only `0` and `100`; with another value they report invalid settings.                                                                   |
| `float marginShort`              | Capital required for short exposure, as a percent of notional; `0` skips the capital check, though an entry without a size still needs equity above `0`. It is checked per order against the whole equity, not net of shorts already held: with `100` and a pyramiding of 3, three shorts of 90% of equity each all fill, about 2.7 times equity short. |
| `bool configurationValid = true` | `false` when the portfolio's own settings are invalid; the broker then rejects every order with `invalidConfiguration` when it would fill.                                                                                                                                                                                                              |

The trade coordinator asks the portfolio for a fresh one before every broker
call that can fill, so broker matching never depends on how the portfolio
keeps its books. Strategies do not construct it.
