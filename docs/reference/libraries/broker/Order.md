A command the broker accepted, with a broker-assigned id and order type.

```tea
type Order
```

| Field                                                  | Description                                                                                                                        |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `int id`                                               | Broker-assigned id, counting up from `1` in each broker.                                                                           |
| `string commandId`                                     | Strategy-chosen command id.                                                                                                        |
| `broker.Side side`                                     | Order side; for an exit, the side that closes its entry.                                                                           |
| `int signalBarIndex`                                   | Bar index where the command was issued.                                                                                            |
| `broker.CommandKind kind = broker.CommandKind.entry`   | What the order does.                                                                                                               |
| `float quantity = na`                                  | Explicit size in units, or `na`.                                                                                                   |
| `float notional = na`                                  | Size as cash value, or `na`.                                                                                                       |
| `string fromEntry = na`                                | For an exit, the `commandId` of the entry it protects.                                                                             |
| `float stop = na`                                      | Entry trigger or exit stop-loss price, or `na`.                                                                                    |
| `bool activateOnEntryBar = false`                      | For an exit, whether it may trigger on its entry's fill bar.                                                                       |
| `float target = na`                                    | Exit take-profit price, or `na`.                                                                                                   |
| `float cashBudget = na`                                | Commission-inclusive cash budget, or `na`.                                                                                         |
| `broker.OrderType orderType = broker.OrderType.market` | How it matches: `market` or `stop` for an entry, `market` for a close or rebalance, and `stop`, `target` or `bracket` for an exit. |
| `float equityPercent = na`                             | Size as a percent of equity at fill time, or `na`.                                                                                 |
| `bool commissionIncluded = false`                      | Whether commission comes out of the equity-percent budget.                                                                         |
| `broker.PositionTarget positionTarget = na`            | Rebalance target, or `na`.                                                                                                         |
| `float trailPrice = na`                                | Trailing-stop activation price, or `na`.                                                                                           |
| `float trailOffset = na`                               | Trailing-stop distance, or `na`.                                                                                                   |
| `int tradeId = 0`                                      | Stable lot id for an immediate order; `0` for a scheduled order.                                                                   |

Submissions return orders, and the [`broker.OrderSubmitted`](./OrderSubmitted.md),
[`broker.OrderCancelled`](./OrderCancelled.md) and [`broker.OrderExpired`](./OrderExpired.md) events carry
them.
