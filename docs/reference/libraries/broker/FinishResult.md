Orders that expired when the broker finished, returned by the coordinators' `end_bar` and `finish` on the final bar.

```tea
type FinishResult
```

| Field                  | Description                            |
| ---------------------- | -------------------------------------- |
| `broker.Order pending` | Pending command that expired, or `na`. |
| `broker.Order exit`    | Attached exit that expired, or `na`.   |

Those methods return `na` on every other bar.
