How an order is matched; on a fill, which kind of price it matched.

```tea
enum OrderType
```

| Member    | Description                                                                                                                                                                |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `market`  | No trigger price: fills at the next eligible open or close.                                                                                                                |
| `stop`    | Entry that triggers when price reaches its `stop` (rising for a buy, falling for a sell), or an exit with only a stop or trailing stop; on an exit fill, the stop matched. |
| `target`  | Exit with only a take-profit `target`; on an exit fill, the target matched.                                                                                                |
| `bracket` | Exit with a `target` plus a stop or trailing stop; its fill reports `stop` or `target`.                                                                                    |
