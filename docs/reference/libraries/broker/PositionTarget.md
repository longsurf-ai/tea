Target position for a rebalance, made by [`trade.targetQuantity`](../trade/targetQuantity.md) or [`trade.targetPercentOfEquity`](../trade/targetPercentOfEquity.md).

```tea
type PositionTarget
```

| Field                            | Description                                                             |
| -------------------------------- | ----------------------------------------------------------------------- |
| `broker.PositionTargetKind kind` | Unit of `value`.                                                        |
| `float value`                    | Signed target: a quantity, or a percent of equity from `-100` to `100`. |

A rebalance fills the difference between the target and the current
position with one buy or sell, even when that crosses zero. A percent target
becomes a quantity at the fill's reference price, before slippage. With long
margin enabled, a buy from a flat or long position is limited to what the
buying power pays for, so the position can stop short of the target. A
difference of at most `0.0000001` cancels the order instead. The formulas
are on [`broker.BrokerEmulator.execute`](./BrokerEmulator.md#execute).
