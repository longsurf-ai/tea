Commission charged as fixed cash per order.

```tea
broker.commissionCashPerOrder(float cash = 0.0)
```

| Parameter | Type    | Default | Description    |
| --------- | ------- | ------- | -------------- |
| `cash`    | `float` | `0.0`   | cash per order |

**Returns:** `broker.Commission`: a `cashPerOrder` commission holding `cash`.

The closing and opening fills of a scheduled reversal belong to one order
and pay it once. A negative or `na` amount makes the broker reject every
order with `invalidConfiguration` when it would fill.

**Example:** 7 per order. The 10-unit buy on index 1 pays 7. The short entry submitted
on index 1 reverses the position on index 2 with two fills of one order:
the closing fill pays 7 and the opening fill shown pays 0, so total fees
reach 14.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(
    broker.new(commission = broker.commissionCashPerOrder(7.0)),
    portfolio.new(initialCash = 10000.0)
)
filled = strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long, qty = 10.0)
if bar_index == 1
    strat.entry("Short", trade.Direction.short, qty = 10.0)
strat.end_bar(close, false)
emit "open" open
emit "fee" filled.fee
emit "totalFees" strat.snapshot().totalFees
emit "position" strat.position_quantity()
```

```csv
1,110,112

```

**Output:**

```text

0      100   na   0          0

```
