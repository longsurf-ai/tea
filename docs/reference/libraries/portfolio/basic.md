Creates a net portfolio with the given starting cash and default settings.

```tea
portfolio.basic(float initialCash)
```

| Parameter     | Type    | Description                      |
| ------------- | ------- | -------------------------------- |
| `initialCash` | `float` | Starting cash; must be positive. |

**Returns:** `portfolio.NetPortfolio`: a portfolio with no position, whose cash and equity are `initialCash`.

Same as `portfolio.new(initialCash = initialCash)`: `pyramiding` is `1` and
both margins are `100`.

**Example:** The entry sets no size, so the broker spends all the cash: 10 units at the
open of 100 at index 1. The `"Exit"` order fills at the open of 120 at
index 3, which leaves 1200 in cash.

```tea
import broker
import portfolio
import trade

var strat = trade.nextOpen(broker.new(), portfolio.basic(1000.0))
strat.begin_bar(open, bar_index)
if bar_index == 0
    strat.entry("Long", trade.Direction.long)
if bar_index == 2
    strat.close("Exit")
strat.end_bar(close, false)
emit "open" open
emit "close" close
emit "cash" strat.cash()
emit "position" strat.position_quantity()
emit "equity" strat.snapshot().equity
```
