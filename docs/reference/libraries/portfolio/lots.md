Creates a portfolio that tracks each entry as its own lot, for [`trade.lots`](../trade/lots.md).

```tea
portfolio.lots(
    float initialCash = 1000000.0,
    int maxOpenTrades = 1,
    float marginLong = 0.0,
    float marginShort = 0.0
)
```

| Parameter       | Type    | Default     | Description                                                                                        |
| --------------- | ------- | ----------- | -------------------------------------------------------------------------------------------------- |
| `initialCash`   | `float` | `1000000.0` | Starting cash; must be positive.                                                                   |
| `maxOpenTrades` | `int`   | `1`         | Most lots open at once; at least `1`. The broker rejects entries beyond it.                        |
| `marginLong`    | `float` | `0.0`       | `100` checks each long lot against the cash; `0` turns the check off. Other values are invalid.    |
| `marginShort`   | `float` | `0.0`       | `100` checks each short lot against the equity; `0` turns the check off. Other values are invalid. |

**Returns:** `portfolio.LotPortfolio`: a portfolio with no open lots, whose cash and equity are `initialCash`.

Cash, equity and peak equity start at `initialCash`. Each entry fill opens
a lot, and each closing fill closes one whole lot by its trade id. Unlike
[`portfolio.new`](./new.md), the margins default to `0`, so the capital check is
off unless you set them and cash can go below zero. With a margin of
`100`, each entry must pass the capital check that [`portfolio.new`](./new.md)
describes, valued at the close. Invalid settings do not stop the script;
instead no lot opens, because the broker rejects entries with
`invalidConfiguration`.

**Example:** Each entry opens its own lot at the close. The margins default to `0`, so
the second lot fills although it costs 660 with 400 left in cash, and cash
goes below zero. Closing the first lot by its trade id at index 3 leaves
the second one open.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(
    broker.new(),
    portfolio.lots(initialCash = 1000.0, maxOpenTrades = 2)
)
var int firstLot = 0
strat.begin_bar(close, bar_index)
if bar_index == 0
    opened = strat.entry("A", "Flip", trade.Direction.long, qty = 6.0)
    firstLot := opened.tradeId
if bar_index == 1
    strat.entry("B", "Flip", trade.Direction.long, qty = 6.0)
if bar_index == 3
    strat.close_trade("Sell A", firstLot)
strat.mark()
emit "close" close
emit "cash" strat.cash()
emit "position" strat.position_quantity()
emit "lots" strat.snapshot().openTradeCount
emit "equity" strat.snapshot().equity
```
