Per-lot accounting that [`trade.lots`](../trade/lots.md) requires.

```tea
interface LotLedger
```

[`portfolio.LotPortfolio`](./LotPortfolio.md) satisfies it. Passing [`trade.lots`](../trade/lots.md) a
portfolio without these methods is a compile error.

## Methods

### account

Returns the [`broker.Account`](../broker/Account.md) view the broker checks orders against.

```tea
broker.Account account() const
```

### apply_lot

Applies one fill to the open lots; coordinators also pass `na` when nothing filled.

```tea
int apply_lot(broker.Fill execution)
```

| Parameter   | Type          | Description                |
| ----------- | ------------- | -------------------------- |
| `execution` | `broker.Fill` | the fill to apply, or `na` |

### mark

Values the open lots at `price` and returns the new equity.

```tea
float mark(float price)
```

| Parameter | Type    | Description                |
| --------- | ------- | -------------------------- |
| `price`   | `float` | price to value the lots at |

### cash

Returns the cash balance.

```tea
float cash() const
```

### position_quantity

Returns the signed total of the open lots: positive when long, negative when short.

```tea
float position_quantity() const
```

### position_avg_price

Returns the average entry price of the open lots, or `na` when none are open.

```tea
float position_avg_price() const
```

### snapshot

Returns all metrics as one [`portfolio.PortfolioSnapshot`](./PortfolioSnapshot.md).

```tea
portfolio.PortfolioSnapshot snapshot() const
```

### open_trade_count

Returns the number of open lots.

```tea
int open_trade_count() const
```

### open_trade

Returns the open lot at `index`.

```tea
portfolio.OpenTrade open_trade(int index) const
```

| Parameter | Type  | Description                                   |
| --------- | ----- | --------------------------------------------- |
| `index`   | `int` | position from `0` to `open_trade_count() - 1` |
