Read-only reporting methods that every portfolio provides.

```tea
interface PortfolioView
```

[`portfolio.NetPortfolio`](./NetPortfolio.md) and [`portfolio.LotPortfolio`](./LotPortfolio.md) satisfy
it, and so do the trade coordinators, such as [`trade.NextOpenTrade`](../trade/NextOpenTrade.md).
Use it to constrain a type parameter, as in
`type Report<P: portfolio.PortfolioView>`, in code that only reads results.

## Methods

### cash

Returns the cash balance.

```tea
float cash() const
```

### position_quantity

Returns the signed position: positive when long, negative when short.

```tea
float position_quantity() const
```

### position_avg_price

Returns the average entry price of the open position, or `na` when flat.

```tea
float position_avg_price() const
```

### snapshot

Returns all metrics as one [`portfolio.PortfolioSnapshot`](./PortfolioSnapshot.md).

```tea
portfolio.PortfolioSnapshot snapshot() const
```
