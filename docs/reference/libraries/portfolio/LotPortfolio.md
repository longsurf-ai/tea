Portfolio that tracks each entry as a separate lot with its own id, entry price and entry commission.

```tea
type LotPortfolio
```

| Field                                   | Description                                                                                      |
| --------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `float initialCash`                     | Starting cash; it must be positive, and `total_return` is measured against it.                   |
| `int maxOpenTrades`                     | Most lots open at once; at least `1`. The broker rejects entries beyond it.                      |
| `float marginLong`                      | `100` requires each long lot's value plus commission to fit in cash; `0` turns the check off.    |
| `float marginShort`                     | `100` requires each short lot's value plus commission to fit in equity; `0` turns the check off. |
| `array<portfolio.OpenTrade> openTrades` | The open lots, in no stable order: closing a lot moves the last lot into its place.              |
| `float cashValue = 0.0`                 | Current cash balance.                                                                            |
| `float equityValue = 0.0`               | Equity at the latest `mark`.                                                                     |
| `float peakEquity = 0.0`                | Highest of `initialCash` and the equity at each `mark`.                                          |
| `float maxDrawdownValue = 0.0`          | Largest drop from peak equity, as a fraction of the peak.                                        |
| `float realizedPnlValue = 0.0`          | Realized profit and loss, net of commission.                                                     |
| `float totalFeesValue = 0.0`            | Total commission paid.                                                                           |
| `int fillCountValue = 0`                | Number of fills applied.                                                                         |
| `int roundTripCountValue = 0`           | Number of lots closed.                                                                           |
| `int winningTradeCountValue = 0`        | Closed lots with a profit above zero.                                                            |
| `int losingTradeCountValue = 0`         | Closed lots with zero or negative profit.                                                        |
| `float grossProfitValue = 0.0`          | Total profit of the winning lots.                                                                |
| `float grossLossValue = 0.0`            | Total loss of the losing lots, as a positive number.                                             |
| `int maxLongStackValue = 0`             | Most long lots open at the same time so far.                                                     |
| `int maxShortStackValue = 0`            | Most short lots open at the same time so far.                                                    |

Create it with [`portfolio.lots`](./lots.md), which starts cash, equity and peak
equity at `initialCash`, and pass it to [`trade.lots`](../trade/lots.md). Each entry fill
opens a lot, and a closing fill closes one whole lot, named by its trade
id. Each closed lot counts as one round trip, and as a winning trade when
its profit after its entry and exit commission is above zero. The
coordinator calls the methods that change the portfolio; strategies read
results through the coordinator.

### snapshot

Returns all metrics as one [`portfolio.PortfolioSnapshot`](./PortfolioSnapshot.md).

```tea
portfolio.PortfolioSnapshot snapshot() const
```

Its `openTradeCount` is the number of open lots, and `maxLongStack` and
`maxShortStack` are the most lots open at once on each side.

**Example:** Two lots of 2, bought at 100 and 120. Each closes against its own entry
price: the first sells at 110 for a profit of 20, the second at 100 for
a loss of 40, so `winRate` ends at 0.5. `mostLots` keeps the largest
number of lots open at once.

```tea
import broker
import portfolio
import trade

var strat = trade.lots(
    broker.new(),
    portfolio.lots(initialCash = 1000.0, maxOpenTrades = 3)
)
var int firstLot = 0
var int secondLot = 0
strat.begin_bar(close, bar_index)
if bar_index == 0
    opened = strat.entry("A", "Flip", trade.Direction.long, qty = 2.0)
    firstLot := opened.tradeId
if bar_index == 1
    opened = strat.entry("B", "Flip", trade.Direction.long, qty = 2.0)
    secondLot := opened.tradeId
if bar_index == 2
    strat.close_trade("Sell A", firstLot)
if bar_index == 4
    strat.close_trade("Sell B", secondLot)
strat.mark()
s = strat.snapshot()
emit "close" close
emit "cash" s.cash
emit "position" s.positionQuantity
emit "equity" s.equity
emit "lots" s.openTradeCount
emit "mostLots" s.maxLongStack
emit "realized" s.realizedPnl
emit "winRate" s.winRate
```

### apply_lot

Applies one fill: an entry opens a lot, and a close or exit closes the lot its `tradeId` names.

```tea
int apply_lot(broker.Fill execution)
```

| Parameter   | Type          | Description                |
| ----------- | ------------- | -------------------------- |
| `execution` | `broker.Fill` | the fill to apply, or `na` |

**Returns:** `int`: the number of fills applied so far.

In the formula, the fill has quantity `q`, price `x` and fee `f`, and
`s` is `1` for a buy and `-1` for a sell; `C` is the cash and `R`
realized profit, with primes for their values after the fill. Lot `i`
keeps the side `s_i`, quantity `q_i`, price `x_i` and fee `f_i` of the
fill that opened it. A new lot's id is the fill's `tradeId`, or the
fill's `id` when `tradeId` is not positive.

Each closed lot adds one to `round_trip_count`, and its profit goes to
the gross profit and the winning trades when it is above zero, or to
the gross loss and the losing trades otherwise. Every applied fill adds
its fee to `total_fees` and one to `fill_count`. It ignores `na`, fills
whose quantity or price is not positive or whose fee is negative,
rebalance fills, entries beyond `maxOpenTrades`, and closes that name no
open lot or whose side or quantity does not match it. Called by
[`trade.LotTrade`](../trade/LotTrade.md); strategies use the coordinator instead.

**Formula**

$$
\begin{aligned}
C' &= C - s \cdot q \cdot x - f \\
(s_i, q_i, x_i, f_i) &= (s, q, x, f)
\quad \text{for the lot } i \text{ an entry opens} \\
R' &= R + s_i \cdot q_i \cdot (x - x_i) - f_i - f
\quad \text{for the lot } i \text{ a close fill closes}
\end{aligned}
$$

**See also:** [`portfolio.LotPortfolio.mark`](./LotPortfolio.md#mark)

### mark

Values the open lots at `price`, updating equity, peak equity and maximum drawdown.

```tea
float mark(float price)
```

| Parameter | Type    | Description                |
| --------- | ------- | -------------------------- |
| `price`   | `float` | price to value the lots at |

**Returns:** `float`: the new equity.

In the formula, `p` is `price`, `E` the equity, `P` the peak equity and
`D` the maximum drawdown; `C`, `R` and the lot values are as in
[`portfolio.LotPortfolio.apply_lot`](./LotPortfolio.md#apply_lot), and the sums run over the open
lots. `U` is their unrealized profit: each lot's price change since
entry, less its entry commission. Called by [`trade.LotTrade`](../trade/LotTrade.md)'s
`mark`.

**Formula**

$$
\begin{aligned}
E &= C + p \cdot \sum_i s_i \cdot q_i = \mathit{initialCash} + R + U,
\quad U = \sum_i \bigl( s_i \cdot q_i \cdot (p - x_i) - f_i \bigr) \\
P &= \max(P,\ E) \\
D &= \max\left(D,\ \frac{P - E}{P}\right)
\end{aligned}
$$
