Net-position accounting that [`trade.nextOpen`](../trade/nextOpen.md), [`trade.ohlc`](../trade/ohlc.md) and [`trade.path`](../trade/path.md) require.

```tea
interface NetLedger
```

[`portfolio.NetPortfolio`](./NetPortfolio.md) satisfies it. It has no per-lot methods;
those belong to [`portfolio.LotLedger`](./LotLedger.md).

## Methods

### account

Returns the [`broker.Account`](../broker/Account.md) view the broker checks orders against.

```tea
broker.Account account() const
```

### apply_net

Applies one fill to the position; coordinators also pass `na` when nothing filled.

```tea
int apply_net(broker.Fill execution)
```

| Parameter   | Type          | Description                |
| ----------- | ------------- | -------------------------- |
| `execution` | `broker.Fill` | the fill to apply, or `na` |

### mark

```tea

```

| Parameter | Type    | Description                    |
| --------- | ------- | ------------------------------ |
| `price`   | `float` | price to value the position at |
